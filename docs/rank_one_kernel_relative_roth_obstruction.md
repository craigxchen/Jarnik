# Relative Roth separation for a rank-one phase kernel

This note treats the first coupled case left open by
[`fixed_hadamard_roth_phase_obstruction.md`](fixed_hadamard_roth_phase_obstruction.md).
When the row-difference matrix has a one-dimensional kernel generated by a
vector whose entries are all `+1` or `-1`, no coordinate is isolable.  The
remaining moving target can nevertheless be removed pairwise.  Nine
pairwise nonassociate nonunit Gaussian directions then force bounded radius
by Roth's theorem.  For the eleven-by-eleven core of a normalized Hadamard
matrix of order twelve, the target angles are all multiples of `pi/12` and
an elementary quadratic-form argument is stronger: if all eleven blocks are
conjugate-primitive nonunits and the normalized row products have Gaussian
gcd one, then

```text
angular span >= (1/2) R^(-4/11),
arc length  >= (1/2) R^(7/11),
R <= (2C)^(22/3)  if the arc length is at most C sqrt(R).
```

This effective core theorem permits shared prime support and does not assume
the eleven block directions are distinct.
Without a condition excluding associates, bounded radius is false: repeated
directions move freely along the kernel.  Thus the exact alternative is a
direction collision, rather than an uncontrolled moving Roth target.

## 1. Rank-one phase normal form

Fix an `m x k` integer matrix `S`, choose a row `0`, and let `D` have rows
`S_i-S_0` for `i!=0`.  Assume

```text
rank_Q(D)=k-1,                 ker_Q(D)=Q r,
r=(r_1,...,r_k),              r_j in {+1,-1}.          (1)
```

Suppose angles `theta_j`, integer row-unit exponents `t_i`, integer lifts
`l_i`, a common real number `c`, and errors `e_i` obey

```text
S theta + (pi/2)t = c 1 + 2 pi l + e,
|e_i| <= Delta/2.                                      (2)
```

There are a constant `L=L(S)` and a finite set
`B=B(S) subset (pi Q/2 pi Z)^k` such that (2) implies

```text
theta_j = r_j tau + beta_j + eta_j  (mod 2 pi),
beta=(beta_1,...,beta_k) in B,       |eta_j| <= L Delta. (3)
```

Indeed, choose a rational row `q` with `q r=1` and a rational matrix `P`
such that

```text
P D=I-r q.                                               (4)
```

Subtracting row `0` in (2), applying `P`, and taking
`tau=q theta` gives (3).  The lift and unit terms have rational
coefficients with fixed denominators, so their residues modulo `2 pi`
belong to a fixed finite set.  The error is bounded by a fixed operator
norm of `P`.  This retains the moving parameter `tau`; it does not apply
Roth to a target depending on `tau`.

Now let `theta_j=arg(kappa_j)` modulo `2 pi` for nonzero Gaussian integers
`kappa_j`, and put

```text
lambda_j = kappa_j       if r_j=+1,
lambda_j = bar(kappa_j)  if r_j=-1.                     (5)
```

Then (3) becomes

```text
arg(lambda_j)=tau+gamma_j+O_S(Delta),                  (6)
```

where every difference `gamma_j-gamma_h` belongs to a fixed finite set of
rational multiples of `pi`.  Consequently

```text
dist(arg(lambda_j bar(lambda_h)), T_(jh))
     <= 2L Delta                                      (7)
```

for a fixed finite target set `T_(jh) subset pi Q/2 pi Z`.  The common
moving angle has disappeared.

## 2. Directional reduction and its exact collision case

Call a Gaussian integer conjugate-primitive if
`gcd(kappa,bar(kappa))=1` up to units.  The property is unchanged by
conjugation.

For every nonzero `G in Z[i]`, there are a conjugate-primitive `A` and a
Gaussian unit `u` such that

```text
G/bar(G)=u A/bar(A),             Norm(A)<=Norm(G).       (8)
```

To see this, cancel the gcd ideal of `(G)` and `(bar(G))`.  That ideal is
stable under conjugation, so a generator and its conjugate are associates.
The reduced denominator is therefore a unit times the conjugate of the
reduced numerator, which proves (8).  In angle form, reduction changes
`arg(G)` only by a multiple of `pi/4`, modulo `pi`.  Enlarging the finite
target sets in (7) absorbs this change.

There is a particularly rigid unit case.

**Collision lemma.**  If `lambda` and `mu` are conjugate-primitive and the
directional reduction of `lambda bar(mu)` in (8) is a unit, then `lambda`
and `mu` are associates.

In fact the unit reduction says

```text
lambda bar(mu)=v bar(lambda) mu                         (9)
```

for a Gaussian unit `v`.  Since `lambda` is coprime to `bar(lambda)`,
Euclid's lemma in `Z[i]` gives `lambda | mu`.  Reversing the two variables
gives `mu | lambda`.  Thus they are associates.  This also rules out a
spurious exact `pi/4` rotation: multiplication by `1+i` would destroy
conjugate-primitivity.

## 3. Pairwise height cost

Assume now

```text
Delta <= C R^(-1/2),             product_j n_j <= R^2,
n_j=Norm(kappa_j),                R>=1,                 (10)
```

and every `kappa_j` under consideration is a conjugate-primitive nonunit.
Fix `epsilon>0`.  There are constants `a>0` and `R_0`, depending only on
`S,C,epsilon`, such that for every pair `j,h` with `lambda_j` and
`lambda_h` nonassociate,

```text
n_j n_h >= a R^(1/(2+epsilon))       for R>=R_0.        (11)
```

Apply (8) to `G=lambda_j bar(lambda_h)`.  By the collision lemma its
reduced numerator `A` is a nonunit.  Equation (7), with the finite unit
shift from (8), puts `arg(A)` within `O_S(C R^(-1/2))` of a fixed finite
set of rational multiples of `pi`.  The phase lemma in the fixed-Hadamard
note, which is an ordinary fixed-target application of Roth's theorem,
gives

```text
c |A|^(-2-epsilon) <= O_S(C R^(-1/2)).                 (12)
```

Therefore

```text
Norm(A) >= a R^(1/(2+epsilon)).                        (13)
```

Since `Norm(A)<=Norm(G)=n_j n_h`, (11) follows.  Notice that common prime
factors between different blocks cause no problem: directional reduction
removes them, and a complete collapse of the reduced height is exactly the
associate case isolated above.

## 4. Nine distinct directions force bounded radius

**Theorem.**  Fix `S` satisfying (1) and `C>0`.  There is an ineffective
constant `B(S,C)` such that any system (2), (10) with nine
conjugate-primitive nonunit blocks whose corresponding `lambda_j` are
pairwise nonassociate satisfies

```text
R <= B(S,C).                                             (14)
```

Choose nine such indices and multiply (11) over their `36` unordered
pairs.  Every selected norm occurs eight times, so

```text
(product_(j=1)^9 n_j)^8
   >= a^36 R^(36/(2+epsilon)).                          (15)
```

The product budget in (10) makes the left side at most `R^16`.  Choose
`0<epsilon<1/4`; then `36/(2+epsilon)>16`, contradicting (15) for all
sufficiently large `R`.  More generally, the same complete-graph
calculation for `q` pairwise nonassociate directions succeeds precisely
when one can choose `epsilon>0` with

```text
q/(2(2+epsilon))>2.                                    (16)
```

Thus `q=9` is the first integer reached by this pairwise Roth argument.
This is weaker than the five-block bound for separately isolable
coordinates because eliminating one common moving angle consumes two block
heights in every fixed-target approximation.

The statement applies in particular when the selected blocks have pairwise
disjoint Gaussian prime support: two nonunit conjugate-primitive blocks with
disjoint support cannot be associates.  Pairwise disjoint support is not
needed for (11); pairwise nonassociation is the exact hypothesis used.

This complete-graph calculation is also the rank-one specialization of the
fractional packing theorem in
[`coupled_block_roth_packing.md`](coupled_block_roth_packing.md): give every
edge of the complete graph on nine directions weight `1/8`.  Every coordinate
has load one and the total weight is `9/2>4`.  The direct argument above also
identifies precisely when a pair certificate reduces to a unit.

### 4.1 Whole-set primitivity removes the distinct-direction hypothesis

The nine pairwise nonassociate directions in the preceding theorem are not
needed when the entire normalized row set is primitive.

**Primitive rank-one-kernel theorem.**  Let `S in {+1,-1}^(m x k)` satisfy
(1), let all `k>=9` blocks be conjugate-primitive nonunits, and define the
normalized row products

```text
Z_i=product_j kappa_j^((1+S_ij)/2)
                    bar(kappa_j)^((1-S_ij)/2).          (17)
```

If `gcd_i Z_i=1` in `Z[i]`, up to units, then every system (2), (10) has
bounded `R`, with a generally ineffective bound depending only on `S,C`.
Shared Gaussian prime support and associate blocks are allowed.

To prove this, conjugate `kappa_j` and reverse column `j` of `S` whenever
`r_j=-1`.  This leaves every product `Z_i` unchanged and reduces (1) to
`ker(D)=Q 1`.  All rows of the new matrix therefore have one common number
`q` of plus signs.  Its row-difference span is the full hyperplane

```text
V={v in Q^k : sum_j v_j=0},                            (18)
```

so every pair difference `e_a-e_b` is a fixed phase certificate.

Partition the transformed blocks into associate classes.  Every class has
size at most both `q` and `k-q`.  Indeed, choose a split Gaussian prime `pi`
dividing the class.  Whole-set primitivity supplies one row with no `pi`
factor and one row with no `bar(pi)` factor.  In the first row every class
coordinate must select the conjugated block, while in the second every class
coordinate must select the unconjugated block.  Contributions from other
blocks have nonnegative valuations and cannot cancel these factors.  Hence

```text
size(class) <= min(q,k-q) <= floor(k/2).                (19)
```

Order the coordinates cyclically with each class contiguous.  If `k` is
odd, join position `i` to `i+(k-1)/2 mod k` and give every edge weight
`1/2`.  These edges form one cycle, every vertex has total load one, and no
edge stays in a contiguous class of size at most `(k-1)/2`.  If `k` is even,
pair each position with its antipode `i+k/2` and give every edge weight one.
Again every edge crosses associate classes and every vertex has load one.
In both cases the total edge weight is

```text
P=k/2>4.                                                (20)
```

The collision lemma makes every selected reduced pair product a nonunit.
The coupled-product packing theorem now bounds `R`.  Although the associate
partition and the displayed matching may depend on the blocks, there are
only finitely many partitions of the fixed coordinate set.  Taking the
maximum of their finitely many bounds gives one constant depending only on
`S,C`.

There is also a simpler mixed-unit case.  After the same column reversals,
if at least one block is a unit, projection of the hyperplane (18) onto the
nonunit coordinates is surjective: use one unit coordinate to make the total
coordinate sum zero.  Unit phases only enlarge the fixed torsion target set.
Thus every remaining nonunit coordinate is isolable, and five nonunit blocks
already give the bounded-radius conclusion of the fixed-Hadamard Roth note.

## 5. The normalized order-twelve Hadamard core

Let `H` be a normalized Hadamard matrix of order twelve, so its first row and
column consist of `+1`, and delete that row and column.  Write the resulting
`11 x 11` core as `S`.  Block multiplication in `H H^T=12I` gives

```text
S 1=-1,              S^T 1=-1,
S S^T=S^T S=12I-J.                                  (21)
```

Thus `S` is invertible and

```text
S^(-1)=(S^T-J)/12.                                   (22)
```

If `D` is its row-difference matrix, then `ker(D)=Q 1`: the equation
`Dx=0` makes `Sx` constant, and (21)--(22) make `x` a multiple of `1`.
Consequently the row-difference span is

```text
V={v in Q^11 : sum_j v_j=0}.                          (23)
```

It contains every pair difference `e_a-e_b` but no individual coordinate.
This is the promised no-isolable-coordinate example.

Every two core rows still have Hamming distance six, hence relative distance
`6/11`.  Thus the core survives the basic pair-distance screen that motivates
this profile; its exclusion below comes from the coupled phase arithmetic.

For complete concreteness one may take the Paley core indexed by
`x,y in F_11`:

```text
S_(x,x)=-1,
S_(x,y)=chi(x-y)  for x!=y,                           (24)
```

where `chi` is the quadratic character modulo eleven, whose nonzero square
set is `{1,3,4,5,9}`.  Formula (24) directly produces a normalized
Hadamard matrix after adjoining the all-`+1` row and column.

### 5.1 Exact pair targets

For `a!=b`, put

```text
lambda_(ab)=(e_a-e_b)S^T/12.                          (25)
```

Then `lambda_(ab) 1=0` and `lambda_(ab)S=e_a-e_b`.
Distinct core columns differ in six positions, so (25) has six nonzero
entries, each equal to `+1/6` or `-1/6`.  In particular

```text
||lambda_(ab)||_1=1.                                  (26)
```

Applying (25) to the lifted phase equation (2) shows

```text
dist(arg(kappa_a bar(kappa_b)), (pi/12)Z)
    <= Delta/2.                                       (27)
```

The integer lifts contribute multiples of `pi/3`; arbitrary independent
Gaussian row units contribute multiples of `pi/12`.  Thus the row units do
not enlarge the target beyond the fifteen-degree grid.

Reduce `kappa_a bar(kappa_b)` as in Section 2.  Because all blocks are
conjugate-primitive, its cancelled factor is an ordinary positive rational
integer, up to a Gaussian unit.  The remaining primitive direction `g_(ab)`
therefore still satisfies (27), since the grid is stable under unit
rotations.  It is a unit exactly when `kappa_a` and `kappa_b` are associates,
by the collision lemma.

### 5.2 Elementary separation on the fifteen-degree grid

Every conjugate-primitive nonunit `g=x+iy` satisfies

```text
dist(arg(g),(pi/12)Z) >= 1/(4 Norm(g)).                (28)
```

For a target line of irrational slope, choose the corresponding form from

```text
x^2+4xy+y^2,   x^2-4xy+y^2,
x^2-3y^2,      3x^2-y^2.                              (29)
```

The chosen integral form vanishes on that target line and does not vanish at
the nonzero integer pair `(x,y)`.  Its value therefore has absolute value at
least one.  After division by `x^2+y^2`, each form in (29), restricted to the
unit circle, has angular derivative of absolute value at most four.  The
mean value theorem gives (28).  For an axis or diagonal target, use one of
`x,y,x-y,x+y`.  Exact vanishing would put `g` on an axis, making it a unit,
or on a diagonal, making `1+i` divide both `g` and `bar(g)`.  Otherwise the
integer linear form has absolute value at least one, giving the stronger
bound `1/(sqrt(2 Norm(g)))`, and hence (28).

Combining (27)--(28) gives, for every nonassociate pair,

```text
Norm(g_(ab)) >= 1/(2 Delta),
n_a n_b      >= 1/(2 Delta).                           (30)
```

Under the endpoint assumption `Delta<=C R^(-1/2)`, the right side is at
least `sqrt(R)/(2C)`.  Unlike the Roth estimate (11), this bound is effective
and has no `epsilon` loss.

### 5.3 Primitive row content controls all associate collisions

Use the actual core products

```text
Z_i=product_j kappa_j^((1+S_ij)/2)
                    bar(kappa_j)^((1-S_ij)/2),
z_i=d u_i Z_i,               R=|d| product_j |kappa_j|. (31)
```

Assume all eleven `kappa_j` are conjugate-primitive nonunits and

```text
gcd_(i=1)^11 Z_i=1             in Z[i], up to units.    (32)
```

This is primitivity of the whole normalized row set; it does not require an
individual `Z_i` to be coprime to its own conjugate.  Partition the
coordinates into associate classes of the `kappa_j`.  Every class has size
at most five.

Indeed, fix a class, choose a Gaussian prime `pi` dividing one (and hence
every) member, and consider `bar(pi)`.  Condition (32) supplies a row `i`
with `v_(bar(pi))(Z_i)=0`.  Every coordinate in the class must have plus sign
in that row: a minus sign would make its conjugated block contribute
`bar(pi)`.  Factors from other blocks have nonnegative valuations and cannot
cancel it.  Each core row has exactly five plus signs by (21), so the class
has size at most five.

Arrange the eleven coordinates cyclically with each associate class
contiguous.  Join position `i` to position `i+5 mod 11`.  Since every class
has at most five positions, every one of these eleven edges joins distinct
classes.  The edges form an eleven-cycle: every vertex occurs twice.
Multiply (30) over the eleven edges and take a square root.  Using the radius
budget from (31) gives

```text
R^2 >= product_j n_j
    >= (1/(2 Delta))^(11/2).                           (33)
```

Therefore the angular span and physical arc length `L=R Delta` satisfy

```text
Delta >= (1/2) R^(-4/11),
L     >= (1/2) R^(7/11).                               (34)
```

**Effective core theorem.**  If the eleven points (31) lie on an arc of
length at most `C sqrt(R)`, all eleven blocks are conjugate-primitive
nonunits, and the normalized row products satisfy (32), then

```text
R <= (2C)^(22/3).                                      (35)
```

Indeed, compare the second inequality in (34) with `L<=C sqrt(R)`.
Different blocks may share Gaussian primes.  Whole-set primitivity is what
turns complete directional collapse into a class-size bound; no distinctness
or individual row-primitivity assumption is being substituted for it.

## 6. Why collisions cannot simply be omitted

Under only the hypotheses in (1), (2), and (10), no bounded-radius theorem
is possible, regardless of the number of nonunit coordinates.  Take a
conjugate-primitive Gaussian integer `kappa`, set

```text
kappa_j=kappa       if r_j=+1,
kappa_j=bar(kappa)  if r_j=-1.                         (36)
```

Then `theta=tau r`, where `tau=arg(kappa)`, and (1) gives
`S theta=tau S r`, a constant vector because `D r=0`.  Hence (2) holds
with zero error after a common phase adjustment.  Taking, for example,
`kappa=2N+i` supplies infinitely many conjugate-primitive choices.  With
unit common factor the natural radius is
`R=|kappa|^k`, so it is unbounded and the product identity is exact.

This family is completely collided.  All the `lambda_j` are associates;
moreover all row products have the same modulus and common phase up to a
Gaussian unit, so they yield at most four distinct lattice points.  It is
therefore harmless in an application that already requires enough distinct
row outputs, but that extra implication has to be proved from the particular
matrix and collision partition.  The phase equations alone do not provide
it.

For an arbitrary collision partition, (11) remains available between every
two distinct associate classes.  If the classes have sizes `s_a` and common
norms `N_a`, put `x_a=log(N_a)/log(R)`.  The pair inequalities include fixed
multiplicative constants, so before taking a limit their second line below
has an `O(1/log R)` error.  Along any unbounded subsequence on which the
exponents converge, the limiting feasibility problem is the elementary
linear system

```text
sum_a s_a x_a <= 2,
x_a+x_b >= 1/(2+epsilon)    (a!=b),
x_a>=0,                                               (37)
```

This records exactly what the relative Roth method proves at exponent level.
Additional row distinctness or block-support information may
exclude the feasible collision patterns, but neither Siegel's theorem nor a
genus computation is needed in the rank-one-kernel reduction itself.

The conclusion is scoped to a fixed matrix `S`.  All target sets and Roth
constants depend on its rational right inverse.  It gives no uniformity as
the matrix varies and makes no effective claim for `B(S,C)`.

The exact finite checks for the Paley core, its 55 pair isolators, the four
quadratic derivative bounds, and the cyclic class matchings are in
[`check_rank_one_kernel_relative_roth.py`](check_rank_one_kernel_relative_roth.py).
