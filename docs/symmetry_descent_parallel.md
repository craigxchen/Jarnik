# Integral orbits of rational circle reflections

This note studies compositions of the pair-bisector reflections from
`rational_reflection_route.md`. The endpoint uniform bound remains
unproved. The new result is an obstruction to a proposed proof mechanism:
even the **entire group** generated by the available reflections can have
exactly the original points as its integral orbit. This happens for
arbitrarily large actual Gaussian configurations with complete balanced
prime patterns. No short-arc assertion is made for these examples.

## 1. The full orbit is an affine multiplicative lattice

Let `z_1,...,z_m` be distinct nonzero Gaussian integers of common modulus
`R`, with `m>=3`, and put `N=R^2`. On the radius-`R` circle, the reflection
exchanging `z_i,z_j` is

```
sigma_ij(w) = (z_i z_j/N) conjugate(w) = z_i z_j/w.
```

The expression is defined also for antipodal anchors; it is the reflection
with the displayed coefficient. Let the group be generated by all these
reflections with distinct anchors. The orbit of any one initial point is
exactly

```
O = { product_i z_i^(c_i) : c_i in Z, sum_i c_i=1 }.       (1)
```

Indeed, reflection sends the exponent vector `c` to `e_i+e_j-c`, which
preserves the affine constraint. Conversely, for distinct `i,j`, choose a
third index `k`. The composition

```
sigma_ik sigma_jk(w) = (z_i/z_j) w
```

realizes every generator `e_i-e_j` of the zero-sum integer lattice.
Starting from any `e_j` therefore gives all vectors in (1). This argument
allows intermediate orbit points to be nonintegral. Requiring integrality
at every intermediate step can only shrink the available orbit.

## 2. Complete balanced patterns have no extra integral orbit points

Fix an even integer `m=2k>=4`. For every `k`-element subset `S` of
`{1,...,m}`, choose a different split rational prime
`p_S=pi_S conjugate(pi_S)` and a positive integer `e_S`. Set

```
z_i = product_(S containing i) pi_S^e_S
      product_(S not containing i) conjugate(pi_S)^e_S,
N = product_S p_S^e_S.
```

These are distinct Gaussian integers of norm `N`. Their common Gaussian
gcd is a unit, and every prime layer cuts the rows exactly in half.

For an affine integer vector `c` in (1), let

```
t_S = sum_(i in S) c_i.
```

The exponents at the two primes above `p_S` in the orbit point are
`e_S t_S` and `e_S(1-t_S)`. Consequently the orbit point is integral if
and only if

```
t_S in {0,1} for every k-element subset S.                 (2)
```

For any distinct indices `i,j`, take a `(k-1)`-element subset avoiding
both. The two resulting `k`-subset sums differ by `c_i-c_j`, so (2)
implies `|c_i-c_j|<=1`. All entries of `c` are therefore either one integer
`a` or `a+1`. Their sum is one. Since `m>=2`, this forces one entry to be
one and all the others to be zero. Thus

```
O intersect Z[i] = {z_1,...,z_m}.                          (3)
```

This controls arbitrarily long compositions, including compositions that
leave the lattice and subsequently return. It is stronger than checking
the domain of each individual reflection separately. The same proof
works with arbitrary Gaussian units attached to the initial points.

There is no conflict with the many other integral points on this circle:
those other points need not belong to the subgroup orbit generated by the
chosen points. Likewise, (3) does not assert that a short arc is already
saturated by the displayed points. Proving that shortness forces useful
additional points outside this orbit would be a genuinely additional
step.

## 3. A quantitative denominator barrier, independent of word length

Write an orbit point in relatively prime Gaussian numerator and
denominator form `w=A/d`. Put

```
phi(t) = max(-t,t-1,0) = dist(t,[0,1]),
w_S = e_S log p_S,
W = sum_S w_S = log N,
B = binom(m,k).
```

Unique factorization gives the exact identity

```
log |d|^2 = sum_S w_S phi(t_S).                           (4)
```

Suppose all cut weights satisfy `w_S >= (1-eta) W/B`, where
`0<=eta<1`. Every orbit point other than the original points then obeys

```
log |d|^2 >= (1-eta) m W/(4(m-1)),
|d| >= R^((1-eta)m/(4(m-1))).                            (5)
```

In particular, a nontrivial word cannot evade the barrier by being very
long.

Here is an elementary proof of the combinatorial estimate used in (5).
Define the symmetric convex function

```
F(c) = (1/B) sum_(|S|=k) phi(sum_(i in S) c_i).
```

Among integer vectors of sum one that are not coordinate vectors,
`F(c)` is minimized at a permutation of

```
v=(1,1,-1,0,...,0).                                      (6)
```

To see this, let `P` be the sum of the positive entries of `c`. A
non-coordinate vector has `P>=2`. While `P>2`, transfer one unit from
a positive entry to a negative entry. If those entries are `a,b`, their
difference is at least two, and the new vector is a convex combination
of the old vector and the vector obtained by swapping those entries:
the swap coefficient is `1/(a-b)`. Symmetry and convexity therefore
show that `F` does not increase. The transfer reduces `P` by one.

At `P=2`, the negative entries consist of one `-1`. The positive entries
are either two ones, giving (6), or one two. In the latter case, transfer
one unit from the two to a zero entry; such an entry exists for `m>=3`.
The same convexity argument gives (6) without increasing `F`.

For (6), the only nonzero contributions occur when the selected subset
contains both positive indices and excludes the negative one, or does
the reverse. Each contribution equals one, so

```
F(v) = [binom(m-3,k-2)+binom(m-3,k-1)] / binom(m,k)
     = binom(m-2,k-1) / binom(m,k)
     = m/(4(m-1)).                                      (7)
```

Equations (4) and (7) prove (5). A single third-point reflection has
coefficient vector of the form (6), so this denominator cost is already
attained by the shortest nontrivial operation in the equal-weight model.

Actual prime-power examples can have cut weights as close to equal as
desired: first fix distinct primes `p_S`, then take
`e_S=floor(T/log p_S)` for sufficiently large `T`. Every weight lies
between `T-log p_S` and `T`. Exact equal weights are not needed for (5).

As a finite arithmetic check of (7) and the minimization, integer vectors
with entries in `[-2,2]` were exhausted for `m=4,6`; those with entries in
`[-1,1]` were exhausted for `m=8`. The respective minimum averages were
`1/3`, `3/10`, and `2/7`, attained at (6). The proof above covers all
integer coefficients and all even `m>=4`.

## 4. Why clearing the denominator is not a free descent

If an integral configuration has angular width `Delta` and radius `R`,
its normalized arc width is `C_0=Delta sqrt(R)`. Multiplying all points
by a Gaussian denominator `d` preserves their angular differences but
changes the radius to `R|d|`. The new normalized width is exactly

```
C_0 sqrt(|d|).
```

For the profiles in Section 3, adding any new generated orbit point by
this procedure therefore costs at least

```
R^((1-eta)m/(8(m-1)))
```

in the normalized width of the original subconfiguration. A hypothesis
that its normalized width merely tends to zero, with no rate relative
to `R`, does not absorb this cost. The construction does not rule out a
different rescaling or a separate arithmetic descent; it identifies the
cost of this particular denominator-clearing operation.

## 5. Scope and remaining question

These are prose proofs, not Lean theorems. They do not improve the
growth rate of the lattice-point count. They show why the following
mechanism cannot be justified using balanced factor incidence alone:
start from a large cluster, compose its rational reflections, and force
additional integral points that violate the known short-arc rigidity.

The constructions use actual Gaussian integers and may have arbitrarily
many rows, but their angles are unconstrained. Thus they do not
disprove the desired uniform bound. To use reflection symmetry for that
bound, one must prove an additional statement exploiting the actual
small angles, or find a transformation outside this generated isometry
orbit with controlled integrality and radius cost. Neither statement is
established here.
