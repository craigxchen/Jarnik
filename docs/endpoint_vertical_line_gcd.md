# Endpoint cofactors on a vertical Gaussian line

## Scope

This note gives an exact pair-gcd formula and a resulting spread bound
for endpoint chords having one fixed ordinary content.  It does **not**
prove a uniform bound for lattice points on an arc of length
`C sqrt(R)`. The available upper bound for cotangent spread is too large
to contradict the estimate below, and a general cluster can have many
different chord contents.

## 1. Endpoint factorization

Let `P` and `Q_j` be distinct Gaussian integers of modulus `R`.  Write

```text
Q_j-P=d_j v_j,
d_j=gcd(|Re(Q_j-P)|,|Im(Q_j-P)|)>0,
```

so that `v_j` is primitive over the rational integers.  Equality of the
two norms gives the exact factorization

```text
2P=v_j w_j,                 w_j=-d_j+i t_j in Z[i].       (1)
```

On a one-sided endpoint arc of angular length less than pi we may orient
the picture so that `t_j>0`.
If `theta_j` is the angular distance from `P` to `Q_j`, then

```text
theta_j=2 arctan(d_j/t_j).                               (2)
```

Thus an arc of length at most `C sqrt(R)` gives, when
`C/(2 sqrt(R))<=1`,

```text
t_j >= d_j cot(C/(2 sqrt(R))) >= d_j sqrt(R)/C.          (3)
```

The last inequality uses `tan x<=2x` for `0<=x<=1`.

## 2. Exact gcd on one vertical line

Fix `d>0`, put

```text
w_i=-d+i t_i,       w_j=-d+i t_j,       delta=t_j-t_i !=0.
```

Then

```text
N(gcd_G(w_i,w_j))
 =gcd(delta^2, delta d, delta t_i, d^2+t_i^2).           (4)
```

Indeed,

```text
(w_i,w_j)=(w_i,w_j-w_i)=(w_i,i delta)=(w_i,delta).
```

As a rank-two integer lattice, the last ideal is generated by the four
columns corresponding to `delta`, `i delta`, `w_i`, and `i w_i`:

```text
(delta,0), (0,delta), (-d,t_i), (-t_i,-d).
```

Its index is the gcd of the absolute values of all two-by-two minors.
Those minors are, up to signs and repetitions,

```text
delta^2, delta d, delta t_i, d^2+t_i^2.
```

Since `Z[i]` is principal, this index is the norm of a Gaussian gcd,
which proves (4).  In particular,

```text
N(gcd_G(w_i,w_j))
 <= |delta| gcd(|delta|,d,|t_i|)
 <= |delta| min(d,|delta|),

|gcd_G(w_i,w_j)|
 <= sqrt(|t_j-t_i| min(d,|t_j-t_i|))
 <= sqrt(d |t_j-t_i|).                                  (5)
```

Thus (5) retains both the immediate difference bound and an additional
square-root bound that is sharper when `d<|t_j-t_i|`.

## 3. A same-content cotangent-spread lemma

Suppose `k>=2` endpoint chords all have content `d`, and let their
distinct cotangent integers be `t_1,...,t_k>0`.  Set

```text
K=k(k-1)/2.
```

If all `t_j` lie in `[T,T+H]`, then

```text
2R >= product_j sqrt(d^2+t_j^2)
      /(d^(K/2) product_(i<j)|t_i-t_j|^(1/2)),          (6)
```

and hence

```text
H >= (T^k/(2R d^(K/2)))^(2/K).                         (7)
```

To prove (6), let `L=lcm_G(w_1,...,w_k)`.  Equation (1) gives
`L|2P`, so `|L|<=2R`.  Prime by prime,

```text
max_j e_j >= sum_j e_j-sum_(i<j) min(e_i,e_j),
```

and therefore

```text
|L| >= product_j |w_j|/product_(i<j)|gcd_G(w_i,w_j)|.
```

Now apply (5), `|w_j|>=T`, and `|t_i-t_j|<=H`.

Combining (3) and (7) yields the explicit critical-scale consequence

```text
H >= 2^(-2/K) C^(-2k/K) d^(2k/K-1)
     R^((k-2)/K).                                      (8)
```

For three same-content chords this is

```text
H >= 2^(-2/3) C^(-2) d R^(1/3).                       (9)
```

Thus three such cofactors cannot remain in a vertical interval of width
`o_C(d R^(1/3))`.

## 4. The full tuple reconstructs the radius up to the factor two

The following statement allows the contents `d_j` to vary.  Suppose the
whole anchored tuple

```text
P,Q_1,...,Q_m
```

has Gaussian gcd one.  With `w_j` and `v_j` as in (1), put

```text
L=lcm_G(w_j),       G=gcd_G(v_j).
```

Valuations in `v_j=2P/w_j` give

```text
G=2P/L                                                   (10)
```

up to a Gaussian unit.  Moreover `G|2`.  To see this, if a Gaussian
prime `pi` occurred in `G` to order greater than `v_pi(2)`, then
`G|2P` would imply `pi|P`.  Since `pi|v_j` for every `j`, equation
`Q_j=P+d_jv_j` would then imply `pi|Q_j` for every `j`, contrary to
primitivity of the tuple.  Consequently

```text
R <= |L| <= 2R.                                        (11)
```

This is an anchored reconstruction statement for the complete tuple.
It need not hold for a selected same-content subfamily, because taking a
subset can introduce a new common Gaussian divisor.

## 5. What remains missing

Formula (5) uses the vertical-line structure, but (6) still pays one gcd
cost for every pair: its denominator has `K` factors while its numerator
has only `k`.  The exponent of `R` in (8) is

```text
(k-2)/K=2(k-2)/(k(k-1)),
```

which tends to zero with `k`. Equation (1) and `|v_j|>=1` do give
`t_j<=2R`, hence `H<=2R`, but this does not contradict (8). The arc
hypothesis gives a lower bound for `t_j`; it does not force all these
integers into an interval of size `O_C(d sqrt(R))`. A uniform proof
along this route would need a sharper
simultaneous gcd-accumulation estimate than the pairwise lcm inequality,
as well as a mechanism coupling the different contents `d_j`.

The exact identities and finite checks are in
[`check_endpoint_vertical_line_gcd.py`](check_endpoint_vertical_line_gcd.py).
