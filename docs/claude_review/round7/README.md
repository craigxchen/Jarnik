# Round 7: factored residue data (draft, refereeing in progress)

`p3lower.md` is an unrefereed draft; its referee and the remaining round-7 tasks are running. Main
claim: the pair channel is a cut LP, `2 lambda_max(D) <= W_cut(D) <= pi lambda_max(D)` for pair demands
`D`. So non-uniform margins absorb heavy-tailed pair demands at real weights, and no pair-cut
certificate can prove growth in P3-all. The only growth statement is conditional on near-uniform
margins and a Poisson-type Hypothesis H.
