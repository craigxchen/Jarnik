# L5: the twin channel — write-up (round 9)

Status: DRAFT, unrefereed. Task: decide L5 (`round7/README.md` §3; `round7/p3Dlower.md` Thm 2.1, §5.2
(M1'), open points 2 and 4). Scripts: `L5_checks/` (outputs `*_out.txt`). The repository was not modified.

## 0. Summary of results

**L5 is not decided.** No construction and no obstruction in the generality asked for is proved. No
growth statement is proved or claimed. What is proved:

1. **Precise form (§1).** L5 is stated with all quantifiers: (F) ideal free labels, (T) twin channel,
   (P) pair code, demands weighted by `log q`. The pair condition concerns **unit-1** collisions only
   (Remark 1.1); the unweighted reading "all but `O(||w||_1 + 1)` moduli" is false for every system (`q = 3, 5`).
   (F), (T), (P) hold for near-extremal actual clusters with a twin profile and margins `O(log M)`, so L5 is a
   growth statement for that subclass, and it ignores the angles.
2. **Exact reformulations (§2, proved).** (T) is the statement that each point class `kappa_y` avoids, in
   the weighted sense, a dense translate `<phi_y, f>` of the sparse sumset of the free labels (Prop. 2.1); L5
   is a statement about a product set `{f} x {kappa}` (Prop. 2.2). **Class-mate transfer** (Prop. 2.3): if
   `kappa_x = kappa_y` at `q^a`, the twin monomials of `y` there have exactly the collisions of the twin monomials
   of `x` translated by the dense pair vector `a_x - a_y`. At every `q` with `n_q << M` most rows have a
   class-mate (Cor. 2.4), so there (T) is a statement about **dense** monomials.
3. **No single-modulus argument proves L5 (Lemma 3.1, proved).** At any `q` with
   `n_q > M - 1 + 4|V|`, any `|V|` twin monomials per row can be avoided while the point code stays injective.
4. **Localisation (Thm 3.2, Cor. 3.3; proved conditionally on ideal systems).** If an ideal system (the
   hypothetical object of L4) with `t` spread candidates per row exists at the moduli `n_q >= cM`, then there
   the twin channel and the pair code are satisfied **simultaneously** (no pair collision at all, (T) with
   constant `t beta_0 (1 + 2c_0)`), by switching each twin label among `t` ideal candidates. So, under this
   hypothesis, L5 holds iff it holds on the moduli `q < 2cM + 1`, the range where (P) forces collisions. The Hall condition needed is
   generic (Lemma 3.4: `c = 2, t = 5` or `c = 1.1, t = 30`, failure probability `<= 1.5/n_q`). For the task's
   moduli `q <= 3M` this range is essentially everything (Remark 3.5); for `X = 3M^A`, `A > 1`, it removes
   the moduli `(2cM, 3M^A]` from the random-rate heuristic. The same switching, done with one common index
   per modulus, localises the strengthened lemma L5+ (all `||c'||_1 <= k`, which membership in P3-all\*
   needs) to `q <~ M^(2+eps)` (Cor. 3.6); we recommend that the route use L5+.
5. **The obstruction form of open point 2 (§4.2).** At medium moduli, for every row that shares its
   class (most rows when `n_q << M`), it is by Prop. 2.3 exactly a tail statement for **dense translates**
   `(phi_x - phi_y) + w` of the free system, for the pairs that the pair code makes collide (an L7 /
   Hypothesis-H type input); at large moduli it is false under IFL. Neither
   input is known. Lemma 3.1 rules out counting proofs. Heuristically, switching cannot be pushed into the
   medium range (Remark 4.3: random lists admit no pair design at fixed `t`).
6. **The twin channel and the pairs cannot both be certified (Thm 4.1, Cor. 4.2; proved).** A volume (singular-value)
   inequality valid for **every** profile: in a coherent design with multiplicatively independent columns,
   `sum_x log ||G(a_x - a_(x_0))|| >= (1/2) log det Gram_A - (1/2) log binom(r, M-1) - (r - M + 1) log B`. On the
   Paley twin profile (`det Gram_A >= ((b-24)M/4)^(M-1)`), certifying (F) and (T) by heights forces pair heights
   of geometric mean `>= M^(1/2)/(C log M)^(b-1)`: (P) can then hold only through smooth parts of dense
   Gaussian integers. This extends the dichotomy of `p3Dconstruct.md` Thm 2 to general profiles (in a weaker
   quantitative form).
7. **Open point 4 (§5; proved).** (i) Non-twin profiles with a unimodular minor (more generally, every
   profile at moduli with `gcd(Delta_M(A), m_Q/2) = 1`) decouple exactly as twin profiles (Thm 5.1). (ii) The
   twin *localisation* needs an integral section of bounded row norm; the interface `c'(v) = s^T v` is
   otherwise not sparse and the mechanism of L5 has no direct analogue (Prop. 5.2); evidence: random
   0/1 profiles have unimodular minors but sections of norm up to `~ 500` at `M = 16`. (iii) Without a
   unimodular minor, `kappa` is confined to `A(Z/n)^r ⊇ d_M (Z/n)^M`, which forces pair collisions only where
   `n_q < M gcd(d_M, n_q)` (Prop. 5.3), and cannot help a construction; Hadamard cores have `d_M = M/2`.

**Verdict on the target.** The twin channel is neither shown to obstruct nor shown to be free. The
precise residual problem is `L5_med`: at the moduli `q < 2cM` where the pair code must be a design, show
that the dense translates (Prop. 2.3) of every ideal free system have unbounded sparse agreement for some
row, or build an ideal system whose dense pair translates are controlled. Certified systems cannot do the
latter (Thm 4.1), random ones cannot (Poisson), and additive twin labels fail the height condition
for monomials with `||c'||_1 >= 2` (Siegel).

## 1. Setting and precise statement of L5

**Conventions** (those of `round7/p3Dlower.md` §2 and `sharp.md` Def. 1.1, Cor. 2.2).
* *Twin profile.* `A = (a_xj) in {0,1}^(M x r)` (`e = 1`). For every row `x` there are columns
  `f(x), s(x)` with `a_(.,f(x)) - a_(.,s(x)) = eps_x e_x`, `eps_x = +-1`, all `2M` of them distinct.
  `J` is the set of the other `r - 2M` columns, `n := r - M`, and `sigma_(yx) := a_(y,s(x))`.
* *Moduli.* `q` runs over the odd primes `q <= X = 3 M^A` not dividing `N`; `Q = q^(A_q)` is the top
  power, `m = m_Q`, `iota = log_g i`, and `T := (m/4) Z/m = {0, iota, 2 iota, 3 iota}` (the logs of
  `mu_4`). At level `a` the same objects are reduced mod `m_(q^a)`. Put `n_q := m_q/2`.
* *Data.* At each `q` a parity-respecting label vector `ell(q) in (Z/m_Q)^r`,
  `ell_j = nu_j(q) mod 2`. **Data at different primes `q` are independent**: by `sharp.md` Cor. 2.2(1)
  nothing links them (levels of one `q` are reductions of the top level).
* *Twin coordinates* (`p3Dlower.md` Thm 2.1). `f := (ell_J, U) in (Z/m)^n` with
  `U_x = ell_(f(x)) + ell_(s(x))` (the **free labels**); `Lambda_x := eps_x ell_(f(x))` (the **twin labels**);
  `phi_y := (a_(yJ), (sigma_(yx))_x) in {0,1}^n`; `F_y := <phi_y, f>`; point classes
  `kappa_y = <a_y, ell> = F_y + Lambda_y` (windings `k = 0`; a winding shifts `kappa_y` by a fixed
  element and changes nothing below). A monomial `v in Z^r` corresponds to `vt = (w, c')`,
  `w = (v_J, v_s) in Z^n`, `c'_x = eps_x (v_(f(x)) - v_(s(x)))`, and
  `<v, ell> = <w, f> + <c', Lambda>` at every level (`p3Dlower.md` (2.2)); `||vt||_1 <= 2||v||_1` and
  `||v||_1 <= 2||vt||_1`.
* *Collisions and demands.* `v` collides at `q^a` with unit `i^s` iff `<v, ell> = s iota mod m_(q^a)`;
  `a_(q,s)(v)` is the largest such `a <= A_q`; the **per-unit demand** is
  `delta_s(v) := log m_(v,s) = sum_q a_(q,s)(v) log q`. Write `delta_s(w, c')` for the demand of the
  monomial with twin coordinates `(w, c')`.
* *Pairs.* `b_q(x,y)` is the largest `a <= A_q` with `kappa_x = kappa_y mod m_(q^a)`, and the **unit-1
  pair demand** is `delta(x,y) := log m_xy = sum_q b_q(x,y) log q`.

**Remark 1.1 (only unit 1 matters for pairs).** For a pair character `c = e_x - e_y` and a unit
`eta != 1`, condition (1.1) of `sharp.md` reads
`|sin((delta_x - delta_y - arg eta)/2)| >= 2^(-1/2) m_(c,eta) e^(-d_xy/2)`. Since `|delta_x - delta_y| <= Delta`
and `arg eta in {pi/2, pi, 3pi/2}`, the left side is `>= sin(pi/4) - Delta/2`, so the condition holds
whenever `log m_(c,eta) <= d_xy/2 - O(Delta)`, and `d_xy >= W/2` (margins are nonnegative). This budget is of
order `W`, not `log M`. So the near-uniform-margin requirement `O(log M)` concerns the unit-1 demand
`delta(x, y)` only; that is how (P) below is stated. For actual clusters, `m_xy` divides the reduced
chord `beta_xy`, and `mu_xy = log(|beta_xy|^2/t_xy^2)` with `t_xy in (0, C]` gives
`2 delta(x,y) <= mu_xy + 2 log C`.

**Definition 1.2 (the three conditions).** Fix `A >= 1`, `beta, K > 0`, a ratio `rho >= 2` and a
range `k_max = k_max(M) >= 1`. Twin data (a twin profile with `r <= rho M`, and labels at all `q <= X`)
satisfy
* **(F)** *(ideal free labels)* `delta_s(w, 0) <= beta ||w||_1 log M` for all `0 != w in Z^n` with
  `||w||_1 <= k_max` and all `s`;
* **(T)** *(twin channel)* `delta_s(w, eps e_y) <= beta (||w||_1 + 1) log M` for all `y`, `eps = +-1`,
  `w in Z^n` with `||w||_1 <= k_max`, and all `s`;
* **(P)** *(pair code)* `delta(x, y) <= K log M` for all `x != y`.

**Statement L5** (`round7/README.md` §3, `p3Dlower.md` §5.2 (M1') and open point 2, made precise).
*For all `A, beta, K, rho` there is `M_0` such that for `M >= M_0` (and `k_max >= 1`) no twin data satisfy
(F), (T) and (P) simultaneously.*

Remarks.
1. The README words (i) as "avoid, at all but `O(||w||_1 + 1)` moduli". Counted without the weights
   `log q` this is false for every system: at `q = 3` and `q = 5` one has `m_q = 4`, so
   `T = Z/m_q` and **every** monomial collides with some unit; and at every `q` with `m_q/4 < |V|`,
   two members of any family `V` have values congruent mod `T`, so their difference collides
   (pigeonhole). The weighted form above is the height condition of P3-all\* (`sharp.md` Prop. 6.1) at
   `tau = Theta(log M)`, which is what the route needs.
2. Monomials with `||c'||_1 = 1` are never in the character lattice `L` (there `c' = c` with
   `sum c = 0`, so `||c'||_1 >= 2`). So (T) is a genuine height condition for every `w`.
3. **(F), (T), (P) are necessary for actual near-extremal clusters with near-uniform margins and a
   twin profile** (so L5 cannot be refuted by actual clusters unless growth fails for them). By
   `round8/stability.md` Cor. 3.6(1), under `H(eps)` every prime of `N` is `<= M^(4/eps - 3 + o(1))`.
   Genuine labels satisfy `m_(v,s) | D_s(prod pi_j^(v_j))`, so
   `delta_s(v) <= w(v)/2 + (log 2)/2 <= (||v||_1/2) max_j log p_j + 1`; with `||v||_1 <= 2||vt||_1` this
   gives (F) and (T) with `beta = 4/eps + o(1)`. Remark 1.1 gives (P) from `mu_xy <= K' log M`.
   So L5 would exclude near-extremal twin-profile actual clusters with near-uniform margins: L5 is a
   growth statement for that subclass, and it ignores the angles entirely.
4. L5 concerns only `||c'||_1 <= 1`. Membership in P3-all\* also needs the height condition for
   sparse monomials with `||c'||_1 >= 2`; these are not part of L5 (see Remark 3.5).

## 2. Exact reformulations of the twin channel

All statements of this section are identities about factored residue data on twin profiles. They
hold for every member of P3-all\* on a twin profile, in particular for actual clusters with a twin
profile (genuine labels). *Class: proved.*

**Proposition 2.1 (translate form of (T)).** For every `q`, level `a <= A_q`, unit `s`, row `y`,
sign `eps` and `w in Z^n`:

```text
(w, eps e_y) collides at q^a with unit i^s    <=>    kappa_y = <phi_y - eps w, f> + eps s iota   (mod m_(q^a)).      (2.1)
```

*Proof.* `<w, f> + eps Lambda_y = <w, f> + eps (kappa_y - <phi_y, f>)`. This equals `s iota` iff
`eps kappa_y = s iota - <w, f> + eps <phi_y, f>`; multiply by `eps` (`eps^2 = 1`). QED

So (T) says exactly: *each coordinate `kappa_y` of the point code avoids, in the `log q`-weighted
sense, the translate of the sparse sumset `{-eps <w, f> + T : ||w||_1 <= k}` by the dense combination
`F_y = <phi_y, f>`.* This is the "point code translated by a dense combination" of `p3Dlower.md` open
point 2, written without loss.

**Proposition 2.2 (the product structure).** For every `q`, the map `ell(q) -> (f(q), kappa(q))` is a
bijection from parity-respecting label vectors onto the pairs `(f, kappa)` with `f` parity-respecting
(parities `nu_J`, `nu_(f(x)) + nu_(s(x))`) and `kappa_y = F_y + nu_(f(y)) mod 2` for all `y`.
Consequently L5 is equivalent to: *for every free system `f` satisfying (F), no `kappa` in the
parity coset satisfies (T) and (P).*

*Proof.* `p3Dlower.md` Thm 2.1(1),(4): `(ell_J, U, Lambda)` are coordinates, and `Lambda = kappa - F`.
Since data at different `q` are independent, the choice of `f` and of `kappa` can be made modulus
by modulus. QED

**Proposition 2.3 (class-mate transfer).** Suppose `kappa_x = kappa_y mod m_(q^a)` (the pair `(x, y)`
collides with unit 1 at `q^a`). Then for every `w`, `eps`, `s`:

```text
(w, eps e_y) collides at q^a with unit i^s    <=>    (w + eps (phi_x - phi_y), eps e_x) collides at q^a with unit i^s.   (2.2)
```

In original coordinates: the twin coordinates of `a_x` are `(phi_x, e_x)`, so the right-hand
monomial is the left-hand one plus `eps (a_x - a_y)`, a dense vector of `L`.

*Proof.* `<w, f> + eps Lambda_y = <w, f> + eps (kappa_x - F_y) = <w + eps(phi_x - phi_y), f> + eps Lambda_x`
mod `m_(q^a)`. The twin coordinates of `a_x` are `w = (a_(xJ), (a_(x,s(z)))_z) = phi_x` and
`c'_z = eps_z (a_(x,f(z)) - a_(x,s(z))) = eps_z^2 delta_(xz)`. QED

**Corollary 2.4 (at small moduli, (T) is a statement about dense monomials).** Fix `q` and let
`D_q` be the set of rows `y` whose value `kappa_y(q)` is shared with another row. Rows of different
`sigma_q`-parity never share a value, and a parity class of `Z/m_q` has `n_q` elements, so at most
`2 n_q` rows are alone and `|D_q| >= M - 2 n_q`. For each `y in D_q` with a class-mate `x`, the
collision pattern at level 1 of **every** twin monomial of `y` coincides with that of a twin monomial of
`x` whose free part is `w + eps(phi_x - phi_y)`, where `||phi_x - phi_y||_1 >= (||a_x - a_y||_1 - 4)/2`.
On every profile of the class (margins `d_xy >= W/2`), and with column weights within a bounded factor of
each other, this is `>= c r`: the translate is dense.

*Proof.* Prop. 2.3 with `a = 1`. For the norm, put `v = a_x - a_y`. For `z != x, y` the twin relation
gives `a_(u,f(z)) = a_(u,s(z))` for `u in {x, y}`, so `v_(f(z)) = v_(s(z))`. Hence
`||v||_1 <= ||v_J||_1 + 2 sum_(z != x,y) |v_(s(z))| + 4 <= 2 ||(v_J, v_s)||_1 + 4`, and
`(v_J, v_s) = phi_x - phi_y`. QED

**Lemma 2.5 (gluing over moduli).** Let the odd primes `q <= X` be split into disjoint sets
`Q_1, Q_2`. Demands are sums over `q`, and data at different `q` are independent. Hence if data `D_i`
on `Q_i` satisfy (F), (T), (P) restricted to `Q_i` with constants `(beta_i, K_i)` (the same profile and
`k_max`), the glued data satisfy (F), (T), (P) with `(beta_1 + beta_2, K_1 + K_2)`. Conversely,
restricting data to `Q_i` preserves each condition. *Proof.* Immediate. QED

*Reading.* Prop. 2.2 shows that L5 is a statement about a **product** set: the free system and the
point code are chosen independently, and the twin labels are their difference. Prop. 2.3 shows how (P)
and (T) interact: only through collisions, and a collision of `(x, y)` at `q` identifies the twin
monomials of `y` with **dense** monomials (pair vector plus sparse vector) of `x`. By Cor. 2.4 this
happens for most rows at every `q` with `n_q << M`, which is where (P) forces collisions. The next
section shows that at the other moduli the twin channel is no obstruction at all, given ideal systems.

## 3. Localisation: L5 lives on the moduli `q <= 2cM + 1` where pair collisions are forced

### 3.1 No single-modulus argument proves L5

**Lemma 3.1 (per-modulus freedom of the twin channel).** Fix `q`, any parity-respecting free labels
`f(q)`, and for each row `y` a family `V_y` of pairs `(w, eps)`. If `n_q > (M - 1) + 4 max_y |V_y|`, there
is a parity-compatible `kappa(q)` such that
* `kappa(q)` is injective on each `sigma_q`-parity class, so no pair collides at `q` at any level; and
* no twin monomial `(w, eps e_y)` with `(w, eps) in V_y` collides at `q` (at any level, with any unit).

*Proof.* A collision at level `a >= 1` implies one at level 1, so it suffices to choose the level-1
values `kappa_y mod m_q` and lift them arbitrarily within the parity coset (reduction `Z/m_Q -> Z/m_q`
preserves parity, both moduli being even). Treat the rows one by one. The admissible level-1 values of
`kappa_y` form a parity class of `n_q` elements. Forbid the at most `M - 1` values already used and, for
each `(w, eps) in V_y`, the at most 4 elements of `<phi_y - eps w, f> + T` (Prop. 2.1). Something remains.
QED

This is the twin-channel analogue of `p3Dlower.md` Lemma 5.1, now with (P) kept at the same modulus.
A proof of L5 therefore cannot come from any one modulus, nor from counting per modulus: it must
show **concentration across moduli** (some `(y, w)` hit at many `q`), exactly as for the free labels.

### 3.2 Large moduli carry no information, given ideal systems

Fix `c > 1`. Put `Q_large(c) = {q <= X : n_q >= cM}` and `Q_med(c) = {q <= X : n_q < cM}`. Since
`n_q >= (q - 1)/2`, every `q in Q_med(c)` satisfies `q < 2cM + 1`.

**Hypothesis IFL(beta_0, t, c_0) on `Q_large(c)`** (ideal systems, in the sense of L4, with spread
candidates). There are, for every `q in Q_large(c)`, parity-respecting data `(f(q), lambda(q))`
(`lambda_y` of parity `nu_(f(y))(q)`), and for each row `y` a fixed set
`S_y = {w_0^(y) = 0, w_1^(y), ..., w_(t-1)^(y)} ⊂ Z^n` with `||w_i^(y)||_1 <= c_0`, such that:
* (a) on `Q_large(c)`, `f` satisfies (F) with `beta_0`, and the twin system `Lambda := lambda` satisfies
  (T) with `beta_0` for all `||w||_1 <= k_max + 2 c_0`;
* (b) *(Hall)* for every `q in Q_large(c)`, every set `Y` of rows of one `sigma_q`-parity class has
  `|union_(y in Y) C_y(q)| >= |Y|`, where `C_y(q) = {F_y + lambda_y - 2 <w, f(q)> : w in S_y} mod m_q`.

**Theorem 3.2 (large moduli are free).** Under IFL(beta_0, t, c_0) on `Q_large(c)` there are data on
`Q_large(c)` with free labels `f`, satisfying (F) with `beta_0`, (T) with
`beta = t beta_0 (1 + 2 c_0)`, and with **zero** pair demand at every `q in Q_large(c)`.

*Proof.* At each `q in Q_large(c)`, Hall's marriage theorem, applied to each parity class, gives
indices `i(y, q)` such that the values `F_y + lambda_y - 2 <w_(i(y,q))^(y), f>` are pairwise distinct
mod `m_q` within each parity class. Put `Lambda_y(q) := lambda_y(q) - 2 <w_(i(y,q))^(y), f(q)>`. Its parity is
that of `lambda_y`, so the data are parity-respecting (Prop. 2.2), and `kappa_y = F_y + Lambda_y` is injective
mod `m_q` on each parity class: no pair collides at `q` at any level.
For (T): at `q`, with `i = i(y, q)`,
`<w, f> + eps Lambda_y = <w - 2 eps w_i^(y), f> + eps lambda_y`, which is the value of the twin monomial
`(w - 2 eps w_i^(y), eps e_y)` of the system `(f, lambda)`. Hence for every level and unit,
`a_(q,s)(w, eps e_y) <= sum_(i < t) a^lambda_(q,s)(w - 2 eps w_i^(y), eps e_y)`, and summing over `q`,

```text
delta_s(w, eps e_y)  <=  sum_(i<t) beta_0 (||w||_1 + 2 c_0 + 1) log M  <=  t beta_0 (1 + 2 c_0) (||w||_1 + 1) log M.
```

(F) is untouched since `f` is unchanged. QED

**Corollary 3.3 (localisation of L5).** Let `L5_med(c)` be the statement L5 with (F), (T), (P) restricted
to the moduli in `Q_med(c)`.
1. `L5_med(c)` implies L5 (unconditionally).
2. On every twin profile carrying IFL(beta_0, t, c_0) on `Q_large(c)` with constants independent of `M`,
   good data exist for all moduli iff good data exist for the moduli in `Q_med(c)` (with constants
   changed by `beta_0 t (1 + 2 c_0)`). So, on such profiles, L5 holds iff `L5_med(c)` holds.

*Proof.* (1) Restriction preserves each condition (Lemma 2.5). (2) Glue data on `Q_med(c)` with the data
of Theorem 3.2 on `Q_large(c)`; the free labels may differ between the two ranges because data at
different primes are independent (Lemma 2.5). QED

**Lemma 3.4 (Hall is generic).** Let `n >= cM`, `t >= 2` and `c^(t-1) >= 2 e^2`. Suppose each of at
most `M` rows has `t` candidates drawn independently and uniformly from an `n`-set, independently over
rows. Then Hall's condition fails with probability `<= 1.5/n`. Examples: `c = 2, t = 5`; `c = 1.5, t = 8`;
`c = 1.1, t = 30`.

*Proof.* A failure gives a set `Y` of `s >= 2` rows (one row always has a candidate) and a set of `s - 1`
values containing all `ts` candidates of `Y`. So the probability is at most
`sum_(s=2)^M binom(M, s) binom(n, s-1) ((s-1)/n)^(ts)`. With `binom(M,s) <= (eM/s)^s` and
`binom(n, s-1) <= (en/(s-1))^(s-1)`, the `s`-th term is at most
`e^(2s) M^s s^(-s) s^(ts - s + 1) n^(-(t-1)s - 1) = (e^2 M s^(t-2) n^(-(t-1)))^s (s/n)`. Since
`s <= M <= n/c`, the bracket is `<= e^2 c^(-(t-1)) <= 1/2`, and `sum_(s>=2) s 2^(-s)/n = 1.5/n`. QED

*Status.* Theorem 3.2 and Corollary 3.3 are proved, **conditional on IFL**, whose part (a) is exactly
the hypothetical object of L4 (an ideal, uncertified system), and whose part (b) holds with probability
`>= 1 - 1.5/n_q` per modulus in the random-candidate model (Lemma 3.4; *model*). For coherent systems,
(b) is a statement about coincidences of dense Gaussian integers mod `q` and is not proved.

**Remark 3.5 (what the localisation means for the rate).**
* For the task's moduli `q <= 3M` (`A = 1`), `Q_large(c)` is contained in `(2cM - 1, 3M]` (empty for
  `c > 3/2 + 1/(2M)`). Its reciprocal mass `sum 1/q ~ log(log 3M/log 2cM) = O(1/log M)` is negligible. So for
  `A = 1` the whole Poisson window `(M^(1-eta), 3M]` of the random-rate heuristic is medium: L5 is a
  statement about the moduli where (P) **forces** collisions (Cor. 2.4).
* For `A > 1`, Theorem 3.2 removes `(2cM, 3M^A]`, which carries reciprocal mass `log A + o(1)`: under
  IFL, the part of the random-rate heuristic coming from these moduli is not a property of the twin
  channel.
* *Common switching (all monomials).* Suppose `(f, lambda)` is ideal for **all** sparse monomials `(w, c')`
  (an ideal system on all `r` columns), and at a modulus one index `i(q)` serves all rows at once
  (`Lambda_y = lambda_y - 2 <w_(i(q))^(y), f>` for every `y`) and makes `kappa` injective, then every sparse
  monomial `(w, c')`, whatever `||c'||_1`, takes the value of `(w - 2 sum_y c'_y w_i^(y), c')` in the system
  `(f, lambda)`, of norm `<= ||w||_1 + (2c_0 + 1)||c'||_1`, so its demand grows by a factor `<= t (1 + 2c_0)` only. A random system is injective at
  `q` with probability `>= 1 - M^2/(2 n_q)` (union bound over pairs), so in the random-candidate model
  this is available with `t = O(1)` options only at `q >= M^(2 + eps)`. With per-row switching
  (Theorem 3.2) a monomial with `||c'||_1 = k` is bounded only by a sum over `t^k` patterns, so Theorem 3.2 says nothing about the height condition for `||c'||_1 >= 2`.
  It concerns L5 as stated.

**Corollary 3.6 (the strengthened lemma L5+).** Let L5+ be L5 with (T) replaced by the height
condition `delta_s(w, c') <= beta (||w||_1 + ||c'||_1) log M` for **all** `c' != 0` with `||c'||_1 <= k_max`
not in `L` (this is what membership in P3-all\* needs). Suppose that on `Q_huge = {q : n_q >= M^(2+eps)}`
there are `(f, lambda)` ideal for all sparse monomials with constant `beta_0`, row sets `S_y` as in IFL, and at
each `q in Q_huge` an index `i(q)` for which `kappa_y = F_y + lambda_y - 2 <w_(i(q))^(y), f>` is injective
(in the random-candidate model this fails with probability `<= (M^2/(2 n_q))^t`). Then L5+ holds iff it
holds on the moduli `n_q < M^(2+eps)`. *Proof.* Common switching (Remark 3.5, third item) and Lemma 2.5.
QED. So for L5+ the content is confined to `q <~ M^(2+eps)`, and for L5 as stated to `q < 2cM + 1`.
*Recommendation:* the route should use L5+ (or (T) with `||c'||_1 <= k`), since L5 as stated is, under IFL,
vacuous on the moduli where the random-rate heuristic for `A > 1` puts most of its weight.

## 4. Obstructions for restricted designs

### 4.1 Certified twin channels: a volume form of the certification tension

`Gamma' := Q(i)^*/(Q^* mu_4 <1+i>)` is free abelian on the classes `[pi_p]` of the split Gaussian
primes, one from each conjugate pair (`conj pi = p/pi = pi^(-1)` in `Gamma'`; `(1+i)^2 = 2i`). Write
`g(zeta) in Z^(P)` for the exponent vector and `H(zeta) = sum_p |g_p| (log p)/2` for the height, i.e.
`log |z|` for the primitive Gaussian integer `z` representing `zeta`. Then
`||g(zeta)||_2 <= ||g(zeta)||_1 <= (2/log 5) H(zeta)`.

A *`Gamma`-coherent design* has elements `zeta_1, ..., zeta_r in Gamma'` and labels
`ell_j(q) in log(zeta_j/conj zeta_j) + T` at every `q` (shifts in `T` arbitrary, `q` prime to the norms).
For `v in Z^r` put `phi(v) = sum v_j zeta_j in Gamma'` with primitive representative `Z_v`. If `phi(v) != 0`,
then `D_s(Z_v) != 0` for all `s` (a primitive `Z_v` with `D_s(Z_v) = 0` is a unit times `1` or `1 + i`) and
`m_(v,s) | D_s(Z_v)` up to the `T`-shifts, so `sum_s delta_s(v) <= 4 H(phi(v)) + 2 log 2`: **the demand
is certified by the height** (`sharp.md` §6.6, `p3Dlower.md` Lemma 4.2 with `d = 0`).

**Theorem 4.1 (volume form).** Let `A in {0,1}^(M x r)` be any profile, `x_0` a row,
`b_x = a_x - a_(x_0)` (`x != x_0`), assumed linearly independent, and `Gram_A = (<b_x, b_y>)`. Let
`zeta_1, ..., zeta_r in Gamma'` be multiplicatively independent, `G = (g(zeta_j))_j in Z^(P x r)`, and
`B = max_j ||g(zeta_j)||_2`. Then

```text
sum_(x != x_0) log ||G b_x||_2   >=   (1/2) log det Gram_A  -  (1/2) log binom(r, M-1)  -  (r - M + 1) log B.        (4.1)
```

*Proof.* Multiplicative independence means `G` is injective on `Z^r`, hence (integer matrix) on `R^r`;
let `s_1 >= ... >= s_r > 0` be its singular values and `k = r - M + 1`.
1. `prod_i s_i = det(G^T G)^(1/2) >= 1`, since `G^T G` is a positive definite integer matrix.
2. `prod_(i <= k) s_i = ||Lambda^k G||_op <= ||Lambda^k G||_F`, and by Cauchy-Binet
   `||Lambda^k G||_F^2 = sum_(|I| = k) det(G_I^T G_I) <= binom(r, k) B^(2k)` (Hadamard's inequality for
   each `I`). Since `binom(r, k) = binom(r, M-1)`, items 1-2 give `prod_(i > k) s_i >= binom(r, M-1)^(-1/2) B^(-k)`.
3. Let `V = span(b_x)`, of dimension `M - 1`. By Cauchy interlacing for the compression of `G^T G` to `V`,
   the singular values `t_1 >= ... >= t_(M-1)` of `G|_V` satisfy `t_i >= s_(i+k)`, so
   `vol_(M-1)(G b_x : x) = det(Gram_A)^(1/2) prod_i t_i >= det(Gram_A)^(1/2) prod_(i > k) s_i`.
4. Hadamard's inequality: `vol_(M-1)(G b_x : x) <= prod_x ||G b_x||_2`. Combine. QED

**Corollary 4.2 (the sharp.md §4 twin profile; certified (F) + (T) excludes certified (P)).** For the
Paley twin profile (`M = q_0 + 1`, `b >= 25` columns per label, `r = b(M-1)`):
1. `det Gram_A >= ((b - 24) M/4)^(M-1)`.
2. In a `Gamma`-coherent design with multiplicatively independent `zeta_j` and `H(zeta_j) <= h` for all
   `j`, the geometric mean over `x != x_0` of the pair heights `H(phi(a_x - a_(x_0)))` is at least
   `(log 5/2) ((b-24)M/(4 e b))^(1/2) ((2/log 5) h)^(-(b-1))`.
3. If (F) and (T) are height-certified at scale `h = beta' log M` (i.e. certified for `w = 0` and
   `||w||_1 = 1`), then every column is: `e_j` (`j in J`) is a free monomial, `e_(f(y))` has twin
   coordinates `(0, eps_y e_y)` and `e_(s(y))` has `(e_(U_y), -eps_y e_y)`, so `H(zeta_j) <= 2 beta' log M`.
   By item 2 the pair heights have geometric mean `>= M^(1/2)/(C log M)^(b-1)`, which exceeds
   `K log M` for large `M`: **(P) cannot be certified by height**.

*Proof.* (1) Write `S = 2A - J`. Without the flips, `<S_x, S_y> = b(M delta_xy - 1)` (rows of the normalised
Hadamard matrix `[1 | H']`), hence `<S_x - S_(x_0), S_y - S_(x_0)> = bM(delta_xy + 1)`, i.e.
`Gram_A = (bM/4)(I + J)` exactly. Each flip changes one entry of one row by `+-2` in a column `f(z)`, the `f(z)`
distinct. Expanding, each entry of `4 Gram_A` changes by at most `8 + 8 + 8 = 24`, so
`Gram_A = (bM/4)(I + J) + E` with `|E_xy| <= 6` and `||E||_op <= 6(M - 1)`. By Weyl,
`lambda_min(Gram_A) >= bM/4 - 6(M-1) >= (b - 24)M/4`. (2) Theorem 4.1 with `binom(r, M-1) <= (eb)^(M-1)` and
`(r - M + 1)/(M - 1) = b - 1`, then `H >= (log 5/2) ||g||_2`. (3) Immediate from (2). QED

*Scope.* Theorem 4.1 is a barrier to one **construction method** (certify everything by heights). On the
Paley profile it repeats, in a weaker quantitative form valid for every profile with large `det Gram_A`,
the dichotomy of `p3Dconstruct.md` Theorem 2 (there for `q = 3 mod 8` coherence, average pair heights and
linear height bounds). For L5 it says: **a twin channel certified by heights forces uncertified pairs**, so
in any coherent construction (P) has to hold through the `X`-smooth parts of dense Gaussian integers,
not through their size. *Exact checks:* `check_volume.py` computes `det Gram_A` exactly for
`q_0 = 43, 47, 59` (`b = 33`) and `(43, 4)`, `(47, 8)`: `(1/2) log det Gram_A` agrees with
`((M-1)/2) log(bM/4) + (1/2) log M` to `0.01`, and tests (4.1) on 200 random integer matrices.

### 4.2 What an obstruction and what a construction would have to contain

Combine Prop. 2.3, Cor. 2.4, Lemma 3.1 and Cor. 3.3. At a medium modulus every row `y in D_q` has a
class-mate `x` (a forced unit-1 collision), and the hit pattern of each twin monomial of `y` at `q` is that
of the **dense** monomial `(w + eps(phi_x - phi_y), eps e_x)`. The class-mate `x = x(y, q)` changes with `q`
(by (P), a fixed pair shares a class at moduli of total weight `<= K log M`).

* *An obstruction (a proof of L5)* must therefore control, across the medium moduli, the joint hit
  patterns of the families `{(w + eps(phi_x - phi_y), eps e_x) : ||w||_1 <= k}` for the pairs that the
  pair code makes collide. That is a statement about dense combinations of the labels, of the type of
  Hypothesis `H` / L7 (Poisson tails for dense values), not about sparse ones. Lemma 3.1 excludes
  every argument that is local in `q`. And (F) by itself says nothing here: it constrains `f` only, and
  by Prop. 2.2 every `f` is compatible with every parity-compatible `kappa`, so (F) implies nothing about
  the values `Lambda_y = kappa_y - <phi_y, f>`.
* *A construction (a refutation of L5)* must use a pair code whose forced collisions at medium moduli
  pair up rows whose dense translates are controlled. If the controls are certificates by height, this
  is impossible on near-Hadamard profiles (Theorem 4.1, `p3Dconstruct.md` Thm 2). If the twin labels are
  independent across moduli it fails by the Poisson barrier (`p3Dconstruct.md` Thm 1: under the model in
  which the twin labels of non-representative rows are independent and uniform in their parity class on
  the medium moduli, these labels are an independent family on a set of primes of reciprocal mass
  `>= log(1/(1-eta)) - o(1)` in `(M^(1-eta), M]`; *model statement*, it does not cover deterministic labels).
  Additive twin labels (`Lambda_y = g_q lambda_y`, `|lambda_y| <= M^h`) die by the Siegel relation
  `sum c'_y lambda_y = 0` with `||c'||_1 <= 2k` (`p3Dlower.md` Prop. 3.1 applied to the `f`-columns); this
  violates the height condition of P3-all\* for a monomial with `||c'||_1 >= 2`, which is outside L5 as
  stated. If the free labels are additive too, the relation `<w, mu> = -eps lambda_y` with sparse `w`
  violates (T) itself.

**Remark 4.3 (why switching stops at `n_q ~ cM`; heuristic).** Theorem 3.2 controls (T) by a union over
`t` ideal candidates per row, with no loss in the rate. At medium moduli the same device would need a
*list pair design*: random `t`-lists `L_(y,q) ⊂ Z/n_q` and a choice `c(y, q) in L_(y,q)` such that every pair
shares a value at moduli of total weight `<= K log M`. Pigeonhole forces about `M^2/(4 n_q)` shared values at
each `q < 2M`, and a row can avoid a set of `Delta` bad partners only if one of its `t` classes (each of
about `2M/q` rows) contains none of them, which needs `Delta <~ (q/2) log t`. The partners that cannot take
another collision number up to `~ 2M/K` per row, so steering fails below `q ~ 4M/(K log t)`, and below that
scale the collisions of heavy pairs occur at the unsteered rate `~ 2/q`, which reproduces the Poisson
maximum `~ log^2 M/loglog M` over the `M^2` pairs. So, heuristically, no fixed `t` works at medium moduli:
the pair code there must be a genuine design (as `x mod p'(q)` in `D_A`), and then Prop. 2.3 applies. This is
a heuristic, not a theorem.

So the obstruction asked for in `p3Dlower.md` open point 2 is, at medium moduli and for the rows that
share a class, **exactly** (Prop. 2.3) a tail statement for dense translates of the free system, and at large moduli it is **false
under IFL** (Theorem 3.2). Neither the tail statement nor IFL is known.

## 5. Profiles without twins (open point 4)

Let `A in Z_(>=0)^(M x r)` be any profile of rank `M`, with invariant factors `d_1 | d_2 | ... | d_M` and
`Delta_M(A) = d_1 ... d_M` (the gcd of the `M x M` minors). Fix `q`, the top modulus `m = m_Q`, and
`n = m/2`. A parity-respecting `ell` is `ell = nut + 2 ell'` with `nut in {0,1}^r` the parity vector and
`ell' in (Z/n)^r` (well defined, since `x -> 2x` identifies `Z/n` with `2Z/m`); then
`kappa = A nut + 2 kappa'`, `kappa' = A ell' mod n`.

**Theorem 5.1 (decoupling for every profile).** Suppose `gcd(Delta_M(A), n) = 1`. Then:
1. `A : (Z/n)^r -> (Z/n)^M` is onto, and there is a section `s` (`A s = id`).
2. `ell' -> (kappa', k) := (A ell', ell' - s(A ell'))` is a bijection
   `(Z/n)^r -> (Z/n)^M x ker(A mod n)`. So every parity-compatible point code `kappa` (i.e.
   `kappa = A nut mod 2`) combines with every free part `k in ker(A mod n)`, at every level.
3. For every `v in Z^r`, `<v, ell> = <v, nut> + 2 <s^T v, kappa'> + 2 <v, k> (mod m)`: a monomial meets the
   pair data only through the **interface vector** `c'(v) := s^T v in (Z/n)^M`.

If `Delta_M(A) = 1` (for instance if some `M x M` minor is `+-1`) this holds at every `q`, and `s` can be
taken integral (`s in Z^(r x M)`, `A s = I`).

*Proof.* (1) For a prime `p | n`, `p` does not divide `Delta_M`, so some `M x M` minor is a unit mod `p`
and `A mod p` is onto; a linear map of free `Z/p^e`-modules that is onto mod `p` is onto (Nakayama,
or lift solutions `p`-adically); CRT over `p | n`. A surjection onto a free module splits. (2) Standard
for a split surjection. (3) Substitute `ell' = s(kappa') + k`. If `Delta_M = 1` the columns of `A` generate
`Z^M`, so each `e_x` is an integral combination of columns. QED

For a twin profile one may take `s(e_x) = eps_x (e_(f(x)) - e_(s(x)))`; then `c'(v)` is exactly the `c'` of
`p3Dlower.md` (2.2), with `||c'(v)||_1 <= ||v||_1`. **So the answer to the first half of open point 4 is
yes:** with a unimodular minor (more generally whenever `gcd(Delta_M, n_Q) = 1`) the free labels
decouple from the pair data exactly as on twin profiles; the proof is the same. What changes is the
*interface*.

**Proposition 5.2 (the interface; when the twin localisation survives).** Let `Delta_M(A) = 1`, let
`s` be an integral section, `||s||_row := max_j sum_x |s_(jx)| = max_j ||c'(e_j)||_1`, and
`sigma(A) := min_s ||s||_row` over integral sections.
1. `||c'(v)||_1 <= ||s||_row ||v||_1` for every `v`. If `sigma(A) = O(1)`, every sparse monomial meets the pair
   data through a sparse combination of point classes, and the twin-channel formulation transfers: the
   analogue of (T) concerns the monomials with `||c'(v)||_1 = 1`, and Prop. 2.1 (a single point class
   `kappa_y` avoiding a translate of a sparse sumset) holds with `s` in place of the twins. Twin profiles have
   `sigma(A) = 1`.
2. For every integral section some single-prime monomial `e_j` has `||c'(e_j)||_1 >= sigma(A)`. If `sigma(A)` is
   large, the collisions of `e_j` depend on the pair data through the combination `<c'(e_j), kappa'>` of
   many point classes (with large coefficients or large support), not through one point class. (P)
   controls only the unit-1 equalities `kappa_x = kappa_y`; the mechanism of L5 (Prop. 2.1: one coordinate
   `kappa_y` against a translated sparse sumset) then has no direct analogue.

*Proof.* `c'(v)_x = sum_j s_(jx) v_j`, and `||s||_row = max_j ||s^T e_j||_1`. QED

*Evidence* (`check_nontwin.py`, part 3): for random 0/1 profiles with distinct rows, `Delta_M = 1` in
all 90 samples (`M = 8, 12, 16`, `r = 2M, 4M`), but the sections `A_S^(-1)` obtained from unimodular minors
found by random search have `max` row `l1`-norm with median `5, 5, 25, 19, 407, 532` (in that order of
`(M, r)`). This bounds the best section from above only; a row with a twin pair always has a section of
norm 2, and random profiles with `M = 16, r = 32` had a twin pair for at least one row in only 3 of 15 samples.
Generic profiles therefore seem to have dense interfaces (evidence, no proof).

**Proposition 5.3 (profiles without a unimodular minor).** Let `g_q = gcd(Delta_M(A), n_Q) > 1`.
1. `kappa'` is confined to `H = A(Z/n)^r`, of index `prod_i gcd(d_i, n)` in `(Z/n)^M` (Smith form). The
   fibres over `kappa' in H` are cosets of `ker(A mod n)`, but `0 -> ker -> (Z/n)^r -> H -> 0` need not split
   (`A = (2)`, `n = 4`), so there need not be a product coordinate system.
2. `H ⊇ d_M (Z/n)^M`. Hence a `kappa'` with no unit-1 pair collision at `q` exists whenever
   `n/gcd(d_M, n) >= M`: take `kappa' = d_M u` with `u` injective mod `n/gcd(d_M, n)`.
3. For an `e = 1` profile, every `a_x - a_y` has an entry `+-1`, so no **single** pair is forced to collide at
   any `q`; forced collisions can only be joint (pigeonhole inside `H`), and by item 2 only at moduli with
   `n_Q < M gcd(d_M, n_Q)`.

*Proof.* (1) Smith form `A = U diag(d_i) V` with `U, V` unimodular. (2) `H ⊇ U diag(d_i)(Z/n)^M ⊇ U d_M (Z/n)^M = d_M (Z/n)^M`,
since `d_i | d_M`. Then `kappa'_x - kappa'_y = d_M (u_x - u_y) != 0 mod n`. (3) `<a_x - a_y, ell'>` runs over all of `Z/n` as
`ell'` varies. QED

So **profiles without a unimodular minor change nothing in the direction a construction needs** (the
constructor can pick twin profiles, which have `Delta_M = 1`), and for a lower bound they only add
constraints on `kappa` at the moduli with `gcd(Delta_M, n_q) > 1`, which by item 2 force pair collisions only
where `n_q < M gcd(d_M, n_q)`. *Exact data* (`check_nontwin.py`, part 4): the 0/1 Hadamard cores
`(J + H)/2` without copies have invariant factors `(1^4, 2^3, 4)` (Sylvester 8),
`(1^5, 2^6, 4^4, 8)` (Sylvester 16), `(1^6, 3^5, 6)`, `(1^10, 5^9, 10)`, `(1^12, 6^11, 12)` (Paley 12, 20, 24), so
`d_M = M/2` in all five cases (and, for the Paley cores, `M/2 - 1` factors equal `M/4`); the `sharp.md` Paley
twin profile (`q_0 = 11`, `b = 3`) has `Delta_M = 1`. For a Paley core, at `q` with `M/2 | n_q` the code
`kappa'` lies in a subgroup of index `(M/4)^(M/2-1) (M/2)`, but injective codes exist as soon as
`n_q >= M d_M = M^2/2` (item 2).
Whether this can force pair demand of order `>> log M` is a question about the moduli `q` with
`q = +-1 mod` (prime factors of `Delta_M`) and `n_q < M d_M`; nothing is known about `Delta_M` for actual
near-extremal profiles. The parts 1-2 statements are verified by brute force (`part 1`: 152 pairs `(A, n)`).

**Answer to open point 4.** (i) Non-twin profiles with a unimodular minor decouple the same way
(Thm 5.1). (ii) The twin-channel *localisation* (pairs meet sparse monomials through `M` labels via
sparse interfaces) needs a section of bounded row norm (Prop. 5.2); without one, the analogue of L5
concerns combinations of many point classes, on which (P) (unit-1 equalities of single pairs) gives no
direct hold. (iii) Profiles without a unimodular
minor only restrict `kappa` at the moduli where `gcd(Delta_M, n_q) > 1` and cannot help a construction;
whether they help a lower bound depends on the Smith invariants of actual profiles, about which nothing
is known.
