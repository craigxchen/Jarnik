**Answer.**
* (a) *Construction:* achieved only up to norm 2 (Proposition D). That is a genuine instance of an uncertified
  parity-respecting multiplicative code with linear demand, and it shows that L4 as literally stated ("bounded
  sparse demand forces certification") is false when restricted to norm `<= 2`. Beyond norm 2 the encoding
  ignores 3-term relations (exact check: 164-916 norm-3 monomials per run escape the certificate).
* (b) *Inverse theorem:* not proved. Its conclusion is now pinned down: in the regime that growth needs,
  certification by sub-genuine Gaussian integers is impossible unconditionally (exactly, in Hamming distance for
  almost all columns, or piecewise with few pieces). So the inverse step is equivalent to (I1\*): bounded
  demand at norms `3..K` forces closeness to **genuine-height** certificates on the deep 2-adic moduli. Combined
  with L7 (Poisson tails of genuine-height witnesses) it would give growth; neither is proved.

**Validity for actual circles.** Every theorem here is about label systems (designs) inside P3-all\*. Actual
clusters satisfy all of them with `zeta_j = pi_j`. Nothing here bounds actual circles beyond `two_thirds`.

## 1. Setting, and the regime that matters for actual circles

**Conventions** (`sharp.md` Def. 1.1, Prop. 2.1, Cor. 2.2; `p3Dlower.md` §0). Columns `j = 1, ..., r` carry
distinct primes `p_j = 1 mod 4`, `N = prod p_j^(e_j)`. For an odd prime `q` not dividing `N` and
`a <= A_q` (`q^(A_q) <= X`), `T_(q^a)` is cyclic of order `m_(q^a) = (q - chi(q)) q^(a-1)`, `chi = chi_(-4)`.
A label system is a family `ell_j(q) in Z/m_Q` (`Q = q^(A_q)`), and it is *parity-respecting* when

```text
ell_j(q) = nu_j(q) mod 2,        nu_j(q) = [ (p_j/q) = -1 ].                                          (1.1)
```

By `sharp.md` Cor. 2.2(1) these are exactly the factored residue data with genuine norms. `v in Z^r`
*collides at `q^a` with unit `i^s`* if `<v, ell(q)> = s iota mod m_(q^a)`, `iota = log i`, and
`m_(v,s)`, `m_v` are the per-unit and all-unit collision moduli (`p3Dlower.md` §0). For
`v != 0` and a family of Gaussian integers `zeta_j` that are units modulo every `q <= X` not dividing `N`, write

```text
Z_v = prod_j zeta_j^(v_j^+) conj(zeta_j)^(v_j^-),     L_j(q) = log(zeta_j / conj zeta_j) in Z/m_Q.           (1.2)
```

The labels `L_j` are *coherent* with `zeta`; `<v, L(q)> = log(Z_v/conj Z_v)`.

**Moduli classes.** `Q_1 = {q = +-1 mod 8}`, `Q_3 = {q = +-3 mod 8}`, `Q_7 = {q = 7 mod 8} ⊂ Q_1`. For
`q in Q_1`, `8 | q - chi(q)`; put `b_q = v_2(q - chi(q)) >= 3`.

**Two elementary facts used throughout.**

*(F1) Parity is an invariant of the collision pattern at `Q_1`.* If `q in Q_1` and `ell' = u ell + (m_Q/4) w`
with `u in (Z/m_Q)^*`, `w in Z^r`, then `ell'` and `ell` have the same collision sets for every `v`
(all units together), and the same parities, because `u` is odd and `m_Q/4` is even.
So "the labels agree with `L` up to `mu_4` and a unit at `q`" forces `ell_j(q) = L_j(q) mod 2`.

*(F2) Legendre symbols at `q = 3 mod 4`.* Let `n >= 1`, `n = 2^e m s^2` with `m` odd and squarefree. For a prime
`q = 7 mod 8` not dividing `n`, quadratic reciprocity and `(2/q) = 1` give

```text
(n/q) = (m/q) = sigma_m (q/m),        sigma_m = (-1)^((m-1)/2),                                           (1.3)
```

with `(q/m)` the Jacobi symbol. If `m > 1`, `(./m)` is a non-principal character mod `m`.
Every prime `q = 7 mod 8` is `3 mod 4`, so **it never divides `N`** (all `p_j = 1 mod 4`).

**(F3) The regime.** By `round8/stability.md` Cor. 3.6(1) (proved, actual circles), an actual cluster with
`M >= eps log R/loglog R` has every prime factor of `N` below `M^(4/eps - 3 + o(1))`. A cluster with
`W <= c_0 M log M` has `M >= (2/c_0 - o(1)) log R/loglog R`, so its primes satisfy

```text
p_j <= M^(h_0),        h_0 = 2 c_0 - 3 + o(1).                                                            (1.4)
```

Hence, to prove `W/(M log M) -> infinity` along actual clusters it suffices to prove:

> **(T')** For every `c_0` there is `A = A(c_0)` such that for large `M` no member of `F^all_(3M^A)(M, C)` whose primes
> satisfy (1.4) has `W <= c_0 M log M`.

(If `W <= c_0 M log M` held along a sequence of actual clusters, they would be members of `F^all_X` for every
`X` (`sharp.md` Prop. 1.2) with primes (1.4), contradicting (T') at `X = 3 M^(A(c_0))`.) (T') is (T) of
`round7/README.md` §3 with the quantifier order `forall c_0 exists A`, which is all that growth needs. **In
this regime `X` may be taken larger than any prescribed fixed power `p_j^C`**, and of `Norm zeta` for every
Gaussian integer of norm `<= M^h` (`h` fixed): take `A >= C(h_0 + h)`. The construction rounds (5-7) all used `p_j > X`; in that regime the theorems of §§2-4 below are
not available unconditionally. This is the reason `p3Dlower.md` Remark 3.4 and open point 3 found the
unconditional version of its Theorem 3.2 useless: it is useless for `p_j > X`, but not in regime (1.4).

**The question (L4).** Fix `beta`. A parity-respecting system is *`beta`-good up to norm `K`* if every
`v` outside the character lattice with `1 <= ||v||_1 = k <= K` has `log m_(v,s) <= beta k log M` for every `s`.
L4 asks whether `beta`-good systems (`K ~ X/tau`) must be *certified*: induced, up to the harmless operations
of (F1), by Gaussian integers `zeta_j` of controlled height, at all or most moduli.

The certified side of that dichotomy is decided in §§2-4: **in regime (1.4), unconditionally, no column is
certified (exactly, approximately in Hamming distance, or piecewise with few pieces) by Gaussian integers
`zeta_j` with `p_j` not dividing `Norm zeta_j`**. Certificates of genuine height (`Norm zeta_j >= p_j`)
remain, and are exactly the genuine-type labels of `p3G.md`. §5 shows that the requirement for monomials of
norm `<= 2` can be met with the parity, so any inverse theorem must use norm `>= 3`.

## 2. Exact coherence is impossible unconditionally (Theorem A)

**Linnik's theorem** (classical; quoted, constants from memory): there are absolute constants `C_L, L` such
that for every `k >= 2` and `a` with `gcd(a, k) = 1` there is a prime `q = a mod k` with `q <= C_L k^L`.
`L = 5` is admissible (Xylouris 2011); any absolute `L` suffices below.

**Lemma 2.1 (a non-residue class at `7 mod 8`).** Let `n >= 1` not be of the form `t^2` or `2 t^2`. Then
there is a prime `q <= C_L (8n)^L` with `q = 7 mod 8`, `q` not dividing `n`, and `(n/q) = -1`.

*Proof.* Write `n = 2^e m s^2`, `m` odd squarefree. Since `n` is neither a square nor twice a square,
`m > 1`. Let `k = lcm(8, rad(n)) <= 8n`. By (1.3), for primes `q = 7 mod 8` not dividing `n`,
`(n/q) = sigma_m (q/m)`, a function of `q mod k`. The Jacobi symbol `(./m)` is non-principal mod `m`, so
there is `b mod m`, `gcd(b, m) = 1`, with `(b/m) = -sigma_m`. By the Chinese remainder theorem choose
`a mod k` with `a = 7 mod 8`, `a = b mod m`, `a = 1 mod l` for the odd primes `l | s` with `l` not dividing
`m`. Then `gcd(a, k) = 1`, and every prime `q = a mod k` satisfies `q = 7 mod 8`, `q` not dividing `n`,
`(n/q) = -1`. Linnik gives one with `q <= C_L k^L`. QED

**Theorem A (exact coherence forces genuine norm; unconditional).** Let `p = 1 mod 4` be prime, `zeta` a
Gaussian integer, `n = p Norm(zeta)`, and `X >= C_L (8n)^L`. Suppose a parity-respecting label `ell_j`
(column of `p_j = p`) satisfies, for every prime `q <= X` with `q = 7 mod 8` and `q` not dividing `Norm zeta`,

```text
ell_j(q)  in  u_q log(zeta/conj zeta) + (m_Q/4) Z/m_Q      for some odd u_q in (Z/m_Q)^*.                     (2.1)
```

Then `n` is a square or twice a square. In particular `p | Norm zeta`, so `|zeta|^2 >= p = e^(w(e_j))`.

*Proof.* At such `q` the labels have parity `nu_j(q) = [(p/q) = -1]` by (1.1), and the right side of (2.1) has
the parity of `log(zeta/conj zeta)`, which is `[(Norm zeta/q) = -1]` (`sharp.md` Prop. 2.1(3); (F1)). Hence
`(n/q) = (p/q)(Norm zeta/q) = 1` for every prime `q <= X`, `q = 7 mod 8`, `q` not dividing `n` (note `q != p`
since `p = 1 mod 4`). If `n` were not of the form `t^2`, `2t^2`, Lemma 2.1 would give a prime `q <= X`
violating this. So `n = t^2` or `2t^2`. Then `p | t` (as `p` is odd), so `p^2 | n = p Norm zeta` and `p | Norm zeta`. QED

*Remarks.*
* No hypothesis on `N` is needed: primes `q = 7 mod 8` never divide `N` ((F2)). Theorem 3.2 of `p3Dlower.md`
  needed GRH and the assumption `p_j > X`; here the hypothesis is `X >= C_L (8n)^L`, which is a polynomial
  condition and holds automatically in regime (1.4) once `A >= L(h_0 + h) + 2`, where `Norm zeta <= M^h`.
* Only the moduli `q = 7 mod 8` are used: inert primes with `8 | q + 1`.
* The theorem is about *designs*. For actual clusters `zeta_j = pi_j` and `n = p_j^2`: consistent.

**Corollary A.1 (coherent certificates have no slack; unconditional in regime (1.4)).** Let
`A >= L(h_0 + h) + 2` and `X = 3M^A`. Every member of P3-all\*_X with primes (1.4) whose labels satisfy (2.1)
at all `q = 7 mod 8`, `q <= X`, for Gaussian integers `zeta_j` with `Norm zeta_j <= M^h`, has `|zeta_j|^2 >= p_j`
for all `j`. Consequently the coherent certificate of a monomial `v`,
`m_(v,s)^((7 mod 8)) <= prod_(s') |D_(s')(Z_v)|`, is never better than the trivial genuine bound
`e^(w(v)/2)` per unit (`p3Dlower.md` Cor. 3.3, now without GRH).

*Proof.* Theorem A column by column; the rest is `p3Dlower.md` Cor. 3.3 verbatim. QED

*Validity.* Theorem A and Corollary A.1 are statements about label systems in P3-all\*. Actual clusters
satisfy them with `zeta_j = pi_j`. They bound nothing about actual circles by themselves. They settle the
unconditional half of L6 (`round7/README.md` §3) for exact coherence, in the regime that growth needs.

## 3. Approximate (Hamming) coherence is impossible for almost every column (Theorem B)

**Heath-Brown's quadratic large sieve** (D. R. Heath-Brown, *A mean value estimate for real character sums*,
Acta Arith. 72 (1995), Theorem 1; quoted from memory, check the exact form). For every `eps > 0`, all
`D, X >= 1` and complex `a_n`,

```text
sum*_(m <= D) | sum*_(n <= X) a_n (n/m) |^2   <<_eps   (DX)^eps (D + X) sum*_(n <= X) |a_n|^2,                 (3.1)
```

where `sum*` runs over odd squarefree integers and `(n/m)` is the Jacobi symbol.

**Definition 3.1 (agreement set).** For a column `j`, a Gaussian integer `zeta` that is a unit modulo every
`q <= X` it is tested at, and the label system `ell`, let

```text
Ag_j(zeta) = { q <= X prime, q = 7 mod 8, q not dividing Norm zeta :
               ell_j(q) in u log(zeta/conj zeta) + (m_Q/4) Z  for some odd u },
```

and `theta(S) = sum_(q in S) log q`, `theta_7(X) = theta({q <= X : q = 7 mod 8})`. Agreement on `Ag_j(zeta)`
is the weakest form of "the column is certified by `zeta` at `q`": it constrains the single label `ell_j(q)`
(up to the operations of (F1)), not the collision pattern of any monomial involving other columns.

**Theorem B (unconditional).** Let `eps > 0`, `0 < delta <= 1`, `X >= X_0(eps)`, `D <= X`, and
`delta X >= 30 log D`. Call a column `j` *`delta`-certifiable* if some Gaussian integer `zeta` with
`p_j Norm(zeta) <= D` and `p_j` not dividing `Norm zeta` has `theta(Ag_j(zeta)) >= ((1 + delta)/2) theta_7(X)`.
Then for every parity-respecting label system,

```text
#{ j : column j is delta-certifiable }   <=   C_eps X^eps (log X)(log_2 D) / delta^2,                             (3.2)
```

with `C_eps` depending only on `eps`.

*Proof.*
1. *Agreement forces a character bias.* Let `zeta` witness `delta`-certifiability and `n = p_j Norm zeta`,
   `n = 2^e m s^2` with `m` odd squarefree. Since `p_j || n`, `p_j | m`, so `m > 1`. By (F1) and (1.1), every
   `q in Ag_j(zeta)` has `(Norm zeta/q) = (p_j/q)`, i.e. `(n/q) = 1`. Let `S_n = sum (n/q) log q` over primes
   `q <= X`, `q = 7 mod 8`, `q` not dividing `n`, and `theta_7' = theta_7(X) - theta({q | n})`. Then
   `theta(Ag) <= (theta_7' + S_n)/2`, hence `S_n >= delta theta_7(X) - log n`.
2. *Pass to the Jacobi symbol.* By (1.3), `S_n = sigma_m (S_m - E)` with
   `S_m = sum_(q <= X, q = 7 mod 8) (q/m) log q` and `E` the contribution of primes `q | s` (`(q/m) = 0` for
   `q | m`). `|E| <= log s <= log n`. So `|S_m| >= delta theta_7(X) - 2 log D >= delta X/5 - 2 log D >= delta X/6`
   for `X >= X_0` (prime number theorem in progressions mod 8: `theta_7(X) ~ X/4`) and `delta X >= 30 log D`.
3. *Large sieve.* Apply (3.1) with `a_n = log n` for primes `n = 7 mod 8`, `n <= X`, and `0` otherwise; these
   `n` are odd and squarefree, and `sum |a_n|^2 <= X log X`. Let `E_bad` be the set of odd squarefree `m <= D`
   with `|S_m| >= delta X/6`. Then
   `|E_bad| (delta X/6)^2 <= C'_eps (DX)^(eps/2) (D + X) X log X`, so `|E_bad| <= 72 C'_eps X^eps log X/delta^2`
   (using `D <= X`).
4. *Columns to moduli.* Step 1-2 assign to each `delta`-certifiable column `j` some `m in E_bad` with `p_j | m`.
   An `m <= D` has at most `log_2 D` prime factors, so at most `log_2 D` columns map to it. QED

**Corollary B.1 (regime (1.4)).** Take `X = 3M^A` with `A >= h_0 + h`, `D = M^(h_0 + h)`, `eps = 1/(4A)`. Then
for every parity-respecting label system with primes (1.4), all but `O(M^(1/4) log^2 M/delta^2)` columns are
**not** `delta`-certifiable by any `zeta` with `Norm zeta <= M^h` and `p_j` not dividing `Norm zeta`. With
`delta = M^(-1/10)` this is `o(M)` columns: almost every column agrees, at `q = 7 mod 8`, with every sub-genuine
coherent label on at most `(1/2 + o(1))` of the log-mass.

*Remarks.*
* Under GRH the exceptional set is empty once `X >= (log D)^(2 + eps)`: `|S_m| << X^(1/2) log^2(mX)` for every
  non-principal real character. Theorem B is the unconditional substitute, at the price of `X^eps` exceptional
  columns.
* Twisted coherent labels (`p3Dlower.md` Def. 4.1) agree with `zeta_j` exactly on the set where the parities
  match, which by Theorem B has relative mass `1/2 + o(1)` for almost every column. They are the extreme case
  of Theorem B, not a counterexample to it.
* *Validity.* A statement about label systems of P3-all\*. Actual clusters satisfy it trivially (they are
  certified by `pi_j`, which has `p_j | Norm pi_j`).

## 4. Piecewise coherence needs many pieces (Theorem C)

Twisted coherence (`p3Dlower.md` Def. 4.1) and every "repair by a short list" are *piecewise* certificates:
at each modulus the label of column `j` agrees, in the sense of (F1), with one of a few coherent labels.

**Definition 4.1.** Column `j` is *covered* by `zeta_1, ..., zeta_P` up to `X` if for every prime
`q <= X`, `q = 7 mod 8`, not dividing `prod_c Norm zeta_c`, there is `c` with
`ell_j(q) in u log(zeta_c/conj zeta_c) + (m_Q/4) Z` for some odd `u`. The pieces are *sub-genuine* if
`p_j` divides no `Norm zeta_c`.

**Lemma 4.2 (common non-residue).** Let `p = 1 mod 4` be prime and `n_c = p Norm zeta_c` (`c = 1..P`) with `p`
dividing no `Norm zeta_c`. There is a prime `q = 7 mod 8`, `q` not dividing `prod_c n_c`, with `(n_c/q) = -1` for
all `c` and `q <= C_L (8 prod_c n_c)^L`.

*Proof.* Write `n_c = 2^(e_c) m_c s_c^2` with `m_c` odd squarefree; `p | m_c`. Let `K` be the product of the
distinct odd primes dividing `prod n_c`, `G = (Z/K)^*`, `psi_c = (./m_c)` on `G`, and `t_c = -sigma_(m_c)`.
By (1.3) we need `a in G` with `psi_c(a) = t_c` for all `c` (then combine with `a = 7 mod 8` by CRT; `K` is odd).
* *Duality.* The image `H` of `Psi = (psi_c)_c : G -> {+-1}^P` is a subgroup, and `t in H` iff `prod_(c in S) t_c = 1`
  for every `S` with `prod_(c in S) psi_c = 1` on `G` (finite abelian duality: `H` is the annihilator of the
  relations).
* *Relations have even size.* `prod_(c in S) psi_c = (./prod_S m_c)` is principal on `G` iff `prod_(c in S) m_c` is a
  perfect square (a Jacobi symbol modulo a positive odd non-square is non-principal: take a non-residue modulo
  a prime to an odd power, CRT). Since `p` divides every `m_c` exactly once, `|S|` is even.
* *Signs.* For odd `a, b`, `(ab - 1)/2 = (a-1)/2 + (b-1)/2 mod 2`, so
  `prod_S t_c = (-1)^|S| prod_S sigma_(m_c) = (-1)^((prod_S m_c - 1)/2) = 1`, as an odd square is `1 mod 8`.
So `t in H`. Pick `a` with `Psi(a) = t`, `a = 7 mod 8`, `gcd(a, 8K) = 1`; every prime `q = a mod 8K` works,
and Linnik gives one below `C_L (8K)^L <= C_L (8 prod n_c)^L`. QED

**Theorem C (unconditional).** If column `j` is covered up to `X` by `P` sub-genuine pieces, then
`X < C_L (8 prod_c p_j Norm zeta_c)^L`. In regime (1.4), with `Norm zeta_c <= M^h` and `X = 3M^A`, this means

```text
P  >  (A - 1) / (L (h_0 + h))           (for M large).                                                          (4.1)
```

*Proof.* At the prime `q` of Lemma 4.2 every piece has the wrong parity: `(Norm zeta_c/q) = -(p_j/q)`, so by
(F1) no piece agrees with the parity-respecting `ell_j(q)`. QED

**Theorem C' (GRH for Dirichlet L-functions).** Under the same hypotheses, covering by `P` sub-genuine pieces
requires `2^P >= c sqrt X/(log X log(X prod_c n_c))` with an absolute `c > 0`; in regime (1.4),

```text
P  >=  (1/2 - o(1)) log_2 X.                                                                                    (4.2)
```

*Proof.* Count primes `q <= X`, `q = 7 mod 8`, `q` not dividing `K`, with `psi_c(q) = t_c` for all `c`:

```text
#  =  2^(-P) sum_(S ⊂ [P]) (prod_(c in S) t_c) sum_(q <= X, q = 7 (8), q not | K) psi_S(q),       psi_S = prod_(c in S) psi_c.
```

Principal `psi_S` (the relations) have `prod_S t_c = 1` (Lemma 4.2), so they contribute
`2^(-P) #{relations} (pi(X; 8, 7) - omega(K)) >= 2^(-P)(pi(X;8,7) - log_2 K)`. Each non-principal `psi_S`,
twisted by the characters mod 8, has `|sum| << sqrt X log(XK)` under GRH; there are at most `2^P` of them, each
with weight `2^(-P)`. So `# > 0` as soon as `2^(-P) X/(5 log X) > C sqrt X log(XK)`. If the pieces cover the
column, `# = 0`, which gives the bound. In regime (1.4), `log K <= P (h_0 + h) log M + log 8`, and
`P <= log_2 X` may be assumed (else (4.2) holds), so `log(XK) = O(log^2 X)` and (4.2) follows. QED

*Remarks.*
* Twisted coherence has `T(X) + 1` pieces per column (`zeta_j` and `zeta_j rho_t`); Theorem C' gives
  `T(X) >= (1/2 - o(1)) log_2 X` under GRH, and Theorem C gives `T(X) + 1 > (A - 1)/(L(h_0 + h))`
  unconditionally, which is unbounded as `A` grows. With `>= P` pieces, the certificate of a monomial of support `s` involves up to
  `min(P^s, pi(X))` distinct witnesses (`p3Dlower.md` Thm 4.3 is the case of a common twist, where the count is
  `(2k+1) T`).
* **What the theorems of §§2-4 do and do not show.** They show that a parity-respecting column cannot be
  certified, exactly, approximately or piecewise with few pieces, by Gaussian integers of norm prime to `p_j`.
  They do **not** show that such columns have large demand. Demand is an upper-bound quantity that a
  certificate controls; the absence of a certificate controls nothing (Lemma 5.1 of `p3Dlower.md`: at each
  modulus separately, collisions can be avoided).
* *Validity.* Statements about designs in P3-all\*. Actual clusters are covered by one genuine-height piece
  (`zeta_j = pi_j`).

## 5. Norm <= 2 is free: a parity-respecting construction (Proposition D)

§§2-4 say that parity-respecting columns are never certified by sub-genuine Gaussian integers. This section
shows that this does **not** by itself make any monomial expensive: the whole norm-`<= 2` part of L4 can be met
with the forced parity by labels that are uncertified in the sense of §§2-4.

**Notation.** For `q` odd not dividing `N`, the canonical decomposition `T_(q^a) ≅ Z/(q - chi(q)) x Z/q^(a-1)`
gives projections `pi_1`, `pi_q` of `Z/m_Q`. `mu_4 = (m_Q/4) Z/m_Q` lies in the first factor, and a label's
parity is the parity of its `pi_1`-component. `v` collides at `q^a` (some unit) iff
`pi_1(<v, ell>) = 0 mod N_q` and `pi_q(<v, ell>) = 0 mod q^(a-1)`, where `N_q = (q - chi(q))/4`.
Let `S_0 = {17, 31, 47}`: the primes `q = +-1 mod 16` with `q - chi(q) < 64`.

**Lemma 5.1 (odd encoding).** Let `N` be a multiple of 4 with `N >= 16`, and `b in {0, 1}`. There is a map
`iota_b : Z/(N/4) -> Z/N` with values `t = b mod 2`, `t not in {0, N/2}`, such that
`iota_b(x) = s iota_b(x')` with `s = +-1` implies `x = s x'`.

*Proof.* The allowed targets `t` (parity `b`, `t != 0, N/2`) have `t != -t`, so they fall into at least
`(N/2 - 2)/2 = N/4 - 1` orbits `{t, -t}`. The orbits of `x -> -x` on `Z/(N/4)` number at most `N/8 + 1`
(at most two fixed points), and `N/8 + 1 <= N/4 - 1` as `N >= 16`. Inject source orbits into target orbits;
send a free orbit `{x, -x}` to `{t, -t}` by `x -> t`, `-x -> -t`, and a fixed point `x` to `t`. If
`iota(x) = s iota(x')`, then `x'` is in the orbit of `x`. For a free orbit, `iota(x) != -iota(x)` forces `x' = x`
when `s = 1` and `x' = -x` when `s = -1`; for a fixed point `x' = x` and `s = 1` (since `t != -t`). QED

**Construction D.** Data: a profile with primes `p_j = 1 mod 4`, a bound `X`, and Gaussian primes `zeta_j`
over distinct primes `p'_j = 1 mod 4` such that each `p'_j` either exceeds `X` or divides `N`, and
`(p'_j/q) = (p_j/q)` for `q in S_0` (e.g. `p'_j = p_j mod 4 * 17 * 31 * 47`). Let `L_j(q) = log(zeta_j/conj zeta_j)`.
For each odd prime `q <= X` not dividing `N`, define `ell_j(q)`:
1. `q in Q_3`: `ell_j = L_j + iota w_j`, `w_j in {0, 1}` chosen to fix the parity (`p3Dlower.md` Thm 1.1(1)).
2. `q in S_0`: `ell_j = L_j` (the parity is already right).
3. `q in Q_1`, `b_q = 3`: `pi_1` splits as `Z/8 x Z/o_q` (`o_q` odd); put `pi_1(ell_j) = (nu_j(q), odd part of pi_1(L_j))`
   and `pi_q(ell_j) = pi_q(L_j)`.
4. `q in Q_1`, `b_q >= 4`, `q not in S_0` (so `4 | N_q`, `N_q >= 16`): put `x_j = pi_1(L_j) mod N_q/4`,
   `pi_1(ell_j)` = any lift to `Z/(q - chi)` of `iota_(nu_j(q))(x_j) in Z/N_q`, and `pi_q(ell_j) = pi_q(L_j)`.
For `q | N` (level residues) choose any parity-respecting values. All levels are reductions of the top one.

**Proposition D (proved; designs, any `X`).** Construction D is parity-respecting (it is a member of the
factored residue data (d) of `sharp.md` Def. 1.1), and every `v` with `1 <= ||v||_1 <= 2` satisfies

```text
m_(v,s)  <=  m_v  <=  |Im(Z_v^16)|  <=  prod_j Norm(zeta_j)^(8 |v_j|)        for every s.                       (5.1)
```

*Proof.* Parity: in cases 1-2 by construction and by `(Norm zeta_j/q) = (p_j/q)` on `S_0`; in cases 3-4 the
`pi_1`-component has parity `nu_j(q)` (in case 4 because `N_q` is even, so a lift keeps the parity).
Collisions: let `v` have norm `<= 2`, put `W = Z_v` and `u = W/conj W` (so `<v, L> = log u`). We show that a
collision of `v` at `q^a` forces `u^16 = 1` in `T_(q^a)`.
* Cases 1-2: the collision sets (all units) are those of `L` (Thm 1.1(1) of `p3Dlower.md`), i.e. `u in mu_4`.
* Case 3: a collision needs the odd part of `pi_1(log u)` and `pi_q(log u) mod q^(a-1)` to vanish, so the
  `pi_1`-component of `u` lies in the 2-Sylow subgroup, of order 8, and `u^8 = 1`. (This case works for
  every `v`; it is `p3Dconstruct.md` Prop. 3.3 in another form.)
* Case 4, `v = +-e_j`: `pi_1(ell_j) mod N_q = iota(x_j) != 0`, no collision. `v = +-2 e_j`: `2 iota(x_j) = 0 mod N_q`
  would force `iota(x_j) in {0, N_q/2}`, excluded. `v = +-(e_j - s e_l)`, `j != l`: a collision needs
  `iota(x_j) = s iota(x_l)` in `Z/N_q` (with the two parities then equal) and `pi_q(L_j - s L_l) = 0 mod q^(a-1)`.
  Lemma 5.1 gives `x_j = s x_l`, i.e. `pi_1(L_j - s L_l) in (N_q/4) Z/(4 N_q)`, an element of order dividing 16.
  So `u^16 = 1` in `T_(q^a)`.
Since `W` is a unit mod `q` (its primes `p'_j` exceed `X` or divide `N`), `u^16 = 1 mod q^a` iff
`q^a | W^16 - conj(W)^16 = 2i Im(W^16)` iff `q^a | Im(W^16)` (a rational integer divisible by `q^a` in `Z[i]`
is divisible in `Z`). Distinct `q` give coprime prime powers, so `m_v | Im(W^16)`. Finally `Im(W^16) != 0`: the
`p'_j` are distinct and split, so `u` has valuation `v_j` at `zeta_j`, and `u` is not a root of unity. QED

**Corollary D.1 (the norm-`<= 2` part of L4 holds with slack).** Fix `A >= 1`, `X = 3M^A`, `h >= A + 1`. Take
`p'_j` distinct primes in `(X, M^h]` in the classes required on `S_0` (possible for large `M` by the prime
number theorem in progressions), and any profile with `p_j > X` and weights `tau_j = log p_j >= (16 h + 3) log M`.
Then every monomial of norm `k <= 2` has `log m_(v,s) <= 8 h k log M <= k (tau/2 - (3/2) log M)`: the per-unit
height condition holds with slack `(3/2) log M` per unit of norm, i.e. more than the `log(4er)` the completion
sum needs. Independent labels, uniform in their parity classes, fail this already at norm 2: some pair
`e_j - e_l` has demand `>= (1 - eta_0)^2 (1 - o(1)) log^2 M/loglog M` with probability `-> 1`. (Proof: that of
`sharp.md` Prop. 6.5 verbatim, applied to `M/2` disjoint pairs, which are independent; at `q = +-3 mod 8` the
difference `ell_j - ell_l` is uniform on its parity class, so it hits `mu_4` with probability `4/m_q`.)

**Corollary D.2 (Construction D is uncertified).** In regime (1.4) with `p'_j | N` (take `zeta_j = pi_(sigma(j))`
for a permutation `sigma` preserving the Legendre pattern on `S_0`), or in the setting of Corollary D.1, the
labels of cases 3-4 at `q = 7 mod 8`, `q not in S_0`, have parity `nu_j(q)`, so by Theorem B all but `o(M)` columns agree with
every sub-genuine coherent label (in the sense of (F1)) on at most `1/2 + o(1)` of the log-mass of those
moduli, and by Theorem C no column is covered by few sub-genuine pieces. Yet Proposition D holds.

*Reading.* Proposition D is a small but complete instance of answer (a) to L4: a parity-respecting system,
not certified in any of the senses of §§2-4, whose monomials of norm `<= 2` all have demand `<= 8h ||v||_1 log M`.
So any inverse theorem must use monomials of norm `>= 3`. The mechanism is visible: at `b_q >= 4` the parity
bit is the bottom bit of a cyclic 2-group, not a direct factor, and the encoding `iota` respects only the
relations `x = +-x'`, not sums of three or more labels. For norm `>= 3` one needs a map that respects
`k`-term signed relations (a Freiman-type isomorphism of order `k` that also fixes the bottom bit), and the
homomorphism `pi_1(L) -> pi_1(ell)` cannot do this because the parity correction `nu_j(q) - [parity of L_j]`
is not linear in the labels (§6).

*Remark (additive labels die at bounded norm).* The analogous encoding with *additive* labels
(`ell_j(q) = g_q(2 a_j + nu_j(q))`, `a_j in Z`) fails already at norm 2, for a reason different from the Siegel
trap of `p3Dlower.md` Prop. 3.1: a collision at `q` then means `(q - chi)/8 | (a_j - s a_l) + t'` for a small `t'`,
a divisibility by `q - chi`, not by `q`. Integers of size `M^(O(1))` with many divisors of the form `(q - chi)/8`
exist (any `y`-smooth `L` with `y ~ log M` has `exp(c log M/loglog M)` such divisors with `q` prime, heuristic
count), and pigeonhole over the `r ~ M` labels modulo such an `L` yields a pair colliding at all of them. The
Gaussian (multiplicative) certificate avoids this because its collision moduli divide a fixed integer with
`q`, not `q - chi`, as the modulus.

## 6. Where L4 now sits

**6.1 The certified side is closed, unconditionally, in the regime growth needs.** In regime (1.4) with
`A >= L(h_0 + h) + 2`:
* a column certified exactly (Theorem A), approximately in Hamming distance on `Q_7` (Theorem B, all but `o(M)`
  columns), or piecewise by fewer than `(A - 1)/(L(h_0 + h))` pieces (Theorem C) by Gaussian integers of norm
  `<= M^h` has a certificate with `p_j | Norm zeta`, hence `|zeta_j|^2 >= p_j`;
* every Gaussian integer that is a unit at all moduli `q <= X`, `q` not dividing `N`, has all its prime factors
  among `1 + i`, the `pi_l, conj pi_l`, or above `X`. A certificate of norm `<= M^h < X` is therefore a monomial
  in the genuine primes, and its labels are `B G` with `G` the genuine labels and `B` an integer matrix; the
  parity forces `B = I mod 2` (Theorem A applied to each row). Such a certificate bounds `m_(v,s)` by
  `e^(w(B^T v)/2)`, and `||B^T v||_1 >= #{j : v_j odd}`, so it never has slack at `v = e_j` (Corollary A.1).

So (I1) and (I2) of `p3Dlower.md` §5.3 merge, unconditionally in regime (1.4), into one statement:

> **(I1\*)** A parity-respecting system that is `beta`-good up to norm `K ~ X/tau` agrees, for a positive
> proportion of columns, with a coherent system of genuine height (`p_j | Norm zeta_j`, `Norm zeta_j <= M^(O(1))`)
> on a positive proportion (`> 1/2 + delta`) of the log-mass of `Q_7 ∩ [1, X]`.

(I1\*) plus Theorem B is a Hamming-form "certified implies genuine size", with no GRH. What then remains is
(I3) for genuine-height certificates: Poisson tails of the `X`-smooth parts of the integers `D_s(Z_v)`, which
is open even for the genuine labels themselves (L7).

**6.2 The inverse step must use monomials of norm `>= 3`, and only the deep 2-adic moduli.**
* *Norm `<= 2` is free* (Proposition D, Corollary D.1): uncertified parity-respecting systems meet every norm-`<= 2`
  requirement with slack. So (I1\*) restricted to `K = 2` is **false**.
* *Shallow 2-adic classes are free for every norm.* Case 3 of Construction D generalises: at `q` with
  `b_q = b`, put `pi_1(ell_j) = (y_j, odd part of pi_1(L_j))` with any parity-respecting 2-part `y_j`, and
  `pi_q(ell_j) = pi_q(L_j)` (at `Q_3`, unit shifts as in case 1). A collision of
  any `v` then forces `u^(2^b) = 1`, i.e. `q^a | Im(Z_v^(2^b))`. Hence for every `v` and every `B`:

  ```text
  log m_v^((b_q <= B))  <=  sum_(3 <= b <= B) log |Im(Z_v^(2^b))|  <=  2^(B+1) log |Z_v|.                       (6.1)
  ```

  This is `p3Dconstruct.md` Lemma 3.2 / Prop. 3.3 restated (proved there). Every obstruction to a construction,
  and every input to an inverse theorem, therefore lives on `Q^(B) = {q : q = +-1 mod 2^(B+1)}` with
  `B -> infinity`; these moduli carry a fraction `2^(-B)` of `theta(X)`.
* *Counting at one modulus cannot do it* (`p3Dlower.md` Lemma 5.1), and by Theorem 2.1 there the twin channel
  is separate.

**6.3 Why norm 3 is different, precisely.** Fix any coherent `L` (from `zeta`) and any parity-respecting `ell`.
At `q in Q^(B)` write `ell_j = L_j + delta_j(q) o_q + 2 E_j(q)` with `delta_j(q) = [(p_j Norm zeta_j/q) = -1]`, `o_q` a
fixed odd element and `E_j(q)` arbitrary. Then

```text
<v, ell(q)>  =  <v, L(q)>  +  t_q(v) o_q  +  2 <v, E(q)>,            t_q(v) = <v, delta(q)> in [-k, k].             (6.2)
```

By Theorem B, for almost every column `delta_j` is a balanced (`1/2 + o(1)`) function of `q`, and the `delta_j` of
different columns are typically distinct characters: when the `p_j Norm zeta_j` (`j in supp v`) are multiplicatively
independent modulo squares, the vector `(delta_j(q))_(j in supp v)` takes all `2^s` values on primes
`q = 7 mod 8` below `X` (duality and Linnik as in Lemma 4.2; unconditional for `s <= (A - 1)/(L(h_0+h))`). A design is a choice
of `E` (and `o_q`). For `k <= 2`, `t_q(v) in {-2, ..., 2}` and Lemma 5.1 absorbs it by a non-linear `E`. For `k >= 3`
any `E` linear in `L` turns (6.2) into the twisted shape `<v, L> + t o_q`, with one witness per value of `t`
(`p3Dlower.md` Thm 4.3: caps quadratic in `k`); any `E` non-linear in `L` loses the multiplicative certificate
of `<v, L>` itself. No intermediate mechanism is known. The heuristic (Remark 4.5 of `p3Dlower.md`) is that both
branches land at `tau ~ log^2 M/loglog M`.

**6.4 Answer to the task.**
* (a) *Construction.* A parity-respecting, uncertified (in every sense of §§2-4), `8h`-good system exists up to
  norm 2 (Proposition D, Corollary D.1). Up to norm `K -> infinity` nothing is constructed. Every known way of
  going beyond norm 2 is a superposition of certificates whose witnesses multiply (§6.3).
* (b) *Inverse theorem.* Not proved. Its certified conclusion is now known to be equivalent, unconditionally in
  regime (1.4), to genuine height (§6.1). So the inverse step must show that bounded demand at norms `3..K`
  forces Hamming-closeness to genuine-height certificates on the deep 2-adic moduli `Q^(B)`. It cannot be proved
  from norm-`<= 2` data, from shallow moduli, or by single-modulus counting.
* No growth improvement, and no new barrier for P3-all\* itself, is claimed. The bracket
  `3 M log M - O(M) <= W_min^all <= (66 A + o(1)) M log^2 M/loglog M` is unchanged.

## 7. Checks and evidence

**Exact** (`L4_checks/check_D.py`, output `check_D_out.txt`: `ALL OK` on five parameter sets,
`X in {400, 1000, 2000, 3000}`, `r in {12, 14, 16}`). Construction D is built literally: profile primes
`p_j in (10^4, 10^6)`, `zeta_j` over the next prime `p'_j = p_j mod 4*17*31*47`, all prime powers `q^a <= X`,
discrete logs in `T_(q^A)` by table (`tq.py`), cases 1-4 of §5 (e.g. at `X = 3000`: 219, 3, 105, 102 moduli).
* Every label has parity `nu_j(q) = [(p_j/q) = -1]`.
* For **every** monomial of norm `<= 2` (156-272 per run), the all-unit modulus `m_v`, computed level by level,
  divides `Im(Z_v^16)` (exact Gaussian integers), and `Im(Z_v^16) != 0`. No failure.
* Norm 3 (1156-2736 monomials per run): `m_v` fails to divide `Im(Z_v^16)` for 164-916 of them, as expected
  (the encoding of case 4 ignores 3-term relations); restricted to the moduli of cases 1-3 the divisibility holds
  for every norm-3 monomial (case 3 works for all `v`).
* At these sizes the norm-2 demands of Construction D and of random parity-respecting labels are comparable
  (e.g. 66.1 vs 58.1 at `X = 3000`); the certificate `16 log|Z_v|` is far from tight. This is not evidence about
  rates.

**Evidence** (`L4_checks/check_AC.py`, output `check_AC_out.txt`; no proof uses it).
1. *Lemma 2.1.* For 4000 sub-genuine `n = p Norm(zeta)` (`p in (10^5, 10^7)`, `Norm zeta < 3200`), the least prime
   `q = 7 mod 8` with `(n/q) = -1` is at most 191. Linnik's bound is very far from sharp; GRH predicts `O(log^2 n)`.
2. *Lemma 4.2 / Theorem C'.* For `P` random sub-genuine pieces of one column (40 columns per `P`), the least
   prime `q = 7 mod 8` at which all pieces have the wrong parity has median 23, 47, 71, 191, 271, 1223, 3719, 3559,
   9791, 10567, 59447, 37199 for `P = 1..12` (maximum `2^(6.3)` ... `2^(19.3)`). Growth is roughly `2^(1.3 P)`, consistent
   with the count `pi(X)/2^(P+2)` behind Theorem C': covering every `q <= X` needs `P >~ log_2 X` pieces.
3. *Theorem B.* For 30 columns and all 651 distinct norms `a^2 + b^2` (`1 <= a < 40`, `0 <= b < 40`) of small `zeta`, the largest relative bias
   `S_n/theta_7(10^6)` is 0.0241: no small `zeta` agrees in parity with a column on more than 51.3% of the
   log-mass of `Q_7 ∩ [1, 10^6]`.

## 8. Open points

1. **(I1\*) for norm `>= 3`.** Does `beta`-goodness up to norm `K -> infinity` force Hamming-closeness, on the
   deep moduli `Q^(B)`, to a genuine-height coherent system? Equivalently (§6.1): is every `beta`-good
   parity-respecting system "genuine-like"? A counterexample must be uncertified (Theorems A-C) and must
   control 3-term relations on `q = +-1 mod 2^B` for every `B`, which no superposition of certificates does
   (§6.3). The smallest open instance is norm 3: a parity-respecting system with all monomials of norm
   `<= 3` of demand `O(log M)`.
2. **Norm 3 via Freiman-type encodings.** Is there, at each `q` with `b_q >= 4`, a map from coherent labels to
   parity-respecting labels that preserves all signed relations of norm `<= 3` (as Lemma 5.1 does for norm 2)?
   A counting obstruction would be an inverse theorem at norm 3; a construction would extend Proposition D.
3. **(I3) for genuine-height certificates** (L7): unchanged and open.
4. **Constants.** Theorems A and C use Linnik's exponent `L`, and Theorem B the `X^eps` of Heath-Brown's
   quadratic large sieve; both citations are from memory and should be checked. They affect only the threshold
   `A >= L(h_0 + h) + 2`, i.e. how large `X = 3M^A` must be chosen, not any growth statement.
5. **The twin channel L5** is separate and untouched here: Proposition D concerns label systems, and on twin
   profiles its free labels can be used for `(ell_J, U)` by `p3Dlower.md` Thm 2.1.
