## 1. Setting, notation, conventions

Conventions are those of round 12. **Theorem / Proposition / Lemma** means proved here with all quantifiers, or quoted
from a named source. **Exact** means an integer or exact-rational computation, or a mod-`p` computation used only in the
direction in which it is rigorous (§1.4). **Evidence** means anything else. Scripts are in `loctheory_checks/`, and each

**1.1 The box.** `T = 1`, `d = n - 1`, `k' = (k_1..k_d) in {-1,0,1}^d`, `k_n = -sum k'`,
`A = {k in Z^n_0 : |k_x| <= 1, |<k,beta_p>| <= w for every p}`, `w = sqrt(8 d ln 4r)`, `j = floor(w/2)`,
`m' = ceil(4w)`. When a column is a sign column (`e_p = 1`, `beta_p = 2*1_{S_p} - 1`), on `Z^n_0` we have
`<k,beta_p> = 2k(S_p)`, so the constraint reads `|k(S_p)| <= j`. The **Sylvester profile** is `n = 2^k`, points
`x in F_2^k`, all `n - 1` sign columns `S_a = {x : a.x = 1}` (`a != 0`), so `r = d`. Throughout, `8j <= 4w <= m' < 8j + 9`.

**1.2 Leading forms.** `S_D = Q[y_1..y_D]`. For a finite `X subset Q^D`, `I(X)` is its vanishing ideal and `J(X)` the
ideal of top-degree forms of elements of `I(X)`. `h_X(e)` is the dimension of the space of functions on `X` that are
restrictions of polynomials of degree `<= e`. `H_X(e) = h_X(e) - h_X(e-1) = dim (S_D/J(X))_e`, and
`sum_e H_X(e) = |X|`. `rho(X) = max{e : H_X(e) != 0}` is the interpolation degree. `J(X) ⊂ J(X')` when `X' ⊂ X`.
`R = S_d/(x_1^3, ..., x_d^3)`. For the cube `C = {-1,0,1}^d`, `J(C) = (x_i^3)` and `H_C(e) = [t^e](1+t+t^2)^d`.

**1.3 Families, images, grids.** A family `F = (v_1..v_b)` of integer directions defines `pi_F(k') = (<v_q,k'>)_q`,
its image `B_F = pi_F(A) subset Z^b`, and its local ideal `J_F = pi_F^* J(B_F) subset J(A)` (README §7.1). The
**grid hull** of `F` is `Gamma_F = prod_q I_q`, where `I_q` is the set of values of `<v_q,.>` on `A`. Then
`J(Gamma_F) = (y_q^{|I_q|} : q)` (grid lemma: loccompute Lemma 4.1), and `pi_F^* J(Gamma_F)` is generated by width
powers. Put `s_F = sum_q (|I_q| - 1)`, the socle degree of `S_b/J(Gamma_F)`, and `Q_F = Gamma_F \ B_F`, the set of
**missing value vectors**. For sign columns, `Gamma_F = [-j,j]^b` and `s_F = 2jb` as soon as each `I_q` is the full
interval, which holds in the regime by refJ/t1rigour Lemma 6.1. We say that `F` **contributes in degree `e`** if
`J(B_F)_e != J(Gamma_F)_e`, that is, if its local ideal has generators of degree `<= e` that are not width powers of
its own directions.

**1.4 Certification.** Where a statement "`L = J(X)` in degrees `<= D`" is certified by computation, the generators
of `L` are computed exactly over `Q`, and `L ⊂ J(X)` holds over `Q` by construction. The mod-`p` dimension of the
ideal they generate is `<=` its rational dimension. The mod-`p` evaluation ranks `h^{(p)}_X(e)` are `<= h_X(e)`. So
equality of the cumulative counts `sum_{e<=D} dim_p L_e = N_{<=D} - h^{(p)}_X(D)` for every `D` forces equality over
`Q` (same sandwich as README §4.2(c)). Mod-`p` values of `rho` are **upper** bounds. `p = 2147475331`.

## 2. Contribution criterion: when can a family F contribute generators to J(A) in degree <= m'

**Answer to task (1).** As literally stated ("`F` contributes generators in degree `<= m'` only if
`rho(pi_F(A)) < m'`"), the claim is **false**. Proposition 2.4 gives an exact counterexample, and loccompute §3.2 one in
the faithful Paley-12 model. The correct statement replaces `rho` of the image by `rho` of the **missing set**
`Q_F = Gamma_F \ B_F`, through a linkage identity inside the grid hull (Theorem 2.2):

```text
F contributes in degree e   <=>   alpha_F <= e <= s_F,   alpha_F := s_F - rho(Q_F)    (exact, every family, every profile).
```

### 2.1 Linkage inside a grid

**Lemma 2.1 (Gorenstein duality of a grid).** Let `Gamma = prod_{q<=b} I_q subset Q^b` be a finite grid with
`N_q = |I_q|`. Put `R_Gamma = S_b/J(Gamma) = Q[y]/(y_q^{N_q})` and `s = sum (N_q - 1)`. For every homogeneous ideal
`K` of `R_Gamma` and every `e`, `dim (0 :_{R_Gamma} K)_e = dim (R_Gamma/K)_{s-e}`.

*Proof.* `R_Gamma` is a monomial complete intersection: its monomial basis is `{y^c : c_q < N_q}`, its socle is
`Q y^{N-1}` in degree `s`, and multiplication `(R_Gamma)_e x (R_Gamma)_{s-e} -> (R_Gamma)_s = Q` is a perfect pairing,
since `y^c` pairs to `1` exactly with `y^{N-1-c}`. Let `f in (R_Gamma)_e` with `f K_{s-e} = 0`. Then for `g in K_{e'}`
with `e' < s - e`, `fg R_{s-e-e'} subset f K_{s-e} = 0`, so `fg = 0` by perfectness; and for `e' > s - e`, `fg = 0`
for degree reasons. Hence `(0:K)_e = {f in R_e : f K_{s-e} = 0} = K_{s-e}^perp`, which has dimension
`dim R_e - dim K_{s-e} = dim R_{s-e} - dim K_{s-e}` (the Hilbert function of `R_Gamma` is symmetric). QED

**Theorem 2.2 (linkage in the grid hull).** Let `Gamma` be a finite grid, `P subset Gamma` and `Q = Gamma \ P`. Then:
* (a) `J(Q)/J(Gamma) = 0 :_{R_Gamma} (J(P)/J(Gamma))`;
* (b) `H_P(e) + H_Q(s - e) = H_Gamma(e)` for every `e`;
* (c) if `Q != ∅`, then with `alpha(P) := s - rho(Q)`: `J(P)_e = J(Gamma)_e` for every `e < alpha(P)`, and
  `J(P)_{alpha(P)} ⊋ J(Gamma)_{alpha(P)}`;
* (d) `rho(P) = max{e : H_Gamma(e) > H_Q(s - e)}`, and `alpha(P) <= rho(P) + 1`.

*Proof.* (a) If `f` vanishes on `Q` and `g` on `P`, then `fg` vanishes on `Gamma` and its leading form is the product of
the leading forms. So `J(Q) J(P) subset J(Gamma)`, i.e. `J(Q)/J(Gamma) subset 0 : K` with `K = J(P)/J(Gamma)`. By
Lemma 2.1, `dim R_Gamma/(0:K) = sum_e (dim R_e - dim (R/K)_{s-e}) = |Gamma| - |P| = |Q| = dim R_Gamma/(J(Q)/J(Gamma))`.
So the two ideals are equal. (b) Compare degree `e` in (a) with Lemma 2.1: `H_Q(e) = dim R_e - dim (0:K)_e
= H_Gamma(e) - H_P(s-e)`; then substitute `e -> s - e` and use the symmetry of `H_Gamma`. (c) For `e < alpha`, `s - e > rho(Q)`,
so `H_Q(s-e) = 0` and `H_P(e) = H_Gamma(e)`. Together with `J(Gamma) subset J(P)`, this gives equality in degree `e`.
At `e = alpha`, `H_Q(rho(Q)) > 0`, so `H_P(alpha) < H_Gamma(alpha)`. (d) The formula is (b). For the inequality, all
forms of degree `rho(P) + 1` lie in `J(P)`, and they do not all lie in `J(Gamma)` unless `H_Gamma(rho(P)+1) = 0`,
which would force `P = Gamma`. QED

`linkage_ok = True` in `parity_sections_out.txt` and `mod3_sections_out.txt` checks (b) exactly on 21 sets.

### 2.2 The correct contribution criterion

**Corollary 2.3.** For every profile, every family `F` of linearly independent integer directions, and every `e`:
`(J_F)_e subset pi_F^* J(Gamma_F)_e` (width powers of `F`'s own directions) for `e < alpha_F := s_F - rho(Q_F)`.
For `alpha_F <= e <= s_F`, `J_F` has elements in degree `e` outside `pi_F^* J(Gamma_F)` (Hilbert functions of finite
sets have no internal zeros, so `H_Q(s-e) > 0` for `0 <= s - e <= rho(Q)`). Equivalently:

```text
F contributes in some degree <= m'   <=>   rho(Gamma_F \ pi_F(A)) >= s_F - m' .
```

For sign columns this reads `rho(missing value vectors) >= 2jb - m'`.

*Proof.* Theorem 2.2(c) with `P = B_F`, `Gamma = Gamma_F`. The pullback is injective on `S_b` for independent
directions, so strictness is preserved. QED

What this does not say: an element of `J_F` outside `F`'s own width powers may still lie in `J_w` (width powers of
other directions) or in other families' local ideals. "Contributes" here means relative to `F`'s own grid. That is the
right notion for bounding which families must appear in `Loc(b_0)`.

### 2.3 The literal statement is false

**Proposition 2.4 (exact).** Let `P = {y in [-2,2]^5 : y_1 + ... + y_5 = 0 mod 3}`, so `|P| = 1041`. Then
`rho(P) = 10`, `rho(Q) = 13` and `alpha(P) = 20 - 13 = 7`. So `J(P)` has non-grid generators in degree `7`, while
`rho(P) = 10 > 8`. (`mod3_sections_out.txt`, exact ranks.)

This is the image type that loccompute §3.2 found in Paley-12 (`L = 2`, `m = 8`): the `index-3` sublattice images of
5-column congruence families, with `1041`-point orbits. Loccompute certifies over `Q` that these families add degree-7
generators to `J(A)` beyond `L_col(4) = J_w`, although `rho(pi_F A) >= 8 = m`. So restricting `Loc(b_0)` to families
with `rho(pi_F(A)) < m'` (README §7.1) would lose generators in a faithful model. **README §7.1 should use `alpha_F <= m'`,
not `rho(pi_F A) < m'`.**

**How far apart are `alpha` and `rho`?** The data for full-support congruences mod `M` (sets
`P = {y in [-j,j]^b : sum y = 0 mod M}`) are:

| `M` | `(b,j)` | `alpha` | `rho(P)` | `jb` |
| --- | --- | --- | --- | --- |
| 2 | all 14 computed cases `b >= 2` (`b <= 5`, `j <= 4`) | `jb` | `jb` | — |
| 3 | (3,2), (4,2), (5,2), (3,3), (4,3) | 4, 5, 7, 6, 8 | 6, 8, 10, 9, 12 | 6, 8, 10, 9, 12 |

(Parity: Theorem 3.3 below proves `alpha = rho = jb` for all `b >= 2`, `j >= 1`. Mod 3: exact for the listed cases
only.) So for parity `alpha = rho`, while a congruence modulo `M = 3` contributes from about `2jb/3` onward. Parity
images, which are the only kind Sylvester circuits produce (§3), are the case where README's `rho` criterion is
accidentally right.

## 3. Projection costs and the structure of parity images

**Answer to task (2).** The bound `rho(pi_F(A)) >= 2j(|F| - O(1))` is **true for families with a full Venn
diagram** (Lemma 3.1), where it is exact (`= 2jb`) and the family contributes nothing. It is **false for dependent
families**. A family of `c` sign columns forming an `F_2`-circuit (e.g. a Fano line, `c = 3`) has
`rho = alpha = jc` exactly (Theorem 3.3), half the claimed cost. The correct cost for column families with
parity-type images is `j` per column of the smallest circuit, and parity images are **local**: they are generated by
their circuits (Theorem 3.4). So within such families the right count is `b_0 = floor(m'/j)`, i.e. `8`, not
`m'/(2j) ~ 4`.

### 3.1 Families with a full Venn diagram are invisible

**Lemma 3.1.** Any profile, any `n` with `2j <= n`. Let `F = (S_1, ..., S_b)` be sign columns, and for
`chi in {0,1}^b` let `X_chi = {x in [n] : ([x in S_q])_q = chi}` (the base point included). If `|X_chi| >= 2j` for
every `chi`, then `pi_F(A) = [-j,j]^b`, `rho_A(F) = 2jb`, and `J_F = (y_q^{2j+1})` is generated by width powers. So
`F` contributes in no degree.

*Proof.* On `A`, `|k(S_q)| <= j` (§1.1), so `pi_F(A) ⊂ [-j,j]^b`. Conversely let `t in [-j,j]^b`. For `l = 1..j` put
`chi^+_l = ([t_q >= l])_q` and `chi^-_l = ([-t_q >= l])_q`, and `k = sum_l (e_{x_l} - e_{x'_l})`, where `x_l in X_{chi^+_l}`
and `x'_l in X_{chi^-_l}` are `2j` distinct points. They exist because each class is used at most `2j` times. Then
`k in {-1,0,1}^n`, `sum k = 0` and `|k|_1 <= 2j`, so `k in S_w ⊂ A` (t1rigour Lemma 6.1, valid for every profile). Also
`k(S_q) = #{l : t_q >= l} - #{l : -t_q >= l} = t_q`. The grid statement is the grid lemma (§1.3), and `rho` of the box
`[-j,j]^b` is `2jb`. QED

Lemma 3.1 is the precise form of "independent columns cost `2j` each": with the cube's own balanced vectors, every
value vector is reachable. The interesting families are therefore those whose Venn diagram has empty (or small)
cells. For sign columns of a Sylvester profile these are exactly the `F_2`-**dependent** families: the cells are the
cosets of `(span F)^perp`, so a cell is empty iff `chi` is not in the column space of `F` over `F_2` (§5).

### 3.2 The one-dimensional self-dual basis

Let `I = {a, a+1, ..., a+N-1}` be `N` consecutive integers, `eps(t) = (-1)^t`, and `F_e` the space of functions on `I`
of degree `<= e` (`dim F_e = e + 1` for `e < N`). Let `Delta^{N-1}` be the `(N-1)`-st finite difference:
`sum_{t in I} (-1)^{t-a} binom(N-1, t-a) g(t) = (-1)^{N-1} (Delta^{N-1} g)(a)`, which vanishes for every polynomial `g` of
degree `< N - 1`.

**Lemma 3.2.** (a) For every function `f != 0` on `I`, `deg f + deg(eps f) >= N - 1`.
(b) For each `0 <= e <= N-1`, `G_e := F_e ∩ eps F_{N-1-e}` is one-dimensional and `G_e ∩ F_{e-1} = 0`.
(c) There are `f_0, ..., f_{N-1}` with `deg f_e = e` exactly and `eps f_e = lambda_e f_{N-1-e}`, `lambda_e in {±1}`,
`lambda_e lambda_{N-1-e} = 1`. One can take `lambda_e = 1` for `e != (N-1)/2`, and for `N = 2j+1`,
`lambda_j = (-1)^j`.

*Proof.* (a) `eps^2 = 1`, so `f^2 = f (eps f) eps`. With `w(t) = binom(N-1, t-a) > 0`,
`sum_t w f^2 = sum_t w eps f (eps f) = ± (Delta^{N-1} [f (eps f)])(a) = 0` if `deg f + deg(eps f) < N - 1`, which forces
`f = 0`. (b) By (a), `F_e ∩ eps F_{N-2-e} = 0`. So `F_{e-1} ∩ G_e ⊂ F_{e-1} ∩ eps F_{N-1-e} = 0`, which makes
`dim G_e <= dim F_e/F_{e-1} = 1`, and `dim G_e >= (e+1) + (N-e) - N = 1`. (c) `eps` is an involution with
`eps G_e = G_{N-1-e}`. For `e < (N-1)/2` pick `0 != f_e in G_e` and put `f_{N-1-e} = eps f_e`. For `N = 2j+1`,
`eps G_j = G_j`, so `eps f_j = lambda_j f_j` with `lambda_j = ±1`. The sign follows from the count in Theorem 3.4(i)
applied to `b = 1` and `C = {0, {1}}`: there `P` is the set of even points of `[-j,j]`, of size `j + [j even]`, while
the formula gives `j + [lambda_j = 1]`. (Computed exactly for `j <= 5`: `orbit_formula_out.txt`.) QED

### 3.3 Binary-code sections: Hilbert function, cost, locality

Let `Gamma = prod_{q<=b} I_q` be a grid of intervals with `N_q = |I_q| >= 2`, and `C ⊂ F_2^b` a linear code
(codewords are identified with their supports). Put

```text
P_C = { y in Gamma : sum_{q in s} y_q is even for every s in C } .
```

A *circuit* of `C` is a nonzero codeword whose support contains no other nonzero codeword. Every codeword is a disjoint
union of circuits (standard for binary matroids: peel off a minimal nonzero codeword contained in the support). For
`s in C`, `P_s` denotes the single-parity section `{y_s in Gamma_s : sum_{q in s} y_q even}` of the grid
`Gamma_s = prod_{q in s} I_q`, and `pi_s` the coordinate projection. `C` acts on the exponent box
`E = prod_q [0, N_q - 1]` by `s.e = e'`, with `e'_q = N_q - 1 - e_q` for `q in s` and `e'_q = e_q` otherwise. An orbit
`O` is **killed** if some `s` in the stabiliser of its points has `prod_{q in s} lambda_{e_q} = -1`. Since `s` fixes `e`,
`e_q = (N_q-1)/2` on `s`, so this sign is `prod_{q in s} (-1)^{(N_q-1)/2}`. Write `|e| = sum e_q` and
`deg O = min_{e in O} |e|`.

**Theorem 3.3 (cost of a parity section).** `J(P_C)_e = J(Gamma)_e` for all
`e < min_{0 != s in C} (1/2) sum_{q in s} (N_q - 1)`. For a single circuit `s` of size `c >= 2` with all `N_q = 2j+1`:
`H_{P_s}(e) = H_Gamma(e)` for `e < jc`, `H_{P_s}(e) = 0` for `e > jc`, and `rho(P_s) = alpha(P_s) = jc`.

*Proof.* Let `g` vanish on `P_C` with `deg g = e`. Reduce `g` modulo the grid polynomials `prod_{t in I_q}(y_q - t)`,
whose leading forms are coprime monomials. The remainder `g_0` has degree `<= e`, exponents `< N_q`, and vanishes on
`P_C`, and `g - g_0` lies in `I(Gamma)` with a representation of degree `<= e`. On `Gamma`,
`1_{P_C} = |C|^{-1} sum_{s in C} eps_s`, with `eps_s(y) = prod_{q in s} (-1)^{y_q}`. So
`0 = sum_y w(y) g_0(y)^2 sum_{s in C} eps_s(y)`, where `w = prod_q binom(N_q-1, y_q - a_q) > 0`. For `s != 0`, the
term `sum_y w eps_s g_0^2` factors over monomials of `g_0^2`. Each monomial has total degree `<= 2e < sum_{q in s}(N_q - 1)`,
so it has some `q in s` with exponent `< N_q - 1`, and that coordinate's alternating sum vanishes. Hence
`sum_y w g_0^2 = 0`, so `g_0 = 0` on `Gamma`, so `g_0 = 0`, and the leading form of `g` lies in `J(Gamma)`. For a
single circuit, apply this to `P_s` and to its complement `Q_s` (odd points; the same argument with `1_Q = (1 - eps_s)/2`).
This gives `H_{P_s} = H_{Q_s} = H_Gamma` below `jc`, and Theorem 2.2(b) then gives `H_{P_s}(e) = 0` for `e > jc`. Finally
`H_{P_s}(jc) = |P_s| - sum_{e<jc} H_Gamma(e) = (H_Gamma(jc) + (-1)^{jc})/2 > 0`. Here `|P_s| = ((2j+1)^c + (-1)^{jc})/2`
and `H_Gamma(jc) >= 2` is the central coefficient for `c >= 2`. So `rho(P_s) = jc`, and the same holds for `Q_s`, so
`alpha(P_s) = 2jc - jc = jc`. QED

Exact check: `parity_sections_out.txt` (14 cases with `2 <= b <= 5`, `j <= 4`: 11 with exact ranks, 3 mod `p`) gives
`rho(P) = rho(Q) = alpha = jb` in every case, and `H_P = H_Gamma` below `jb`.

**Theorem 3.4 (structure and locality of parity sections).** In the setting above:
* (i) `H_{P_C}(D) = #{non-killed C-orbits O in E with deg O = D}`.
* (ii) For every circuit `s`, `pi_s(P_C) = P_s`.
* (iii) **Locality:** in every degree,

  ```text
  J(P_C)  =  J(Gamma) + sum_{s circuit of C} ( pi_s^* J(P_s) ) ,
  ```

  where `( . )` is the ideal generated in `S_b`. By Theorem 3.3, a circuit `s` contributes nothing below degree
  `(1/2) sum_{q in s}(N_q - 1)`, which is `j|s|` for `N_q = 2j+1`. So in degrees `<= D` only circuits with `j|s| <= D` are
  needed.

*Proof.* Take the bases `f^{(q)}_e` of Lemma 3.2 on each `I_q` and put `f_e = prod_q f^{(q)}_{e_q}` (`e in E`). This
basis is adapted to the total-degree filtration of `Fun(Gamma)`: `F_D(Gamma) = span{f_e : |e| <= D}`. The leading form of
`f_e` is `c_e y^e` with `c_e != 0`. By Lemma 3.2(c), `eps_s f_e = lambda_{s,e} f_{s.e}` with
`lambda_{s,e} = prod_{q in s} lambda_{e_q}`. On `P_C`, `eps_s = 1`, so `f_e|_P = lambda_{s,e} f_{s.e}|_P`.

(i) `Pi = |C|^{-1} sum_s eps_s` is multiplication by `1_{P_C}`, and `Fun(P_C) = Pi Fun(Gamma)`. Now
`Pi f_e = |C|^{-1} sum_s lambda_{s,e} f_{s.e}`, so for `e in O` these vectors are all `±` one vector `g_O`. `g_O` is zero
iff the signs cancel, i.e. iff `O` is killed (`lambda` restricted to the stabiliser is a character, and a sum of a
nontrivial character vanishes). Distinct orbits involve disjoint sets of basis vectors, so the nonzero `g_O` are
independent. Then `h_{P_C}(D) = dim Pi F_D(Gamma) = #{non-killed O : deg O <= D}`.

(ii) Let `y_s in P_s`. The parities `r_q in F_2` of the remaining coordinates must satisfy
`sum_{q in s' \ s} r_q = sum_{q in s' ∩ s} y_q (mod 2)` for all `s' in C`. This affine system is solvable iff its
right side vanishes on `{s' in C : s' ⊂ s} = {0, s}`, which holds since `y_s in P_s`. Each `I_q` has both parities
(`N_q >= 2`), so the extension exists in `Gamma`. The inclusion `pi_s(P_C) ⊂ P_s` is clear.

(iii) Let `L` be the right side. `L ⊂ J(P_C)` because `P_C ⊂ pi_s^{-1}(P_s)`. For a circuit `s` and `e in E`, put
`g_{s,e} = prod_{q in s} f^{(q)}_{e_q} - lambda_{s,e} prod_{q in s} f^{(q)}_{N_q-1-e_q}`, a polynomial in `y_s`. On
`P_s`, `eps_s = 1`, so `g_{s,e}` vanishes there. Hence `f_e - lambda_{s,e} f_{s.e} = (prod_{q notin s} f^{(q)}_{e_q}) g_{s,e}`
lies in the ideal generated by `pi_s^* I(P_s)`, and its leading form lies in `L`. That leading form is:
* `c_e y^e`, when `|s.e| < |e|`;
* `c_e y^e - lambda c_{s.e} y^{s.e}`, when `|s.e| = |e|`;
* `2 c_e y^e`, when `s.e = e` and `lambda_{s,e} = -1`.

Now count in degree `D`, modulo `J(Gamma)` (reduced monomials `y^e`, `e in E`):
1. If `e` is not of minimal degree in its orbit, some codeword `s'` has `|s'.e| < |e|`. Write `s'` as a disjoint union of
   circuits. Their degree changes add up, so one circuit already lowers the degree, and `y^e in L`.
2. If the orbit of `e` is killed, the killing `s'` is a disjoint union of circuits that each fix `e`, with multiplicative
   signs. So one circuit fixes `e` with sign `-1`, and `y^e in L`.
3. If `O` is not killed and `e, e' in O_min` (the elements of degree `deg O`), write `e' = s'.e` with `s'` a disjoint
   union of circuits. Each circuit changes the degree by `delta_i >= 0` (minimality), and `sum delta_i = 0`. So all
   `delta_i = 0`, and `O_min` is connected by degree-preserving circuit moves. The binomials along a spanning tree are
   independent, so `L` contains a subspace of codimension `<= 1` of `span{y^e : e in O_min}`.

Altogether `dim (L/J(Gamma))_D >= #{e in E : |e| = D} - #{non-killed O : deg O = D} = dim (J(P_C)/J(Gamma))_D` by (i).
So `L = J(P_C)` in degree `D`. QED

*Exact checks.* `orbit_formula_out.txt`: the orbit count (i) equals the Hilbert function computed from exact ranks for
22 (code, `j`) pairs, including two-circuit, three-generator and overlapping codes. `circuits_loc_out.txt`: (iii)
certified by the sandwich of §1.4 for a Fano line (`j = 2, 3`), a 4-circuit, and the Sylvester family
`F = {1,2,3,4,5} ⊂ F_2^3` (circuits of sizes 3, 3, 4). In the last case `L` with all `b <= 3` subfamilies has deficits
`[.., 28, 52, 16]` in degrees 8-10, and adding the 4-circuit closes them, as (iii) predicts.

**Corollary 3.5 (locality for parity images; any profile).** Let `F` be a family of directions whose image is a parity
section, `B_F = P_C` inside `Gamma_F` with all `|I_q| = 2j+1`. Then in every degree `e`,

```text
J_F  =  pi_F^* J(Gamma_F) + sum_{s circuit of C, j|s| <= e} J_{F_s} ,        F_s = (v_q)_{q in s} ,
```

so `F` is replaced, in degrees `<= m'`, by sub-families of size `<= floor(m'/j)` (`<= 8` when `j >= 9`). Each circuit of
size `c <= floor(m'/j)` contributes in degree `jc <= m'` (Theorem 3.3); it is not generated by its own proper
sub-families, whose images are full grids.

*Proof.* `pi_{F_s} = pi_s ∘ pi_F`, so `J_{F_s} = pi_F^* pi_s^* J(pi_s(B_F)) = pi_F^* pi_s^* J(P_s)` by Theorem 3.4(ii).
Pull back Theorem 3.4(iii) along `pi_F`. Then drop the circuits with `j|s| > e`: their pullbacks agree with grid
powers in degrees `< j|s|` (Theorem 3.3), and in degree `e` they are generated by elements of degree `<= e`. For the
last claim, `pi_{s \ q}(P_s)` is the full grid `Gamma_{s \ q}` (drop `q` and the parity is free). QED

**Proposition 3.6 (cost of any parity section).** Let all `N_q = 2j+1`. For every binary code `C`,
`H_{P_C}((j-1)b) >= 1`, so `rho(P_C) >= (j-1) b`. If `j` is even, or every codeword of `C` has even weight, then
`rho(P_C) >= jb`.

*Proof.* Take `e = (j-1, ..., j-1)`. For `s != 0`, `s.e` equals `j+1` on `supp s`, so `|s.e| = |e| + 2|s| > |e|`. Thus
`e` is the unique element of minimal degree in its orbit, and its stabiliser is trivial, so its orbit is not killed.
Theorem 3.4(i) gives `H_{P_C}(|e|) >= 1`. For the second claim take `e = (j, ..., j)`. Its orbit is `{e}`, and the sign
of `s` is `lambda_j^{|s|} = (-1)^{j|s|} = 1`. QED

**Corollary 3.7 (the correct form of task (2) for parity images).** If `B_F` is a parity section in `[-j,j]^b`, then
`rho(B_F) >= (j-1)|F|`. Hence a family with a parity image and `rho(B_F) < m'` has
`|F| <= floor((m'-1)/(j-1))`, which is `<= 8` once `j >= 17` (`m' <= 8j+8`). For families with a full Venn diagram,
`rho = 2j|F|` (Lemma 3.1). Circuits show that `(j-1)|F|` cannot be improved beyond `j|F|`.

**Consequence for task (2).** For a circuit `F` of `c` sign columns (e.g. Fano lines `{a, b, a+b}` of Sylvester profiles,
§5), `rho(pi_F A) = jc`. That is `j` per column, not `2j`, and `2j(c - O(1))` fails for every `c >= O(1)+1`. The cost
that controls contributions is `alpha_F`, and for parity images `alpha_F = j * girth(C)` with
`girth = min_{s != 0} |s|`.

## 4. The string (fibration) theorem: cut boxes reduce to lattice sets in atom space

This section handles boxes cut by **atom-constant** columns, i.e. by any number of crossing cuts. The Lefschetz strings
of the cube reduce `J` and `H` of such a box exactly to lattice-point sets in the space of atom sums, whose dimension is
the number of atoms, independent of the atom sizes. It is the tool that makes `J(A_F)` (the box cut by a family `F`
alone) computable for every `n`, and it contains the one-cut and disjoint-cut theorems (J6(b); refJ Thm 3.3) as the
case of one atom per cut.

**Setting.** Partition `[d] = X_1 ⊔ ... ⊔ X_a` into **atoms**, `u_i = |X_i|`, `sigma_i = sum_{x in X_i} x_i` (a linear
form) and `tau(k) = (k(X_1), ..., k(X_a)) in prod [-u_i, u_i]`. For any set `T ⊂ prod_i [-u_i, u_i]` of level vectors put
`A_T = {k in {-1,0,1}^d : tau(k) in T}`. Every box cut by columns constant on atoms (`|sum_i c_{p,i} k(X_i)| <= L_p`) is an
`A_T`, where `T` is a lattice polytope set. For one atom of size `u`, let `h^{(u)}_i = [t^i](1+t+t^2)^u` and
`m_i = h^{(u)}_i - h^{(u)}_{i-1}` (`0 <= i <= u`). A **string** of the atom is a pair `(i, copy)`: there are `m_i`
strings of *radius* `r = u - i` and *shift* `i`. A string of the whole configuration is a tuple `s = (s_1..s_a)`, with
shift `b_s = sum i_{s_l}` and box `Bx_s = prod_l [-r_{s_l}, r_{s_l}]`.

**Theorem 4.1 (string decomposition).** For every `T`:
* (a) `h_{A_T}(e) = sum_s h_{Bx_s ∩ T}(e - b_s)` for all `e`, i.e. `H_{A_T}(z) = sum_s z^{b_s} H_{Bx_s ∩ T}(z)`;
* (b) for every homogeneous ideal `K ⊂ Q[sigma_1..sigma_a]`, as graded vector spaces
  `R/K R ≅ ⊕_s (Q[sigma]/(J(Bx_s) + K))(-b_s)`, where `J(Bx_s) = (sigma_l^{2 r_{s_l} + 1})`;
* (c) `J(A_T) ⊇ (x^3) + tau^* J(T)`, with equality in all degrees `<= m` iff for every string `s`
  **(BIP_s)** `J(Bx_s ∩ T)_e = (J(Bx_s) + J(T))_e` holds for all `e <= m - b_s`.
* (d) `|A_T| = sum_s |Bx_s ∩ T|`.

*Proof.* **Step 1 (one atom, `T` arbitrary).** Let `C = {-1,0,1}^u`, `sigma = sum x`, `R_u = Q[x]/(x^3)`.
* `R_u` has the strong Lefschetz property with respect to `sigma` (Stanley 1980; proved via `sl_2` in refJ Thm 3.1). So
  `R_u = ⊕_{i<=u} ⊕_{p in Prim_i} span{sigma^l p : 0 <= l <= 2(u-i)}` with `Prim_i = ker(sigma^{2(u-i)+1} : R_i -> R_{2u-i+1})`
  of dimension `m_i`, and `sigma^l p != 0` for `l <= 2(u-i)`.
* Let `Z_r = {k in C : |sigma(k)| <= r}` (a one-cut box) and `Z_r^c` its complement. By refJ Thm 3.3 (one cut),
  `J(Z_r) = (x^3, sigma^{2r+1})`.
* `R_u` is Gorenstein with socle degree `2u`. By the argument of Theorem 2.2(a) (with the cube in place of the grid;
  Lemma 2.1 holds verbatim for `Q[x]/(x_i^3)`), `J(Z_r^c)/(x^3) = 0 :_{R_u} sigma^{2r+1}`.
* Hence every `p in Prim_i`, which is killed by `sigma^{2(u-i)+1}`, lies in `J(Z^c_{u-i})_i`. So there is a function
  `f_p` on `C` of degree `<= i`, with symbol `p` in `R_u` (its degree-`i` part mod `x^3`), vanishing on every level
  `|sigma| > u - i`.
* The functions `sigma^l f_p` (`l <= 2(u-i)`) have symbols `sigma^l p`, which form a homogeneous basis of `R_u`. So they
  form a basis of `Fun(C)` adapted to the degree filtration: `F_e(C) = span{sigma^l f_p : i_p + l <= e}`.
* `f_p` is supported on the `2(u-i)+1` levels `|t| <= u - i`, so `Q[sigma] f_p` has dimension `<= 2(u-i)+1`. It contains
  the `2(u-i)+1` independent vectors `sigma^l f_p`, so `f_p` is nonzero on every one of those levels. Hence
  `Q[sigma] f_p ≅ Fun(levels [-r_p, r_p])` via `g(sigma) f_p -> g|_{[-r_p, r_p]}`.

**Step 2 (atoms).** Put `f_s = prod_l f_{s_l}`. The degree filtration of a product of cubes is the tensor product of the
filtrations, so `F_e(C) = ⊕_s {G(sigma) f_s : deg G <= e - b_s}`, and `G(sigma) f_s` restricted to the level vector `t`
is `G(t) f_s|_t`, where `f_s|_t != 0` iff `t in Bx_s`.

**Step 3 (restriction to `A_T`).** `Fun(A_T) = ⊕_{t in T} Fun(level t)`, and `Fun(C) = ⊕_s Q[sigma] f_s` is compatible with
the level decomposition (each summand is `sigma`-stable). So restriction gives `Fun(A_T) = ⊕_s Q[sigma] f_s|_{A_T}` and
`h_{A_T}(e) = dim F_e(C)|_{A_T} = sum_s dim{G|_{Bx_s ∩ T} : deg G <= e - b_s} = sum_s h_{Bx_s∩T}(e - b_s)`. This is (a), and
(d) is the case of large `e`.

**Step 4, (b).** The Lefschetz decomposition makes `R_u ≅ ⊕_p Q[sigma]/(sigma^{2r_p+1})(-i_p)` as graded
`Q[sigma]`-modules. Tensoring over the atoms gives `R ≅ ⊕_s Q[sigma_1..sigma_a]/J(Bx_s)(-b_s)` as graded modules over
`Q[sigma_1..sigma_a]`, and `R/KR` is the direct sum of the quotients.

**Step 5, (c).** The inclusion holds because `tau^* I(T) ⊂ I(A_T)`. With `K = J(T)`, (b) and `J(Bx_s) + J(T) ⊂ J(Bx_s ∩ T)`
give `H_{R/((x^3)+tau^* J(T))}(e) = sum_s H_{Q[sigma]/(J(Bx_s)+J(T))}(e - b_s) >= sum_s H_{Bx_s ∩ T}(e - b_s) = H_{A_T}(e)`,
degree by degree. Equality of ideals in degree `e` is equality of these numbers, i.e. every term is equal. QED

*Exact checks* (`fibration_check_out.txt`): five two-crossing-cut boxes (`d = 5..7`, `L in {1,2}`; one with four
atoms). In every degree, `H_A` from exact ranks equals the fibred sum (a) and the BIP sum (c). All string boxes satisfy
BIP.

**Corollaries.**
1. **One cut, disjoint cuts (J6(b), refJ Thm 3.3).** With one atom per cut, `T` is a product of intervals, and BIP is
   trivial: the `J` of an interval is a power, and `J` of a product of grids is generated by the coordinate powers. So
   (c) gives `J(A) = (x^3, sigma_p^{2L_p+1})`.
2. **Dimension reduction.** For a family `F` of `b` cuts, `J(A_F)` and `H_{A_F}` are determined by the lattice sets
   `Bx_s ∩ T` in the `<= 2^b`-dimensional atom space, whatever `d` is. The radii of the strings range up to the atom
   sizes, so the number of sets grows with `d`, but their dimension does not. This puts few-cut boxes of regime size
   (`d` in the thousands) within exact reach. zetc §4's few-cut models were limited to `d <= 8`.
3. **Two crossing cuts.** BIP holds in all five computed cases. A proof for general `(u, L)` would give
   `J(A) = (x^3, sigma_1^{2L_1+1}, sigma_2^{2L_2+1}) + tau^* J(hexagon-type T)` (`Loc` with `b_0 = 2` on atom
   directions). It is **open** here.
4. **What fibration does not do.** In the regime, the atoms of the whole profile are singletons (Sylvester columns
   separate all points), so Theorem 4.1 describes `J(A_F)` for subfamilies `F`, not `J(A)`. The passage from the
   `J(A_F)` to `J(A) = J(∩_F A_F)` is the global problem of §6.

## 5. Sylvester profiles: every column-family image, and what it costs

Setting: the Sylvester profile of §1.1. `U ⊂ F_2^k` is a subspace of dimension `t`. Its classes are the cosets of
`U^perp`, indexed by `z in U^* ≅ F_2^t`, each of size `n/2^t`. `c_z = k(C_z)` are the class sums, and
`y_a = k(S_a) = sum_{z : a.z = 1} c_z` for `a in U \ 0`. Put

```text
Y_U(j) = { (sum_{z: a.z=1} c_z)_{a in U\0} : c in Z^{U^*}, sum c = 0, |sum_{z: a.z=1} c_z| <= j for all a in U\0 } ,
Lambda_U = { (sum_{z: a.z=1} c_z)_a : c in Z^{U^*}, sum c = 0 }   (so Y_U(j) = Lambda_U ∩ [-j,j]^{U\0}) .
```

For `F ⊂ U \ 0`, `Lambda_F` is the coordinate projection of `Lambda_U` to `F`.

### 5.1 The images are lattice sections, for every n

**Lemma 5.1 (full image).** Let `2^t ln(2n) < j` and `n >= 2^{t+1} j`. Then `pi_{U\0}(A) = Y_U(j)`. If moreover
`j >= 2^{t-2}`, then `pi_F(A) = Lambda_F ∩ [-j,j]^F` for every `F ⊂ U \ 0`.

*Proof.* "`⊂`": for `k in A`, the class sums satisfy the constraints. "`⊃`": let `c` be admissible. Then
`hat c(a) = sum_z c_z chi_a(z) = -2 y_a` for `a != 0` and `hat c(0) = 0`, so
`|c_z| = 2^{-t} |sum_{a != 0} hat c(a) chi_a(z)| < 2j <= n/2^t` and `sum_z |c_z| < 2^{t+1} j`. In each class `C_z` choose
independently a uniformly random subset `X_z` of size `|c_z|`, and put `k = sum_z sgn(c_z) 1_{X_z}`. Then
`k in {-1,0,1}^n`, `sum k = 0`, the class sums are `c`, and `k(S_a) = y_a` for `a in U \ 0`.

Now let `a' notin U`. Then `chi_{a'}` is a nontrivial character of `U^perp`, so it takes the values `±1` equally often
on every coset `C_z`. By Hoeffding's inequality for sampling without replacement (Hoeffding 1963, Thm 4, with the
lemma `E e^{lambda X} <= e^{lambda^2/2}` for mean-zero `X in [-1,1]`), and independence across classes,
`P(|hat k(a')| >= 2j) <= 2 exp(-(2j)^2/(2 sum_z |c_z|)) < 2 exp(-j/2^t)`. A union bound over the `< n` characters
`a' notin U` gives total probability `< 2n e^{-j/2^t} < 1`. So some `k` has `|k(S_{a'})| = |hat k(a')|/2 < j` for every
`a' notin U`. Then `k in A`, since `|<k,beta_{a'}>| = 2|k(S_{a'})| <= 2j <= w`.

For the second claim, let `y_F in Lambda_F ∩ [-j,j]^F` and extend it to some `y in Lambda_U`. Since
`2^{t-1} e_a in Lambda_U` for every `a` (`y = 2^{t-1} e_a` gives `sum_{a'} y_{a'} chi_{a'}(z) in 2^{t-1} Z`, the
integrality condition for `c_z = -2^{1-t} sum_{a'} y_{a'} chi_{a'}(z)`), the coordinates outside `F` can be moved into
`[-2^{t-2}, 2^{t-2}] ⊂ [-j,j]`. QED

In the regime `j ~ sqrt(2 n ln n)`, so Lemma 5.1 covers every `t <= (1/2) log_2 n - O(log log n)`. The second claim is
sharp in `t`: at `t = 3`, `j = 1` the image can be strictly smaller than the lattice section
(`sylvester_lattices_out.txt`: `F = {1,2,4,7}`, 33 vs 41 points). So, for all large `n`, **the image of every column
family with `F_2`-rank `t <= 5` is the lattice section `Lambda_F ∩ [-j,j]^F`**, which does not depend on `n`.

### 5.2 The lattices: parity (cycle-space) lattices, except for complete blocks

For `F ⊂ U \ 0`, let `C(F) ⊂ F_2^F` be the cycle space of the binary matroid of `F`: the sets `s ⊂ F` with
`sum_{a in s} a = 0`. Its circuits are the minimal dependent sets: Fano lines `{a, b, a+b}` (size 3), quadrangles
`{a, b, c, a+b+c}` (size 4), and so on. `dim C(F) = |F| - t`.

**Lemma 5.2.** `Lambda_F ⊂ Lambda_{C(F)} := {y : sum_{a in s} y_a even for all s in C(F)}`.

*Proof.* `sum_{a in s} y_a = sum_z c_z #{a in s : a.z = 1}`, and `#{a in s : a.z = 1} = sum_{a in s} a.z = 0 (mod 2)`. QED

*Census* (`sylvester_lattices_out.txt`, Smith normal forms; exhaustive for `t <= 3`, 400 random families of each size
for `t = 4`). The index of `Lambda_F` equals `2^{|F| - t} = [Z^F : Lambda_{C(F)}]`, so **`Lambda_F = Lambda_{C(F)}`**, in
every computed family that contains no complete 3-dimensional block (all 7 nonzero vectors of a 3-space). Families
containing one have an invariant factor `4` (and `8` for the complete 4-block). The minimum distance of `C(F)`, i.e.
its girth, is always `>= 3`. Call `F` **binary** when `Lambda_F = Lambda_{C(F)}`. This is a finite, checkable condition
per isomorphism type. It is not proved in general here.

**Corollary 5.3 (Sylvester column families reduce to circuits of size `<= 8`).** Let `n` be large enough for
Lemma 5.1 at `t`, with `j >= max(9, 2^{t-2})`. Let `F` be a binary column family of `F_2`-rank `t`. Then in every degree
`e <= m'`,

```text
J_F  =  (width powers y_a^{2j+1}, a in F)  +  sum_{circuits s of F, |s| <= e/j} J_s .
```

Every circuit of size `c <= 8` contributes in degree `jc <= m'` and is not generated by its own sub-families. Circuits
of size `>= 9` never contribute in degrees `<= m' < 9j`. So, among binary column families, **exactly the circuits of
size `<= 8` are needed**, and `b_0 = 8` (not `m'/(2j) ~ 4`) is the right count for this part of `Loc`.

*Proof.* By Lemma 5.1 and the census hypothesis, `pi_F(A) = P_{C(F)}` with all `N_q = 2j+1`. Apply Corollary 3.5.
The bound uses `8j <= m' < 8j + 9 <= 9j`. QED

**Corollary 5.3' (strata check for binary column spans).** In the setting of Corollary 5.3 with `j >= 17`, let `F` be
a binary column family of `F_2`-rank `t` with `2^t ln(2n) < j` and `rho(pi_F A) < m'` (projection-cheap). Then `|F| <= 8` (Corollary 3.7), so its span `L` has
`2^t <= 256` equal classes. With the transversal order `o_L <= m'`,
`o_L N_2/P(L) <= m' (n-1)/(n/2^t - 1) <= 257 m' = O(sqrt(n log n)) = o(d)`. So **README §7.3 item 4's per-stratum
condition `o_M N_2/P(M) < (1-eps) d` holds for the spans of all projection-cheap binary column families**, for `n`
large. Complete 3- and 4-blocks have at most 16 classes and pass for the same reason. Complete blocks with `t >= 5`
and `2^t <= n/(2j)` are not projection-cheap (Cor 5.7). Mixed non-binary families of large rank are not covered.

So Fano lines (`c = 3`, degree `3j`; refJ Lemma 1.3) are only the first layer: quadrangles (`4j`), 5-circuits (`5j`),
..., up to 8-circuits (`8j`) all appear, and each is essential relative to the column families. Whether non-column
directions can replace them is open (§7).

### 5.3 Complete blocks are not parity images, and they are not local in the tested sense

**Proposition 5.4 (exact).** For the complete 3-block (`F = U \ 0`, `|F| = 7`, image `Y_3(2) = Y_U(2)`, `|Y_3(2)| = 2605`;
by Lemma 5.1 this is the image of `A` for every large Sylvester `n` with `j = 2`, and the same lattice set appears at
every `j` with the box `[-j,j]^7`), let `L` be generated by:
* the grid (`y_a^5`);
* the pullbacks from all 7 lines and all 7 quadrangles;
* the width powers of all 3025 primitive directions `sum_z m_z c_z`, `m in {-1,0,1}^8`.

Then `dim_Q J(Y_3(2))_7/(grid) = 764` and `dim_Q L_7/(grid) = 386`. So over `Q`, `J(Y_3(2))_7 ⊄ L_7`, with a deficit of
`378` in degree `7 = 3.5j`. (`fano_block_cert_out.txt`: exact `fmpz` ranks for both. In degree 6 the lines already give all 63
new generators; they enter at `3j = 6`, Theorem 3.3.)

The mechanism is the order-4 relation `sum_a y_a chi_a(z) = 0 (mod 4)` (SNF factor 4) of full support 7. Single
congruences modulo `M` with full support `b` contribute from degree about `2jb/M` (`modM_sections_out.txt`: `M = 4`
gives exactly `alpha = 2jb/4` in 8 of 9 cases), and `2j * 7/4 = 3.5j` matches. For complete `t`-blocks the analogous
relation has modulus `2^{t-1}` and support `2^t - 1`, which suggests contributions near `4j(1 - 2^{-t}) < m'` **for every
`t`** (heuristic only). If those generators cannot be produced by families of bounded size, `Loc(b_0)` fails for
Sylvester profiles for every fixed `b_0`. `fano_block_pairs.py` tests all families of `<= 2` of the 43 cheap directions on `Y_3(2)`. A deficit of 302 remains in
degree 7, and 7 in degree 6 (mod `p`, evidence; the run for triples did not finish).

### 5.4 Projection cost of complete blocks grows like `2^{t/2} j` (refJ §6.4)

**Proposition 5.5 (counting bound).** For every finite `P ⊂ [-j,j]^b`,
`rho(P) >= min{e : #{c in [0,2j]^b : |c| <= e} >= |P|}`. For complete blocks,
`|Y_t(j)| >= 2^{(t-1)b} floor((2j+1)/2^{t-1})^b / I_t`, with `b = 2^t - 1` and
`I_t = [Z^b : Lambda_U] = 2^{t-1 + (t-2)(2^{t-1}-1)}`.

*Proof.* `J(P) ⊃ (y_q^{2j+1})`, so `h_P(e) <= #{c in [0,2j]^b : |c| <= e}`, and `h_P(rho(P)) = |P|`. Next,
`Lambda_U = M Z^b` with `M_{a,z} = [a.z = 1]` (`a, z != 0`), because `c_0` does not enter. With the Hadamard core `H`,
`M = (J - H)/2`, `H 1 = -1` and `H^2 = 2^t I - J`. So `M` has eigenvalue `2^{t-1}` on `1` and `±2^{t/2-1}` on `1^perp`,
and `|det M| = I_t`. Finally `2^{t-1} Z^b ⊂ Lambda_U` (proof of Lemma 5.1), and every coset of `2^{t-1} Z^b` meets the
box in at least `floor((2j+1)/2^{t-1})^b` points. QED

Numbers (`counting_bound_out.txt`; exact Irwin-Hall CDF, 50 digits). As `j -> infinity`,
`rho(Y_t(j))/j >= 3.00, 4.16, 5.87, 8.30, 11.76, 16.64` for `t = 2..7` (`t = 2` is exact: `3j`). Finite `j`:
`8.289` at `t = 5`, `j = 1000`.

**Lemma 5.6 (monotonicity in `t`).** If `t_1 <= t`, `2^{t_1} ln(2n) < j` and `n >= 2^{t+1} j` (every `U`-class has
`>= 2j` points), then for every `t`-dimensional `U`, `rho(pi_{U\0}(A)) >= rho(Y_{t_1}(j))`.

*Proof.* Choose a subgroup `Z_1 ⊂ U^*` of dimension `t_1`. Run the construction of Lemma 5.1 with class sums supported
on `Z_1`: `c in Z^{Z_1}`, `sum c = 0`, `c` admissible for `Y_{Z_1}(j)`. The random choice inside the classes `C_z`,
`z in Z_1`, controls every `a' notin U` as before (the condition uses `2^{t_1}`). For `a in U`,
`k(S_a) = sum_{z in Z_1 : a.z = 1} c_z` depends only on `a|_{Z_1} in Z_1^*`, and it is `0` when `a|_{Z_1} = 0`. So
`pi_{U\0}(A)` contains the image of `Y_{t_1}(j)` under the injective linear map that copies coordinate `alpha in Z_1^* \ 0`
to all `a` with `a|_{Z_1} = alpha`. `rho` is monotone under inclusion and invariant under injective linear maps. QED

**Lemma 5.6' (all `j`, `t = 6`).** `rho(Y_6(j)) > 9j + 9` for every `j >= 91`.

*Proof.* `#{c in [0,2j]^63 : |c| <= e} <= binom(e+63, 63) <= (e+63)^63/63!`, and by Prop 5.5
`|Y_6(j)| >= (2j-30)^63/2^129`. At `e = 9j+9`, the inequality `(9j+72)^63 2^129 < (2j-30)^63 63!` holds at `j = 91`
(exact integers, `t6_bound_out.txt`). The ratio `(9j+72)/(2j-30)` decreases in `j`, so it holds for all `j >= 91`. QED

**Corollary 5.7 (answer to refJ §6.4).** For Sylvester profiles with `2^6 ln(2n) < j` (`n` large; then `j >= 91`),
every complete XOR block of dimension `t >= 6` with `2^t <= n/(2j)` has `rho(pi_{U\0}(A)) > 9j + 9 > m'` (Lemma 5.6
with `t_1 = 6`, Lemma 5.6'). At `t = 5` the asymptotic bound `8.30 j` also exceeds `m'`, but it is verified only at the
computed `j` (`8.289 j` at `j = 1000`). For `t <= 5`, `(m' - rho_t) 2^t <= 32 m' = o(d)`. The mechanism of refJ §6.4 needs `(m' - rho_t) 2^t > (1+delta) d`, hence
`2^t > d/m' ~ n/(8j)`. So **the mechanism never occurs asymptotically with `2^t <= n/(2j)`**. The range
`2^t > n/(2j)` (classes with fewer than `2j` points, `t >= (1/2) log_2 n - O(log log n)`) is not covered by
Lemma 5.6 and stays open. There the random construction lacks room, and `pi_{U\0}(A)` is not a full lattice
section.

The caveat matters: by Proposition 2.4 and Proposition 5.4, `rho > m'` does **not** imply that the block contributes
nothing in degrees `<= m'`. That is governed by `alpha`, which for complete blocks may stay near `4j`. So Corollary 5.7
settles the `rho`-based strata question, not locality.

## 6. Hilbert-function approach to the global problem

### 6.1 Reformulations

**Lemma 6.1.** Let `A = ∩_{F in 𝓕} A_F`, where `A ⊂ A_F ⊂ C = {-1,0,1}^d` (for instance `A_F` = the box cut by the
columns of `F` only). Then:
* (a) `I(A) = I(C) + sum_F I(A_F)`;
* (b) `J(A) ⊇ sum_F J(A_F)`, with equality in degrees `<= m` iff for every `e <= m`, every function in `Fun(C)` of
  degree `<= e` that vanishes on `A` is a sum of functions of degree `<= e` that vanish on the respective `A_F`;
* (c) dually, `span{Phi_c : c in V(A,m)} ⊂ ∩_F span{Phi_c : c in V(A_F, m)}`, with equality iff (b) holds in degree `m`.

*Proof.* (a) `Fun(C) = Q^C`. Its ideals are the sets of functions vanishing on a subset, and a sum of such ideals
corresponds to the intersection of the subsets. (b) Leading forms of sums are sums of leading forms whenever the
degrees are controlled. Conversely, if `J(A)_e = sum_F J(A_F)_e` for all `e <= m`, peel off top degrees by induction on
`e`. (c) Apolarity: `span{Phi_c : c in V(X,m)} = J(X)_m^perp` (compute R2; README J6(a)), and
`(sum_F J_F)^perp = ∩_F J_F^perp`. QED

So `Loc` relative to the boxes `A_F` is a **degree-controlled ideal-membership** statement in the function algebra of
the cube: "`A = ∩ A_F` in low degree". Dually, the global tangent forms are the intersection of the local ones. For
column families, Theorem 4.1 reduces `J(A_F)` to lattice sets in atom space for every `n`. For Sylvester binary
families, §3 and §5 describe the local ideals `J_F` completely. The global step is what remains.

### 6.2 Reduction to lattice sets in atom space

**Proposition 6.2.** In the setting of Theorem 4.1, let `𝒢` be any set of families of directions in atom space, and
`K = sum_{G in 𝒢} pi_G^* J(pi_G(T)) ⊂ Q[sigma_1..sigma_a]`. Then
`J(A_T)_e = ((x^3) + tau^* K)_e` for all `e <= m` iff, for every string `s` and every `e <= m - b_s`,
`J(Bx_s ∩ T)_e = (J(Bx_s) + K)_e`.

*Proof.* Theorem 4.1(b) with this `K`, and the degree-wise comparison of Theorem 4.1(c). Use
`J(Bx_s) + K ⊂ J(Bx_s ∩ T)`, which holds because `pi_G(Bx_s ∩ T) ⊂ pi_G(T)`. QED

So for any box cut by atom-constant columns, locality, in all of `d`, is **equivalent to locality of finitely many
lattice-point sets in `a` dimensions** (`a` = number of atoms). In particular:
* parity-type `T` (Theorem 3.4) together with BIP gives `Loc` with `b_0` = the largest circuit size up to the degree in
  question;
* the counterexamples of §5.3 live in atom space too: the complete Fano block is the lattice set `Y_3(j)` in 7 atom
  coordinates.

### 6.3 Why the Hilbert-function comparison cannot be run directly in the regime

The task's suggestion is to show `H(S/J_loc)(i) = H_A(i)` for `i <= m'`. The upper bound `H_A(i) <= H(S/J_loc)(i)` is
automatic. The lower bound needs `h_A(i)` from below, i.e. a subset `A' ⊂ A` with computable `J(A')` and
`J(A')_{<=m'} ⊂ J_loc`.
* The natural computable subsets are the boxes `A_T` of §4 and the balanced small vectors `S_w`. But `A_T ⊄ A` unless
  `T` constrains every column, and columns outside the atom algebra (all but `O(2^t)` of them) are not atom-constant.
* `S_w` has `rho(S_w)` of order `j`, so it sees only degrees `<~ j`.

No subset in between is known whose leading-form ideal is computable and as small as `J_loc` up to degree `~8j`. For
`A` itself, `dim (S/J)_i` in degrees `<= m'` is a question about polynomials of degree `~8 sqrt(2 n ln n)` on `~3^n`
points, beyond exact reach (README §5). Lefschetz/Fröberg-type counts give the Hilbert function of
`R/(sigma_p^{2j+1} : p)` only under genericity. Here the columns are far from generic (§5: `F_2` circuits,
congruences, complete blocks), and the exceptions are exactly the non-width generators. **The Hilbert-function route
therefore reduces to the same structural question**: which lattice relations among columns produce low-degree
syzygies of the slab powers (loccompute Lemma 4.3).

## 7. Open points and recommendations

1. **Locality of the complete-block lattice sets `Y_t(j)`: the decisive open question for Sylvester profiles.** By
   Lemma 5.1 these are the images of `A` for every large `n`, and by Prop 6.2 they are lattice problems in `2^t - 1`
   dimensions. Decide whether `J(Y_3(j))` is generated, in degrees `<= 8j`, by pullbacks along families of `<= 6` integer
   directions (any directions, not only columns, class sums and their `{-1,0,1}` combinations).
   * If **no**: `Loc(b_0)` fails for every `b_0 <= 6`.
   * If complete `t`-blocks behave alike for growing `t` (heuristic contribution degree `~4j(1 - 2^{-t}) < m'`), then
     `Loc(b_0)` fails for every fixed `b_0`. By README §7.4 this is then the place to look for global low-degree
     relations, and for real tangent-cone points, on fake pattern boxes.

   Exact route: `Y_3(3)` (about `5 * 10^4` points) with the `GL(3,2) x {±1}` isotypic decomposition.
2. **Lower and upper bounds for `alpha(Y_t(j))`** (the first non-grid degree), as functions of `t` and `j`. Theorem 2.2
   reduces this to `rho` of the complement `[-j,j]^b \ Y_t(j)`. The analogue of Theorem 3.3 for characters of order
   `2^{t-1}` needs weights adapted to `i^t`, `e^{2 pi i t/2^{t-1}}`; with binomial weights only order-2 characters work.
3. **Binarity.** Prove the census (§5.2): `Lambda_F = Lambda_{C(F)}` iff `F` contains no complete block of dimension `>= 3`.
   Lemma 5.2 gives one inclusion. Only the index computation is missing.
4. **BIP for crossing cuts** (§4, Corollary 3). It would give `Loc` with `b_0 = 2` (atom directions) for all two-cut
   boxes, in all dimensions. It is exact in 5 cases.
5. **The global step** (Lemma 6.1): a degree-controlled membership `F_e(I(A)) = sum_F F_e(I(A_F))`. For this one needs
   subsets `A' ⊂ A` with computable `J(A')` and `J(A')_{<= m'} ⊂ J_loc`. None are known beyond degree `~j` (§6.3).
6. **Corrections to README §7.**
   * §7.1: replace "`rho(pi_F(A)) < ceil(4w)`" by "`alpha_F <= ceil(4w)`" (Cor 2.3; Prop 2.4).
   * §7.3 item 3: the bound is `rho >= 2j|F|` only for full-Venn families, which never contribute. For parity images it
     is `>= (j-1)|F|` (Prop 3.6), and contributions start at `j * girth`. So the predicted `b_0 ~ m'/(2j) ~ 4` becomes
     `b_0 >= 8` for column families of Sylvester profiles, provided they are not generated by non-column directions.
   * §7.3 item 4 (strata): passes for all projection-cheap binary column spans (Cor 5.3'); refJ §6.4's `rho_t`
     mechanism is impossible for `2^t <= n/(2j)` (Cor 5.7).
7. **Scope.** Everything in §§3, 5 is for sign columns (`e_p = 1`). Columns with `e_p > 1` give images in grids of
   other shapes, and congruences modulo odd `M` appear (loccompute's Paley-12 mod-3 relations). Theorem 2.2 and
   Theorem 4.1 cover them; Theorems 3.3-3.4 do not.

**No growth improvement and no uniform bound is claimed.** The results:
* settle the contribution criterion (task 1);
* correct and prove the projection-cost bound where it holds (task 2);
* prove `Loc` for all parity images (task 3, partial), and reduce cut boxes to lattice sets in atom space;
* certify that complete Fano blocks are not local in the natural family sets.
