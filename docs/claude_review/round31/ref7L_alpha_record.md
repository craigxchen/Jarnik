## 0. Verdict

**CORRECT, with corrections.** The claim holds: A_5(delta) is false for every delta < 0, and alpha^ess_e(-K) <= 4
over Q. Hence 10/3 <= alpha^ess_e(-K) <= 4. The two normalisations agree. Nothing in the record contradicts the
claim, and nothing in the record already gave the bound. The bound is not trivial in the sense asked: the easy covering
families give exponents well above 4, and the record's own theorems forbid any polynomial or fixed-order family below 4.

The corrections are listed in §5. The main ones are these.
1. The bounded Gaussian gcd is not needed for the upper bound. Dividing by the gcd only lowers H.
2. Lehmann–McKinnon–Satriano define alpha_ess as an infimum over **Zariski-dense sequences**. One sequence that
   escapes a given Z is not enough as it stands. A diagonal argument with strict slack is needed (§3.3). The
   per-curve constants are seed-dependent and not uniform.
3. A strengthening, found in this check (§4). Fix the integer T and let n -> infinity, instead of fixing n and letting
   T -> infinity. At T = 2 the matrix is A(2) = [[5,2],[2,1]], the record's Cilleruelo–Granville Pell matrix. Each such
   curve then carries five-tuples with Delta H^{1/4} bounded, so its exponent is exactly 4, and the union of these
   curves is Zariski dense. The constant grows with the seed height (§4.3). So "exponent exactly 4 on a Zariski-dense
   set with one constant" is still **not established**.

## 1. Definitions used

* A primitive k-tuple is a tuple of distinct Gaussian integers zeta_1..zeta_k with |zeta_j| = R'' and
  gcd_{Z[i]}(zeta_j) = 1. Its class [zeta] = (zeta_j/zeta_1)_j is a point of T_k(Q), and T_k is the norm-one torus of
  dimension k-1.
* A_k(delta) says the following. There are a proper Zariski-closed Z ⊂ T_k and an R_0 such that every primitive
  k-tuple with R'' >= R_0 and all mutual distances <= R''^{1/2-delta} has [zeta] in Z.
* X is the smooth weak Fano 4-fold twisted Losev–Manin \bar L_5^{tw}, and e is the identity of T_5. For a primitive
  representative, H = H_{-K}([zeta]) = R''^2 (expert note §3). The distance is dist(y,e) ≍ Delta := diam/R''.
* For a sequence {y_i} -> e, alpha({y_i}) = inf{gamma : dist(y_i,e)^gamma H(y_i) is bounded}. This is McKinnon–Roth's
  normalisation with multiplicative heights relative to Q (`papers_check/README.md` l.59–64).
  alpha^ess_e(-K) is the infimum of alpha({y_i}) over Zariski-dense sequences {y_i} -> e. This is LMS Def 1.1, as the
  record quotes it at `papers_check/README.md` l.65–68; the record's checker item 55 shows it equals the sup-over-open-U
  form.
* The family is as in the task. A(t) = [[t^2+1, t],[t, 1]] and beta = t + 2i. G_j = X_j + iY_j with
  (X_j,Y_j)^T = A^n (1,s_j)^T. The marks are z_0 = beta prod_l conj(G_l) and
  z_jk = conj(beta) G_j G_k prod_{l != j,k} conj(G_l) for jk in {12,13,23,14}.

**2.3 Density** (`check2.py`, `check4.py`). Fix t = T0. Consider the map from seeds (s_1..s_4) to the Cayley

the union of the curves of §4 (n -> infinity, fixed T).

## 3. Normalisation and the logic of the consequence

**3.1 The two normalisations agree.** Suppose the points are at mutual distance R''^{1/2-delta} and H = R''^2. Then
Delta = R''^{-1/2-delta} = H^{-(1+2delta)/4}, so gamma = 4/(1+2delta). The Pell data are R'' ≍ T^D and
diam ≍ T^{4n+1}, so diam = R''^{(4n+1)/(8n+1)} = R''^{1/2 + 1/(2D)}. Hence delta = -1/(2D) and
gamma = 4/(1 - 1/D) = 4D/(D-1) = 4(8n+1)/(8n) = 4 + 1/(2n). The judge writes W/h = 2D/h = (16n+2)/(4n) =
4 + 1/(2n). This is the same number. It is also d/m for a rational curve of -K-degree 2D whose branch at e has
multiplicity h = 4n. Directly: Delta ≍ T^{-4n} and H ≍ T^{2D}, so Delta^gamma H is bounded iff gamma >= 2D/(4n).
Neither normalisation is wrong.

**3.2 Gcd and denominators.** For an *upper* bound on alpha, only H <= (unreduced R)^2 is used, where the unreduced
tuple is the one with cleared denominators. Dividing by any Gaussian gcd lowers H and leaves Delta unchanged. So the
bounded-gcd lemma is not needed for alpha^ess <= 4 or for the failure of A_5(delta < 0). It is needed only if one
wants the exponent to be exactly 2D/h along the curve. The denominators do matter. They enter H through the cleared
integer tuple, and my scripts keep them (§4.3).

**3.3 From curves to alpha^ess (quantifiers).** Fix n and gamma > 4 + 1/(2n). For every rational seed vector s with
distinct entries, let C_s be the curve T -> [z(T)]. Then dist^gamma H ≍_s T^{2D - 4n gamma} -> 0. The implied
constant depends on s and n. Enumerate the rational seed vectors as s^(1), s^(2), and so on. Choose T_k so that, on
C_{s^(k)}, every T >= T_k gives dist <= 1/k and dist^gamma H <= 1. Let Sigma be the set of all points of C_{s^(k)} with
T >= T_k, over all k. Each tail is an infinite subset of an irreducible curve, so it is dense in that curve. So the
closure of Sigma contains every C_s, and Sigma is Zariski dense (§2.3). Ordered suitably, Sigma is a sequence
converging to e, with dist^gamma H <= 1 throughout. So alpha^ess_e(-K) <= gamma. Letting gamma decrease to
4 + 1/(2n), and then n -> infinity, gives **alpha^ess_e(-K) <= 4**. A_5(delta) for delta < 0 fails in the same way.
Given Z, pick n with 1/(2D) < |delta| and a seed s with C_s not inside Z. For large T the points are off Z, and
diam <= C_s R''^{1/2+1/(2D)} <= R''^{1/2-delta}. Strict slack is essential in both arguments. The constants C_s are not
uniform in s.

## 4. A strengthening the referees did not draw: fixed T, n -> infinity

**4.1 Identity.** Let lambda be the larger eigenvalue of A(t), and put omega = (lambda-1) + i t. Then (lambda-1, t) is
an eigenvector, and **omega^2 = t(lambda-1) beta** modulo lambda^2 - (t^2+2) lambda + 1. Both facts are checked
symbolically in `check4.py`. For real t, omega^2/conj(omega)^2 = beta/conj(beta). Now fix an integer T and put
u = lambda^n. Then G_j = r_j omega u + O(u^{-1}), with r_j real and r_j ∝ (lambda-1) + T s_j, which is nonzero for
s_j > 0. So G_j/conj(G_j) = (omega/conj omega)(1 + O(u^{-2})), and
z_jk/z_0 = (conj beta/beta)(omega/conj omega)^2 (1 + O(u^{-2})) = 1 + O(u^{-2}). Also R ≍ u^4. Hence
Delta R^{1/2} = O_{T,s}(1).

**4.2 Exact data** (`check3.py`). Five distinct points of one norm, with the exact Gaussian gcd removed, at T = 1, 2, 3,
seeds (1,2,3,5) and (1/2,-2,7/3,4), and n up to 160. Delta H^{1/4} is periodic in n and bounded. At T = 2 with seeds
(1,2,3,5) it alternates between 5.78740034 and 8.65418205, and the gcd norms alternate between 320 and 64.
log Delta / log H -> -1/4. So each fixed-(T,s) sequence has alpha exactly 4. It lies on the curve
C_{T,s} = closure of phi(G_m), where phi(u^2) is the ratio class. The union over s of these curves is Zariski dense
(§2.3, Jacobian at T = 2, n = 1, 2, 3). The diagonal argument of §3.3, run with gamma = 4 + epsilon, gives
alpha^ess <= 4 with no polynomial algebra in t. Moreover, for every proper closed Z there are a constant C_Z and
infinitely many primitive five-tuples off Z on arcs <= C_Z R''^{1/2}.

**4.3 Not uniform.** Δ H^{1/4} grows with the seed height (`check5.py`, `check6.py`; T = 2, n = 39, 40). Seeds
((q+1)/q, 2, 3, 5) give 16.7, 23.7, 42.8, 327 and 1030 for q = 2, 5, 17, 1009 and 10007. Integer seeds (1,2,3,m) give
8.65, 36.5, 118, 374 and 1183 for m = 5, 50, 500, 5000 and 50000. A bounded seed height allows only finitely many
seeds. So this construction does **not** give a single Zariski-dense sequence with Delta <= C H^{-1/4}, and it does not
refute A_5(0) (which has constant 1). The record's open question ("whether a dense unit family reaches exponent 4",
`ref6L_subspace.md` l.92) is answered only in the weak sense: for each Z, at exponent 4 with a constant C_Z.

  Pell family has r = 4, m = 4n and -K·C = 16n+2 >= 16n+1. It satisfies the bound with slack 1, at exponent above 4.
  This is consistent, and it is sharp up to one unit. The same holds for expert note (iv), 4h+1 <= W, with W = 4h+2.
* *Gauss Thm 4.3(ii)* (covering families excluded) assumes delta > 0. The Pell families have delta = -1/(2D) < 0.
* *kill_gauss §4 dimension count.* One-variable polynomial families can be dense at k = 5 only if e > 1/2. The Pell
  families have e = 1/2 + 1/(2D), so they realise the count. The phrase at `kill_gauss.md` l.322, "cannot be dense at
  k = 5 for any profile", must be read with e <= 1/2. This is a wording point, not an error.
* *Round 31 Part VI.1, the thin class* (expert note l.371–386). Off an ineffective Z(K,S,b,eps) it excludes
  Delta <= H^{-1/4-eps}, i.e. exponent < 4. The Pell points have exponent >= 4 in both regimes, so they never satisfy

## 6. Triviality and easy families

* *Star (linear) family* (`check2.py` (d)). Take P_j = t + i c_j, z_0 = prod conj(P_j) and
  z_j = P_j prod_{l != j} conj(P_l). Then D = 4, h = 1 and the exponent is 2D/h = 8. Measured: 11.0, 9.2 and 8.55 at
  T = 10^3, 10^6 and 10^12, tending to 8.
* *Pigeonhole and Dirichlet.* A single circle has R^{o(1)} points, so pigeonhole gives only arcs R^{1-o(1)}. A
  Dirichlet argument over all of T_5(Q) would need equidistribution in balls of radius H^{-1/4}. That is not available
  for this torus, so it is not a soft proof.
* *Below 4.* No polynomial dominating family can go below 4 (Theorem D, -K·C >= 4m + 1). No fixed-order unit
  template can go below 4 off Z (VI.1). I found no family below 4, so nothing signals a normalisation error. The bound
  needs either unbounded contact (h = 4n -> infinity, -K·C/h -> 4) or unit sequences at exactly 4 (§4). In this sense
  it is not trivial. It is, however, an elementary consequence of the Cilleruelo–Granville Pell mechanism once the
  extra mark beta = t+2i (at T = 2, beta = 2+2i) is added. The identity omega^2 = t(lambda-1)beta of §4.1 explains why
  beta works.

## 7. Corrected statement I sign

For every proper Zariski-closed Z ⊂ T_5 and every delta < 0 there are infinitely many primitive five-tuples of
distinct Gaussian integers of one norm R''^2, with class outside Z, all mutual distances <= R''^{1/2-delta} and R''
arbitrarily large. Hence A_5(delta) is false for every delta < 0. Moreover, for every eps > 0 there is a Zariski-dense
sequence y_i -> e in T_5(Q) with dist(y_i,e)^{4+eps} H_{-K}(y_i) bounded. Hence alpha^ess_e(-K) <= 4, and with
Cilleruelo–Córdoba 10/3 <= alpha^ess_e(-K) <= 4.

Two families give these tuples. Either fix n and the seeds and let T -> infinity, at exponent 4 + 1/(2n). Or fix T
(for example T = 2) and the seeds and let n -> infinity, at exponent exactly 4, with Delta H^{1/4} <= C(T,s) and C
depending on the seeds.

Not established: a Zariski-dense set with Delta <= C H^{-1/4} for one constant C, A_5(0), anything for delta > 0, and
anything for the balanced (L_5°).
