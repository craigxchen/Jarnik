WHERE THIS LEAVES THE RATE

At the smooth critical height the truth on typical parents is O(log s), probably O(1); the order-s barrier is a worst-case phenomenon. Every local, valuation-based or character-tested input is imitated, by fakes on circles and by your relaxation in the twin. The input that is not imitated is the exact additive structure with signs: in the twin, y_j - y_i = rho_j - rho_i with each rho_i in one of two classes at every prime, so at each p all separated differences are +- delta_p with the sign given by one bit vector. So far this has been used on a fixed modulus only for pairs with equal signature difference (IX.3) and for prescribed low-complexity profiles (IX.5).

THE TENTH QUESTION (the judge's, which I endorse)

In the critical two-class problem with q squarefree and all primes in [P, 2P], P <= s^A, use that at each p | q the separated differences satisfy (y_i - y_j)^2 = delta_p^2 mod p, with signs given by one residue vector. Do one of the following, and say which you can do:
 (i) prove B = o(s) for EVERY such q (extending IX.3's sum-and-square device beyond equal signature differences), or for one explicit dense family of q with no randomness (all primes in [P, 2P]; all primes up to X);
 (ii) exhibit for one fixed dense q configurations with B >= c s;
 (iii) build the sign-free relaxation: an edge table with |d_ij| <= C sqrt q, the correct gcds, and d_ij = +- delta_p mod p on separated pairs with the sign free per pair, reaching B >> s and failing the triangle identities; (note: with the signs tied to one residue vector and |d_ij| < q/3 the table is automatically genuine, so the sign-free version is the meaningful relaxation);
 (iv) prove that no such table exists for the Paley cuts, and say which pair congruences give the contradiction and whether they constrain an arbitrary Sidon cut pattern with B >> s.
Any of these is a result. If you find that the same argument runs on circles through z_j - z_i = 2 i eta H_ij t_ij (every pair gives prod_{p in D_ij} p = x^2 + t_ij^2 with t_ij tiny, the D_ij closed under symmetric difference), say so; the parallel session is being asked the circle version.
