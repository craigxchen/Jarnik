## 1. Setting

The setting is that of `ptolemy.md` §1 and §7. Write `k = m + 1`. An *anchored configuration*
consists of primitive integer vectors `P_0 = (1,0)` and `P_i = (X_i, Y_i)` for `i in [m]`,
together with positive integers `n_T` for nonempty `T` contained in `[m]`, such that

```text
det(P_i,P_j) = t_ij * prod_{T contains i,j} n_T        (t_ij in Z \ {0}),     Y_j = det(P_0,P_j).
```

The quantities are:

* `w`, a scale parameter, with balance `|log n_T - w| <= eta w`;
* `H_Sigma = sum_j log|Y_j| + sum_{i<j} log|t_ij|`.

The visible (boundary) blocks are `2 <= |T| <= m-1`. Singletons and the top block `T = [m]`
appear in no Plücker relation (`ptolemy.md`, Theorem B(iii)).

**(L_k).** There exist `c > 0`, `eta_0 > 0` and a proper Zariski-closed `Z` contained in
`Mbar_{0,k}` with the following property. Every anchored configuration whose point
`Phi = [P_0 : ... : P_m]` lies in `M_{0,k}(Q) \ Z`, whose blocks form two nested chains at each
prime, and which has `eta <= eta_0`, satisfies `H_Sigma >= c w - O(1)`.

**Negation of (L_k).** For every `c, eta_0, Z, C_0` there is such a configuration off `Z` with
`H_Sigma < c w - C_0`. To refute `(L_k)` it suffices to have, for every proper closed `Z`, a
sequence of configurations off `Z` with `eta -> 0`, `w -> infinity` and `H_Sigma = O(1)`.

**Dictionary** (`ptolemy.md` Theorem B(iv) and Lemma 6.2, audited in `referee_ptolemy.md`).

* At a good prime `p`, the contact of `Phi` with the boundary divisor `D_T` is the `p`-adic tree
  edge length.
* For balanced Boolean configurations,
  `h_{D_T}(Phi) = w + O(eta w + H_Sigma) + O(1)` for every boundary `T`.

So the normalized height vector of `Phi` is `w * beta + o(w)`, where `beta` is the
**balanced class**: `beta.D_S = 1` for all `2^(k-1) - k - 1` boundary divisors. `beta` is a
genuine numerical class, because both sides of every Keel relation have the same number of terms.

## 2. Theorem A: no Liouville argument proves (L_k), for any k

### 2.1 Statement

**Theorem A.** Let `k >= 4`.

**(a)** There is `c_k > 0` with `beta.E >= c_k ||E||` for every pseudo-effective `R`-divisor
class `E` on `Mbar_{0,k}`. Here `||.||` is any fixed norm on `N^1(Mbar_{0,k})_R`. In particular
`beta.E > 0` for every nonzero effective divisor.

**(b) Liouville is vacuous.** Let `F` be a nonzero section of a line bundle `L` on
`Mbar_{0,k}`. Write `div F = sum_T nu_T D_T + E'`, where `E'` is the effective part with no
boundary components. Every Liouville estimate obtainable from `F` is equivalent to

```text
h_{E'}(Phi) >= -c_{E'}        for Phi not in supp E',
```

that is, to positivity of local heights. Fix constants `C_k` for the boundary representation
(Section 2.2). Then for every balanced configuration with

```text
eta <= c_k/(4 C_k),     H_Sigma <= c_k w/(4 C_k),     w >= w_0(E'),
```

this inequality holds automatically, with margin `(c_k/2)||E'|| w`. The constant `w_0(E')` is at
most `O(c_{E'}/||E'||)`, which is `o(w)` per unit degree whenever the coefficients of `F` have
logarithmic height `o(w deg F)`.

**(c) Polynomials in the matrix entries.** Let `F` be any nonzero polynomial in
`X_1, Y_1, ..., X_m, Y_m` (with `P_0 = (1,0)`), not necessarily invariant, evaluated at any
integral lift of the configuration. Then the inequality

```text
sum_T nu_T(F) log n_T  <=  log||F||_1 + sum_i deg_{P_i}(F) log|P_i|          (L(F))
```

is implied by the corresponding inequality for an `SL_2`-invariant bracket polynomial, to which
(b) applies. Here `nu_T(F)` is the order along `Lambda_T = {rank[P_i]_{i in T} <= 1}`.

**Corollary A.** No argument that applies one fixed auxiliary polynomial or section, or finitely
many, can prove `(L_k)` for any `k`. The same holds for a sequence of polynomials of growing
degree with coefficient height `o(w)` per unit degree. Nor can it prove any bound
`H_Sigma >= f(w)` with `f -> infinity`, because the inequality it produces is already satisfied by
the balanced class with `H_Sigma = 0`. The same holds for auxiliary polynomials in the union of
several tuples taken from one cluster: that union is again a balanced Boolean configuration
(item 532 applies to any fixed tuple size), so (b) applies with `k` replaced by the union size.

### 2.2 Proof

**(a)** Let `E` be pseudo-effective and nonzero. Then `E_bar = sum_{sigma in S_k} sigma^*E` is
`S_k`-invariant, pseudo-effective and nonzero, since the pseudo-effective cone is pointed. It
descends to a pseudo-effective class on `Mbar_{0,k}/S_k`.

By **Keel–McKernan** (S. Keel, J. McKernan, *Contractible extremal rays on Mbar_{0,n}*, Thm 1.3;
arXiv alg-geom/9607009), the effective cone of `Mbar_{0,k}/S_k` is the simplicial cone spanned by
the boundary classes `B_2, ..., B_{floor(k/2)}`. That cone is closed, so it is also the
pseudo-effective cone. Hence `E_bar = sum_j a_j B_j` with `a_j >= 0`, not all zero, and

```text
beta.E = beta.E_bar / k! = sum_j a_j |B_j| / k! > 0.
```

Here `|B_j|` is the number of components, and `beta` is `S_k`-invariant. Positivity on the
compact slice `{E psef, ||E|| = 1}` gives the uniform constant `c_k`.

*Independent check at `k = 6`, without KM.* Hassett–Tschinkel (*On the effective cone of the
moduli space of pointed rational curves*, 2002) show that `Eff(Mbar_{0,6})` is generated by the
25 boundary divisors and the 15 Keel–Vermeire divisors. In Kapranov's model (Section 6.3),
`KV = 2H - sum E_i - E_13 - E_14 - E_23 - E_24`, and the script gives `beta.KV = 5`
(`gauss/gammahat.py`). With `beta.D_S = 1 > 0`, this proves (a) at `k = 6` directly.

**(b)** Choose Weil functions. The product formula for `F(Phi) != 0` gives

```text
h_L(Phi) = sum_v lambda_{div F, v}(Phi) = sum_T nu_T h_{D_T}(Phi) + h_{E'}(Phi) + O(1).
```

The finite part of `sum_T nu_T h_{D_T}` is exactly the forced divisibility
`prod n_T^{nu_T} | F(Phi)` (up to `Sigma`-bounded factors), and the archimedean and size bound is
`h_L`. So the Liouville estimate is equivalent to `h_{E'}(Phi) >= -c_{E'}` (positivity of local
heights of an effective divisor not containing `Phi`). Nothing else enters.

Now fix a basis of `N^1` consisting of boundary divisors (Keel), and write
`E' == sum a_T D_T` with `||a|| <= C_k ||E'||`. By the dictionary,

```text
h_{E'}(Phi) = sum a_T h_{D_T}(Phi) + O_{E'}(1)
           >= (beta.E') w - C_k ||E'|| (2^{k-3} eta w + 3 H_Sigma) - O_{E'}(1)
           >= (c_k - C_k 2^{k-3} eta - 3 C_k H_Sigma/w) ||E'|| w - O_{E'}(1).
```

After absorbing `2^{k-3}` and `3` into `C_k`, this is `>= (c_k/2) ||E'|| w - O_{E'}(1)` under the
stated conditions. For `w >= w_0(E')` that exceeds `-c_{E'}`.

**(c)** Let `U = {u_c = (1 c; 0 1)}`, the stabilizer of `P_0`. Write `F(u_c P) = sum_r c^r F_r(P)`.

* The ideal of `Lambda_T` (the `2 x 2` minors of `[P_i]_{i in T}`) is `U`-stable.
* Its powers equal its symbolic powers, since maximal minors of a generic `2 x n` matrix have
  this property.
* Hence every `F_r` has `nu_T(F_r) >= nu_T(F)` and the same multidegree.
* The top coefficient `G = F_{r_max}` is `U`-invariant, because comparing top powers of `c` in
  `F(u_{c+c'}P) = F(u_c u_{c'} P)` gives `G(u_{c'}P) = G(P)`.

`U`-invariants of `m` binary vectors are polynomials in the brackets `[ij]` and the
`Y_i = [0i]`. This is the first fundamental theorem for `SL_2` with the extra vector
`P_0 = e_1`. So `G` is the restriction of an `SL_2`-invariant bracket polynomial `G~` in
`P_0, ..., P_m`. Decomposing by torus weight (`Y` has weight `-1`, `[ij]` weight `0`), we may take
`G~` multihomogeneous.

Since `log n_T > 0` and `nu_T(G) >= nu_T(F)`, the left side of `L(F)` is at most the left side
of `L(G)`. The coefficients of `G` are at most `2^{deg F} ||F||_1`. The right side of `L(G)` is
at least `h_L(Phi) + O(deg)`, for every lift. `G~` is a section on `Mbar_{0,k}`, so (b) applies.

### 2.3 Relation to known statements

* **The non-strict, elementary form is in the notes.** `plucker_compatibility_route.md` §1 proves,
  for bracket polynomials, `sum_S nu_S <= B 2^{m-2}` (average order at most that of a product of
  minors), by a binary-cube multiplicity argument.
  * That statement is equivalent to `beta.E' >= 0`.
  * Theorem A(a) adds strictness with a uniform margin. Equality holds only for products of
    brackets (`E' = 0`).
  * The margin is what makes the barrier robust against imbalance `eta > 0` and growing degree.
  * (c) removes the invariance assumption.
* **Gaussian divisibility (Section 6).** Keeping the two isotropic points gives a class
  `gamma_hat` on `Mbar_{0,k+2}` with `pi_* gamma_hat = 2^{1-k} beta`.
  * The forced-divisibility barrier of `construct.md` (Corollary C3, cube profile) is the
    statement that `gamma_hat` is movable.
  * Movability of `gamma_hat` implies movability of `beta`, since `pi_*` of a movable class is
    movable. So the form-blind barrier is the image of the Gaussian one.
* **Nested chains.** Item-532 blocks from primes with exponent `>= 2` form nested chains. There a
  configuration approaches codimension-`>= 2` strata, and sections on blow-ups of `Mbar_{0,k}`
  could use multiplicity along chain strata.
  * Theorem A says nothing about that refinement.
  * It is irrelevant to `(L_k)`, whose hypothesis class contains the pairwise-coprime
    configurations.
  * It is also irrelevant to squarefree `R^2`, where every prime contributes a single threshold
    layer, so all item-532 blocks are pairwise coprime.

## 3. Theorem B: (L_6) is false

### 3.1 The family

Let `t = (x_1, x_2, x_3, x_4)` be distinct nonzero rationals, and let `e_1, ..., e_4` be their
elementary symmetric functions, so `prod (z - x_j) = z^4 - e_1 z^3 + e_2 z^2 - e_3 z + e_4`. Put

```text
P_lam(z) = (1 + lam e_2) z^2 - lam e_3 z + lam e_4,      Q_lam(z) = 1 + lam e_1 z - lam z^2,
f_lam = P_lam / Q_lam,
lam_a = 0,     lam_b = 4 e_4 / (e_3^2 - 4 e_2 e_4),     lam_c = -4 / e_1^2,
f_a(z) = z^2,  f_b = f_{lam_b},  f_c = f_{lam_c}.
```

Let `E_t` be the normalization of `{(a, b, c) : f_a(a) = f_b(b) = f_c(c)}`, and

```text
Psi_t : E_t -> Mbar_{0,6},     (a, b, c) |-> (x_1, x_2, x_3, a, b, c).
```

The labels are three **anchors** `x_1, x_2, x_3` and three **moving** points `a, b, c`. The
fourth common argument `x_4` is not a marked point. The common value is `T = a^2`.

**Lemma B.1 (pencil identities).**

1. `P_lam - z^2 Q_lam = lam prod_j (z - x_j)`. Hence `f_lam(x_j) = x_j^2` for all `lam` and `j`.
2. For `lam != mu`, `P_lam Q_mu - P_mu Q_lam = (lam - mu) prod_j (z - x_j)`. This is a
   polynomial of exact degree 4. So `f_lam(z) = f_mu(z)`, with `z` in `P^1`, holds iff `z` is one
   of the `x_j`.
3. `disc_z(P_lam) = lam (lam (e_3^2 - 4 e_2 e_4) - 4 e_4)` and `disc_z(Q_lam) = lam (lam e_1^2 + 4)`.
   So `f_b` has a double zero, giving branch value `0`, and `f_c` has a double pole, giving
   branch value `infinity`.
4. Let `Delta_lam(T) = disc_z(P_lam(z) - T Q_lam(z))`. Then `Delta_a = 4T`,
   `Delta_b = kappa_b T (T - s)` and `Delta_c = kappa_c (T - t')`, for rational
   `kappa_b, kappa_c, s, t'`. The branch pairs are therefore
   `{0, infinity}`, `{0, s}`, `{infinity, t'}`: the mixed path pattern of items 108–109.

*Proof.* Each part is a direct expansion. For (2), write `P_lam = P_0 + lam P_1` and
`Q_lam = Q_0 + lam Q_1`, with `P_0 = z^2`, `Q_0 = 1`, `P_1 = e_2 z^2 - e_3 z + e_4` and
`Q_1 = e_1 z - z^2`. Then `P_lam Q_mu - P_mu Q_lam = (mu - lam)(P_0 Q_1 - P_1 Q_0)` and
`P_0 Q_1 - P_1 Q_0 = -prod (z - x_j)`. A common pole would need `Q_1(z) = 0` and `Q_0(z) = 0`,
which cannot both hold. `[]`

**The open set `U`.** Let `U` be the set of `t` where the following hold. Each is the
non-vanishing of a polynomial in `t`, so `U` is open in the parameter space; checked in
`anchored.py`.

* the `x_j` are distinct, nonzero, and `x_j != -x_k`;
* `e_1 != 0` and `e_3^2 - 4 e_2 e_4 != 0`;
* `lam_b` and `lam_c` are distinct and nonzero;
* `s` and `t'` are finite, distinct and nonzero;
* `x_j^2` is not in `{s, t'}`;
* `Q_lam(x_j) != 0` for `lam` in `{lam_a, lam_b, lam_c}`;
* the leading coefficients `l_lam(x_j^2) = (1 + lam e_2) + lam x_j^2` are nonzero;
* for each `j`, the derivatives `f_a'(x_j), f_b'(x_j), f_c'(x_j)` are nonzero and pairwise
  distinct.

`U` is nonempty: `t_0 = (2, 3, -5, 1)` lies in it, and so do 36 of 40 random rational points with
`x_4 = 1` (`verify_L6.py`). It is invariant under the scaling `x -> kx`. Normalize `x_4 = 1`, so
`U` is open in `A^3`.

**Lemma B.2 (geometry of `E_t` for `t` in `U`).**

1. `E_t` is a smooth, geometrically connected curve of genus one.
2. `Psi_t` meets each of the 25 boundary divisors of `Mbar_{0,6}` exactly once, transversally, at
   25 distinct rational points `B_C(t)`. Its image meets `M_{0,6}`.
3. Each moving coordinate has degree 4 on `E_t`.

*Proof.*

*(1)* The function field is `Q(T)(sqrt T, sqrt(Delta_b), sqrt(Delta_c))`. The three square
classes are independent: they ramify at `{0, infinity}`, `{0, s}` and `{infinity, t'}`, which are
distinct by `U`. So `E_t -> P^1_T` is a connected Galois `(Z/2)^3`-cover branched over 4 points,
each with inertia of order 2. Riemann–Hurwitz gives `2g - 2 = 8(-2) + 4 * 4 = 0`.

*(2) Collisions.* By B.1(2), two moving coordinates can coincide only at a common argument
`z = x_j`, that is over `T = y_j := x_j^2`. A moving coordinate equals an anchor `x_k` only over
`T = y_k`, since `f(x_k) = y_k`. So all collisions lie over the four values `y_j`. These are not
branch values, so `E_t -> P^1_T` is étale there and `T - y_j` is a local parameter.

*(2) The contact points.* Over `y_j` the 8 points are `(+-x_j, {x_j, b_j'}, {x_j, c_j'})`, where
the primes denote the other roots. They are rational, since one root is rational. The other roots
`-x_j, b_j', c_j'` are not common arguments, by `U` and B.1(2), so they collide with nothing. The
contacts are:

* For `j <= 3` (anchor `x_j`): the 7 nonempty subsets `S` of `{a, b, c}` that take the value
  `x_j` give the divisors `D_{{x_j} u S}`.
* For `j = 4`: the subsets with `|S| >= 2` give `D_S`.

This is `3 * 7 + 4 = 25` contacts, one for each boundary divisor (sides with at most one anchor).
They are distinct points of `E_t`.

*(2) Transversality.* Near a contact the colliding coordinates are
`x_j + (T - y_j)/f'(x_j) + O((T - y_j)^2)`, with pairwise distinct nonzero slopes by `U`. A
colliding anchor has slope 0. Stable reduction produces one bubble with distinct points, so each
contact has multiplicity one and lies in the open part of exactly one `D_C`.

*(3)* The coordinate `a` has degree `[Q(E_t) : Q(a)] = 8/2 = 4`, and similarly for `b` and `c`.

**Lemma B.3 (the quotient curve and a non-torsion section).**

* Let `E'_t : W^2 = Delta_b(T) Delta_c(T)`. This is a cubic in `T` with roots `0, s, t'`, so it
  is an elliptic curve over `U`.
* The map
  `phi_t : (a, b, c) -> (T, W) = (a^2, l_b(T)(b - b_bar) l_c(T)(c - c_bar))`
  is a morphism `E_t -> E'_t` of degree 4. Here the bars denote the deck-conjugate roots.
* The points over `y_j` map to `Q_j(t) = (y_j, +-W_j(t))`, where
  `W_j = l_b(y_j)(x_j - b_j') l_c(y_j)(x_j - c_j')` is a regular function on `U`.
* At `t_0`, with `X = kappa T` (`kappa` the leading coefficient), the curve is

  ```text
  E'_{t_0} : Y^2 = X^3 + (912465360/14641) X^2 - (513022816051200/1771561) X,
  Q_1(t_0) = (-10483200/1331, -383098060800/161051).
  ```

  Exact arithmetic gives `n Q_1(t_0) != O` for `n` in `{1, ..., 10, 12}`. The same holds for
  `Q_2, Q_3, Q_4` and `2 Q_1`, and at 36 random points of `U` (`ell.py`, `verify_L6.py`).

**Corollary B.3.** There is a proper Zariski-closed `Z_tor` contained in `U` such that, for
every `t` in `U(Q) \ Z_tor`, the point `Q_1(t)` has infinite order. Hence `E_t(Q)` contains a
point `P` of infinite order relative to the rational origin `O = (x_1, x_1, x_1)`; for example
`P = (x_1, b_1', x_1)`, for which `phi(P) - phi(O) = +-2 Q_1`.

*Proof.* Let `Z_tor = union_{n in {1..10, 12}} {t in U : [n] Q_1(t) = O}`.

* Each set in the union is closed, being where the section `[n] Q_1` of the elliptic scheme
  `E'_U -> U` meets the zero section.
* None of them contains `t_0`.
* By Mazur's theorem, a torsion point of an elliptic curve over `Q` has order in
  `{1, ..., 10, 12}`.
* A non-constant map of genus-one curves is a translate of an isogeny, and isogenies preserve
  infinite order.

**Lemma B.4 (dominance).** The curves `Psi_t(E_t)`, for `t` in `U`, are Zariski dense in
`Mbar_{0,6}`. More precisely, for every proper closed `Z`, the set `{t in U : Psi_t(E_t) in Z}`
is contained in a proper closed subset of `U`.

*Proof.*

* Take `C = {x_1, a}`. The contact point `B_C(t)` lies in `D_C`, which is isomorphic to
  `Mbar_{0,5}`. It is the 5-point configuration `(x_1, x_2, x_3, b_1'(t), c_1'(t))`, a rational
  function of `t`.
* The Jacobian of `t -> B_C(t)` has rank 2 at `t_0`. This was checked with exact dual numbers for
  each of the three anchors (`dominance.py`). So `t -> B_C(t)` is dominant onto the irreducible
  surface `D_C`.
* The total space `E_U` is irreducible, so the closure `W` of its image is irreducible. `W`
  contains `D_C` and points of `M_{0,6}`, hence `dim W = 3`.
* Finally, `{t : E_t in Psi^{-1}(Z)}` is closed, since `E_U -> U` is proper. It cannot be all of
  `U`, because that would give `W` contained in `Z`.

**Lemma B.5 (integer contact profile; `disjoint_mixed_elliptic_integer_contact_profile.md`,
audited for item 109).** Let `E` be a smooth genus-one curve over `Q` with a morphism
`Psi : E -> Mbar_{0,6}`, image meeting `M_{0,6}`, such that `Psi^* D_C = [B_C]` with 25 distinct
rational points `B_C`. Let `P` in `E(Q)` have infinite order.

Then there are a finite set of primes `Sigma`, an infinite set of positive integers `N`, and
integers `d_C(N)` with the following properties:

* the `d_C(N)` are pairwise coprime and coprime to `Sigma`;
* `log d_C(N) = alpha N^2 + O(N)` with the same `alpha = h_hat(P) > 0` for all `C`;
* with primitive rows normalized at anchors `(1,0)`, `(0,1)`, `(1,1)`,
  `|det(v_i, v_j)| = b_ij prod_{C contains i,j} d_C(N)`, where the `b_ij` are positive,
  `Sigma`-supported and bounded independently of `N`.

The proof in the note uses only these hypotheses: a smooth model over `Z[1/Sigma]` with disjoint
sections, compact recurrence of `N P` in `E(R) x prod_{p in Sigma} E(Q_p)`, and the identity
`div(det) = sum_{C contains i,j} [B_C]`. By Lemma B.2 they hold for every `E_t` with `t` in `U`.

**Lemma B.6 (anchoring).** Let `y_j = det(v_infinity, v_j)` and `D = lcm_j |y_j|`. Put
`P_0 = (1,0)` and `P_j = (D x_j/|y_j|, sgn y_j)`. Then:

* `det(P_0, P_j) = +-1`;
* `det(P_i, P_j) = t_ij prod_{T contains i,j} n_T`, with the following data:
  * `T` runs over the sides not containing the anchor `infinity`;
  * `n_T = d_C` for `T = C` or `T = C^c`;
  * the `t_ij` are integers supported on `Sigma` and bounded independently of `N`.

*Proof.*

* `|y_j| = b_{infinity j} prod_{C contains infinity, j} d_C`.
* The `d_C` are pairwise coprime and every side contains a non-anchor label, so
  `D = lcm(b) * prod_{C contains infinity} d_C`.
* `|det(P_i,P_j)| = D |det(v_i,v_j)| / (|y_i||y_j|)`. Inclusion–exclusion over the `C`
  containing `infinity` turns this into
  `(Sigma-part) * prod_{C not containing infinity, C contains i,j} d_C * prod_{C contains infinity, C misses i and j} d_C`.
* That is `(Sigma-part) * prod_{T contains i,j} n_T`.
* The `Sigma`-part is an integer, because the left side is an integer and the `n_T` are coprime
  to `Sigma`.

### 3.2 The theorem

**Theorem B.** `(L_6)` is false. In detail: for every proper Zariski-closed `Z` contained in
`Mbar_{0,6}` there is a sequence of anchored configurations with the following properties.

* `Phi` lies in `M_{0,6}(Q) \ Z`.
* Every block, including the top block and the singletons, is pairwise coprime to the others.
* `|log n_T - w| <= eta w` with `eta = O(w^{-1/2})`, and `w -> infinity`.
* `Y_j = +-1` and `|t_ij| <= B_Z`, so `H_Sigma = O_Z(1)`.

Hence no choice of `(c, eta_0, Z)` makes `(L_6)` true.

*Proof.*

* **Choose the curve.** `U(Q) \ Z_tor` is Zariski dense in `U`, so it meets the nonempty open set
  `{t : E_t not contained in Psi^{-1}(Z)}` of Lemma B.4. Pick such a `t`.
* **Produce configurations.** Apply B.5 with B.3 to `E_t`, then B.6. This gives anchored
  configurations `Phi_N = Psi_t(N P)` with:
  * balance `eta = O(1/N)` about `w = alpha N^2`;
  * `Y_j = +-1`;
  * bounded `t_ij` after the `Sigma`-parts are moved into the residues;
  * at each prime outside `Sigma`, at most one block (a trivial chain).
* **Fill the invisible blocks.**
  * The top block can be inflated: replace `P_j` by `(n X_j, Y_j)`, with `n` a prime near `e^w`
    not dividing anything. Rows stay primitive because `Y_j = +-1`. The determinants
    `det(P_0, P_j)` are unchanged and `det(P_i,P_j)` gains the factor `n`.
  * The singleton blocks occur in no determinant, so they can be any distinct primes near `e^w`.
  * If `(L_6)` is read for boundary blocks only, neither step is needed.
* **Avoid `Z`.**
  * `Psi_t(E_t)` is not contained in `Z`, so it meets `Z` in finitely many points.
  * The `Phi_N` are pairwise distinct, because `P` has infinite order and `Psi_t` is birational
    onto its image (each `D_C` pulls back to one point).
  * So all but finitely many `Phi_N` avoid `Z`.
  * For large `N`: `eta <= eta_0` and `H_Sigma = O(1) < c w - C_0`.

## 4. Proposition C: (L_5) fails for trivial reasons; the integral chart

**Proposition C.** Fix a modulus `q_0` and a residue class `x mod q_0` in which the 10 differences
of `0, x_1, ..., x_4` have fixed `q_0`-parts. Then the integer points `x` in `[X, 2X]^4` of that
class have the following properties for a positive proportion of `x`, uniformly as
`X -> infinity`:

* the 10 numbers `x_i` and `x_i - x_j` are pairwise coprime apart from the fixed `q_0`-parts;
* each of them is at least `X/C`.

The corresponding points `(0, x_1, ..., x_4)` of `M_{0,5}`, with `infinity` unmarked, are balanced
Boolean configurations with `eta = O(1/log X)` and `H_Sigma = O(1)`, and they are Zariski dense.
So `(L_5)` is false.

*Proof.*

* **Contacts.** With `infinity` unmarked and the points integral, the `p`-adic tree at a prime
  dividing exactly one of the 10 numbers, say `x_i - x_j`, is a single edge `{i,j} | rest` of
  length `v_p(x_i - x_j)`. For 5 points every boundary divisor is a pair collision, so the contact
  profile is exactly the 10 numbers.
* **Coprimality.** Simultaneous divisibility of two of the 10 linear forms by `p` is a
  codimension-2 condition mod `p`. The Ekedahl–Poonen geometric sieve shows that the proportion
  with a common prime factor `p > P` tends to 0 as `P -> infinity`. Small primes are handled by
  the residue class.
* **Archimedean part and residues.** The archimedean part is bounded when all differences are at
  least `X/C`. Anchoring (Lemma B.6, or `ptolemy.md` Lemma 5.2) gives bounded residues.
* **Density.** The set is Zariski dense, since it has positive density in a box.

`[]`

The C1 family of `ptolemy.md` (`u_i = (s - tau_i)/a_i`) is the linear subfamily. The referee's
repair (several curves C1 with different `tau_4`) is correct but unnecessary.

**The integral chart in general.** Put the configuration in `A^1` with `infinity` unmarked and the
points integral. At each 3|3 split of six points, one side must cluster. Each pair must lie in the
same number of clustered triples, so the clustered triples form a 2-(6,3,2) design. That design is
unique up to isomorphism, and it splits the 20 triples into complementary halves. In cyclic form
it is `{0,i,i+1}, {i,i+1,i+3}`.

This explains the C5 ansatz of the previous attempt: the moving points are cubics whose roots are
indexed by the 5-cycle. For `k = 7` the same balance requirement forces all 35 triples to cluster,
with sextic coordinates (Section 5).

## 5. (L_7): open

* **The mechanism of Theorem B does not extend.**
  * With four moving points as preimages under four maps of a pencil, the fiber product of four
    independent quadratic covers has genus `1 + 2^{m-2}(m + c - 4) >= 5`. This is item 112,
    `seven_row_quadratic_quotient_obstruction.md`. By Faltings each such curve has finitely many
    points.
  * Lifting `E_t` to `Mbar_{0,7}` by a seventh point fails too. The 6-point projection of a
    balanced 7-point curve must have class `2 beta_6`, so one would use a degree-2 cover `E''` of
    `E_t`. The seventh point is then a ratio of sections of a degree-8 bundle on `E''`, which has
    15 projective parameters, subject to 25 linear incidence conditions. That is overdetermined
    by 10.
  * A structured ansatz `u_i(s) = f_s(theta_i)` with `f_s` cubic in `theta` needs a plane sextic
    through 35 triple points. Exactly, these points impose 28 independent conditions on sextics
    (`k7/cubicnet.py`), so the ansatz is empty for generic `theta`.
* **Numerics are inconclusive** (NUMERICAL).
  * In the integral chart, with sextics `u_i = c_i (s - r_i) prod_j (s - r_ij)` and 20 triple
    concurrences, Levenberg–Marquardt from 25 random complex starts converged only to degenerate
    solutions (`k7/k7search.py`).
  * The same solver also finds only degenerate solutions for the `k = 6` C5 ansatz
    (`k7/k6control.py`, 0 of 30). The elimination method there finds 63 non-degenerate real
    curves (`k6/c5real.py`).
  * So the `k = 7` failure says nothing about existence. `ptolemy.md` §5.4 reports the same
    behaviour in other charts.
* **Heuristics.**
  * `K.beta = -7 < 0` at `k = 7`, so the `D = 0` Vojta inequality is vacuous on balanced points.
  * The integer heuristic exponent per shift class is `8 > 0`. In the integral chart the expected
    dimension of balanced rational curves is 3, and the lattice count gives `e^{w}`.
  * I expect `(L_7)` to be false. Proving it needs a dense supply of genus-0 or genus-1 curves of
    class `d beta` (any `d`) with rational structure, or a curve-free construction.

### 6.1 The Gaussian class gamma_hat on Mbar_{0,k+2}

Label the two isotropic points `P = 0` and `Q = infinity` in the `z`-coordinate, and the circle
points `1..k`. Item 117 (`lifted_isotropic_mark_toric_heights.md`) already uses both isotropic
marks. For balanced `k`-subsets of a large cluster, the normalized height vector converges to the
class `gamma_hat` defined by

```text
gamma_hat.D_S = 1/4     for {S, S^c} = {{P,Q}, [k]}        (archimedean: the short arc),
              = 2^{-k}  for S = {P} u A, A nonempty proper  (finite: Gaussian blocks),
              = 0       otherwise.
```

**Checks (`gauss/gammahat.py`, `gauss/pushforward.py`).**

* `gamma_hat` satisfies every Keel relation exactly, for `k = 2..7`.
* Forgetting `P` and `Q` gives `pi_* gamma_hat = 2^{1-k} beta`, for `k = 4..9`.
* Using only `D_PQ`-vanishing, Liouville needs `gamma_hat.(D H - m D_PQ) < 0`, that is
  `m > 2D`. This is exactly the threshold of `tau_problem.md`.
* The vanishing along `D_{P u A}` is toric in the `z`-chart, so it equals the tropical bound. This
  matches Theorem C1 of `construct.md`.
* At `k = 4`, `gamma_hat.KV` is `1/8` or `1/4` over all 720 labellings, which are positive. With
  Hassett–Tschinkel this shows `gamma_hat` is movable on `Mbar_{0,6}`. That independently
  confirms `construct.md`'s Corollary C3 at `k = 4`.

**Pointer (not proved here).** `K_{Mbar_{0,k+2}}.gamma_hat` equals:

|---|---|---|---|---|---|---|
| `K.gamma_hat` | -3/8 | -3/16 | 1/32 | 17/64 | 65/128 | 193/256 |

* So the `D = 0` Vojta instance on `Mbar_{0,8}` (over `Q(i)`), evaluated at six circle points

### 6.3 Kapranov dictionary used for KV

Use the `psi_6` model with points `p_1..p_4 = e_1..e_4` and `p_5 = (1,1,1,1)`. The dictionary is:

## 7. What would still be needed for (L_8) or a growth improvement

* **Liouville is excluded** (Theorem A). That includes several shells, `N`-dependent
  coefficients, non-invariant polynomials, and several tuples at once. With forced Gaussian
  divisibility it is excluded by `construct.md` and Section 6.1.
* **Subspace and Ru–Vojta.** The exceptional sets and height thresholds depend on `S`, the primes
  of `N`, whose number is of order `log R/loglog R`. Exceptional-subspace counts of the form
  `c^{|S|}` exceed `M^{k-1}`. This is unchanged from `ptolemy.md` §7 and
  `claimed_complete_proof_salvage_audit.md`.
* **The heuristic threshold.** `(L_8)` is the `D = 0` Vojta inequality at balanced points, where
  `h_K = 10 w > 0`. Below `k = 8` (form-blind) or `k = 6` (Gaussian, Section 6.1),
  `h_K < 0`, and Theorem B together with Proposition C show that no height gap exists at
  `k = 5, 6`.
* **Function-field analogue.** The analogue of `(L_8)` asks for the absence of balanced curves of
  genus `<= 1` and class `d beta` in `Mbar_{0,8}`, beyond a fixed exceptional set. Their expected
  dimension is negative (`-10d + 2` for genus 0), but this is not proved. The truncated second
  main theorem for the braid arrangement in `P^5` gives no contradiction:
  `(21 - 6) 31 = 465 <= 621`.

**Net effect on the growth question.** None. In the form-blind setting a superlogarithmic `f`
cannot come from `k <= 6`, even off an exceptional set (Theorem B, Proposition C). For
`k >= 7` it cannot come from Liouville (Theorem A).
