### 1.2 Theorem B (re-derived; slicing proof)

The statement is: for finite nonempty `S` in `Z^n`, `reg(S) <= MW_n(S) = 2^{1-n} sum_{P subset [n]} w_P(S)`.

* **Base.** `n = 0` is trivial. For `n = 1`, `reg = |S| - 1 <= max - min`.
* **Splitting.** `K := MW_n(S) = E_{P'}[w_{P'}(S) + w_{P' cup 1}(S)]`, with `P'` uniform among
  subsets of `{2..n}`. Correct, since `2^{1-n} * 2^{n-1} = 1`.
* **Key inequality (2.5).** It holds for **all** pairs of slice indices `c, c'`, not only `c <= c'`:
  `w_{P' cup 1}(S) >= (c' + b_2) - (c + a_1)` and `w_{P'}(S) >= a_2 - b_1`. Averaging over `P'` gives
  `K >= (c' - c) + (g_c + g_{c'})/2`, where `g_c = MW_{n-1}(S'_c) = 2 E_{P'} l_c(P')`.
* **Counting.** The slices of `C_v` sit at integer positions in an interval of length `<= K - v`, so
  `|C_v| <= K - v + 1`. When `|C_v| = 1`, use `g_c <= K` (the case `c = c'`).
* **Peeling.** Lemma 2.1 applies with the hyperplanes `x_1 = c`, taken in any order. Ordering by
  decreasing `g`, together with `reg(S_c) <= g_c` (induction hypothesis; `reg` is affine-invariant),
  gives `reg <= max_i (g_(i) + i - 1) <= K`, because `N(g_(i)) >= i`.

Every step is correct.

**Corollary B1** (slice to `Z^{M-1}`) is correct.

* For `P` containing `M`: `k(P) = s - k(P^c)`, so the sum over `P subset [M]` is twice the sum over
  `P' subset [M-1]`.
* On a slice, `h_A(eps) = 2 w_{eps=+1}(A)`.

**Corollary B2** (`w_P(A_{s,D}) <= D`, trivial cuts give 0, so `Omega <= (2 - 2^{2-M}) D`) is correct.
It equals `upper.md`'s crude constant.

**Equality cases** are correct. For a product of root binomials the Newton polytope is a zonotope, so
`h_supp(eps) = sum_edges |eps_i - eps_j|` and `Omega = #edges = ord`. Boxes give `reg = sum a_i = MW`.

## 2. Theorem B is the Cayley transform of a recorded inequality (major novelty issue)

`hermitian_polynomial_barrier.md`, inequality (1), concerns a nonzero `F` over `Q(i)` that is
multihomogeneous of degree `d_j` in `(X_j, Y_j)`. Write `f(t) = F(1,t)`, `D = sum d_j` and
`v = ord_0 f`. Let `nu_S^+-` be the generic orders of `f` along `{t_j = +-i : j in S}`. Then

```text
2^{-m} sum_S (nu_S^+ + nu_S^-)  <=  (D - v)/2.
```

It is proved there by multiplicity Schwartz–Zippel on `{i,-i}^m`.

**Proposition (equivalence).** Let `c != 0` be supported in `prod_j [0, d_j]`, and put

```text
f(t) = sum_k c_k prod_j (i - t_j)^{k_j} (i + t_j)^{d_j - k_j}  =  prod_j (i + t_j)^{d_j} g(w(t)),
g(w) = sum_k c_k w^k,    w_j = (i - t_j)/(i + t_j).
```

Then:

* (a) `ord_0 f = ord(c)`;
* (b) `nu_S^+ = min_{supp} k(S)`;
* (c) `nu_S^- = d(S) - max_{supp} k(S)`.

Hence `nu_S^+ + nu_S^- = d(S) - w_S(supp c)`, and inequality (1) is literally
`ord(c) <= 2^{1-m} sum_S w_S(supp c) = MW_m(supp c)`. Since `reg(S) = max ord(c)` and `MW` is
monotone, this is Theorem B.

*Proof.*

* (a) The map `t -> w` is a local biholomorphism from `t = 0` to `w = 1`, and the prefactor is a unit
  there. Then apply `upper.md` Lemma 1.1.
* (b) Near a generic point of `{t_j = i, j in S}`, the elements `s_j = i - t_j` (`j in S`) are local
  parameters, and every other factor is a unit or a function of the remaining variables. The terms
  with minimal `k(S)` cannot cancel. Distinct `k_S` give distinct monomials in `s_S`. For equal
  `k_S`, distinct `k_{S^c}` give the linearly independent functions
  `prod_{j notin S} (i - t_j)^{k_j} (i + t_j)^{d_j - k_j}`.
* (c) The same argument with `s_j = t_j + i`.
* `sum_S d(S) = 2^{m-1} D`, so (1) becomes `D/2 - 2^{-m} sum_S w_S <= (D - v)/2`. `[]`

**Direct consequence: a second proof of Theorem B.** Let `f~(s) = s^d f(1/s)`, which has total degree
`D - v`. Coordinatewise inversion maps the grid `{i,-i}^n` to itself. At the vertex with `t = i` on
`P` and `t = -i` on `P^c`, the multiplicity of `f` is at least
`min_k k(P) + d(P^c) - max_k k(P^c)`. Summing over `P` and applying Schwartz–Zippel to `f~` gives
`2^{n-1} D - sum_P w_P <= 2^{n-1}(D - v)`.

**Exact check (R2, `r2_cayley.txt`).** On 295 random measures (`n <= 3`, `d_j <= 3`, many of positive
order) I built `f` as an exact `Z[i]` polynomial and computed `ord_0 f` and `nu_S^+-` by exact
translation. In every case:

* `ord_0 f = ord(c)`, computed exactly from moments;
* `nu^+_S = min k(S)` and `nu^-_S = d(S) - max k(S)`;
* the slack of (1) equals half the slack of Theorem B, exactly.

There were 0 mismatches.

**Assessment.**

* The slicing and peeling proof in `construct.md` is a valid and genuinely different proof. It is
  elementary and avoids Schwartz–Zippel.
* The **statement** is a reformulation of a result the project already has (item 27), and through it
  of DKSS 2009.
* The phrase "A new, self-contained Theorem B" should become "a new elementary proof of the
  mean-width form of the recorded multiplicity Schwartz–Zippel inequality".

## 4. Conjecture E: finite reduction and exhaustive verification

**Lemma (reduction; proved here).** Let `T` be the cut closure of a set:
`T = {x in Z^n : min_supp x(P) <= x(P) <= max_supp x(P) for all P}`. Let `K_m(T)` be the space of
measures on `T` whose moments of degree `< m` all vanish.

* (i) If `c` is tight (`ord c = MW(supp c) = m`), then `T(supp c)` has the same widths, so
  `MW(T) = m` and `c` lies in `K_m(T)`.
* (ii) If `MW(T) = m`, every nonzero `c` in `K_m(T)` is tight, by
  `m <= ord c <= MW(supp c) <= MW(T) = m`.

**Consequence.**

* If some `T` has `dim K_m(T) >= 2`, Conjecture E fails. Up to scalars there are only finitely many
  root products times monomials inside a box, while a 2-dimensional space contains infinitely many
  lines.
* If `dim K_m(T) = 1` and its generator is a root product, then every tight measure with that cut
  closure is a root product.

**R3 (`r3_conjE.txt`).** I enumerated every cut-closed subset of each box below; that covers every
tight measure supported in the box. Kernels were filtered mod `p` (a zero kernel mod `p` implies a
zero kernel over `Q`) and then computed exactly over `Q`. Factorisation is exact symbolic division by
`(x_a - 1)` and `(x_a - x_b)`.

  - The conclusion is unchanged.

## 6. Corrected statement

For every `M >= 2`:

* **Barrier.**
  - Every measure `c` on a shell `S_{s,t}`, or on a slice `A_{s,D}`, satisfies
    `ord(c) <= (2 - 1/ceil(M/2)) t` (respectively `D`). This is `upper.md`, refereed.
  - Independently, `ord(c) <= Omega(supp c) <= (2 - 2^{2-M}) t`.
  - Hence (B), `ord(c) > 2t`, is impossible for every `M`.
* **Mean-width bound.** `reg(S) <= 2^{1-n} sum_P w_P(S)` for finite `S` in `Z^n`, with equality for
  boxes and root-binomial products.
  - This is the Cayley transform of the multiplicity Schwartz–Zippel inequality on `{i,-i}^n`,
    recorded as inequality (1) of `hermitian_polynomial_barrier.md`.
  - `construct.md` gives a new elementary proof by slicing and sorted peeling.
* **Route (C), exponent level.**
  - The tropical bound (C1) is a valid lower bound for the forced divisor. With it, the Liouville
    criterion is degree-free (C2).
  - The cube profile (= the uniform block model of item 27) satisfies, at the exponent level, the
    resulting inequality of every auxiliary form simultaneously, because `ord <= Omega`.
  - Coefficient content of arbitrary height gains only an additive `max_k log Norm c_k`, which the
    Liouville bound pays back (C4).
  - So forced divisibility makes the Vandermonde, and every root-binomial product, exactly critical
    (`ord/Omega = 1`), never supercritical. Against the best half-separating adversary the
    Vandermonde ratio is `1 - 1/(2 ceil(M/2))`.
  - The exponent-level barrier is item 27 of the project notes, restated on `X_M`. New here: the LP
    reduction (Lemma C2'), the unrestricted-height C4, and the `tau`/slice bookkeeping.
* **Route (C), constant level.**
  - It is closed for non-tight forms and for root-binomial products.
  - For other tight forms it is conditional on Conjecture E, which holds exactly for all measures
    supported in `[0,3]^2`, `[0,4] x [0,2]`, `[0,2]^2 x [0,1]` and `{0,1}^4`.
  - Bounded extra forced divisors, such as `2 | 2i Im(z_1 conj z_2)`, are outside C1 and matter only
    at this level.
