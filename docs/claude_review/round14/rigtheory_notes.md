## Theory ideas (session 1)
1. Slack identity (genuine labels): B(v,s) - log charged(D_s(Z_v)) = log uncharged(D_s) + log(1/|sin(<v,phi>-s pi/4)|),
   since |D_s| = nu_s^{-1} e^{w/2} |sin(arg Z_v - s pi/4)|. Uncharged = 2-part, p_l-parts, primes outside charged set.
   One-modulus affordable extra collision (v,s) at q0 (v not genuine collision at q0): charged(D_s) <= nu^{-1} e^{w/2}/q0.
2. Lemma G (short generation): if c'(D)=Z/n for D subset Z^r, then Lambda_{c'} generated by {d+e_j-d' in Lambda'}.
   proof: coset reps; any lattice vector = sum of unit steps; telescoping.
3. Prop R (anticode rigidity): if D has l1-diameter <= K-1 and genuine c(D)=Z/n, and c' has Lambda' cap V_K subset Lambda_gen,
   then c' = u c, u unit. (c factors through c' on D => c'(D)=Z/n => Lemma G => Lambda' subset Lambda_gen => equal => Lemma P.)
   Range: n <= max anticode size of diam K-1 ~ |S_{floor((K-1)/2)}| (x2 if K-1 odd) = pigeonhole-forced range at norm K-1.
   EXPLAINS q_core(K) ~ q*(K-1).
4. Two flexibility mechanisms at one modulus: F1 = extra affordable (non-genuine) collisions; F2 = collision set subset of
   genuine collision set but lattice != genuine (only possible when no covering anticode). F2 is budget-free.
   Prop R': if anticode D with c(D)=Z/n and (D-D+S_1) avoids Sigma_aff(q), then rigid (all deformations).
5. Units: survivors invariant under u in (Z/m)^*, u = 1 mod 4 (s -> us keeps s). u=3 mod 4 swaps s=1,3.
6. Per-modulus packing: any good system: collisions v at q have w(v) >= 2 log q - log 2.
7. Random heuristics useless (free vectors are structured); random lattice heuristic predicts rigidity up to n ~ |V_K|/r.
